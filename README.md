# DSR_function_demo

低弹药实时掉落：玩家携带枪的同类总弹药少于半匣时，敌人死亡掉落最缺的一种弹药，靠近自动拾取。每个区域最多两包未拾取弹药，拾取后恢复掉落；盒子和数量标签置顶显示，尸体不会遮住。`resources/ammo/types/` 的弹药资源统一配置掉落开关、每包数量范围与盒子模型；支持直接新建弹种，原四类武器和初始备弹兼容保留。操作见[弹药与掉落说明](docs/gameplay/AMMO.md)。

使用 Godot 和 GDScript 制作的 3D 俯视角功能性 demo。

直接运行工程或按 **F5** 即开始连续五关。每关先显示可关闭的 2D 游玩说明，阅读时暂停；全波次清空后点击按钮进入下一关，第5关显示通关。死亡重开当前关，各关使用各自保存的生命与装备。首次全屏布局及完整操作见[五关游玩说明](docs/gameplay/PLAY_GUIDE.md)。

当前工程包含玩家移动与耐力、对话、枪械锁定与 3D 散射、训练靶、场景交互物、竞技场及敌人巡逻、感知、搜索和掩体走位。竞技场 AI 在玩家进入区域后运行，离场后刷新并等待再次进入。

武器资源的 **瞄准与散布 → 玩家收敛** 可选择线性／二次／指数公式，并设置最大散布到最小散布的完整时间；二次与指数前快后慢。**Combat → 蹲姿精度 → Crouch Spread Reduction** 只降低最大散布，最小值、基础恢复与爆头资格不变。霰弹只改变随机偏移，固定图样保留。玩家统一按时间恢复；敌人保留独立的原恢复接口。配置、公式与默认时间见[射击说明](docs/gameplay/COMBAT.md#瞄准收敛公式2026-10-26)。

玩家跟枪精度现在只受目标有效横向移动影响：敌人沿瞄准连线靠近／远离时允许正常恢复，斜向损失较小，横向仍需跟枪。**武器资源 → 瞄准与散布 → 玩家跟枪 → 跟枪免罚半角（仅玩家）** 可调整默认25°半角的平行容差（两侧合计50°），仅玩家使用该枪时生效。配置与验证见[射击说明](docs/gameplay/COMBAT.md)。

玩家爆头率从武器可调的 **爆头起始准度**（默认90%）开始线性增加，满准度实际命中必爆头；旧固定“爆头概率”已移除。玩家近战给受击敌人一次眩晕破绽，在 **近战 → 命中反馈 → 眩晕破绽门槛倍率** 调整，默认0.8倍；射击武器普通门槛乘倍率，例如80%×0.8=64%。首次玩家枪击实际命中即消费；玩家自身不获得该状态。眩晕期间敌人头顶有星环，准星金色菱形随当前目标的爆头率收小，满准度发光。防护、倍率伤害和原被爆头状态继续沿原规则，霰弹每枪每个实际命中目标一次判定。配置和限制见[射击说明](docs/gameplay/COMBAT.md#精准爆头2026-10-25)与[近战说明](docs/gameplay/MELEE.md#近战眩晕与爆头破绽2026-10-27)。

武器 **Fire Mode → 霰弹** 提供半自动多弹丸射击，附均衡／横向／纵向三种图样；稳定度只改变各颗弹丸的小幅偏差。展开 **Shotgun → Pattern** 可在检查器画板上点选、拖动弹丸并另存图样；**Shotgun → 逐发装填** 可选一发一发补弹，右键瞄准中断。调大原射击间隔即可模拟泵动节奏。配置、独立 F6 试玩与编辑器 2D 预览见[霰弹使用说明](docs/gameplay/SHOTGUN.md)，原武器资源与关卡配置保留。

**Shotgun → 霰弹图样 → 图样覆盖范围** 可用“散布标定距离＋标定覆盖面积”调整固定散布：面积相同时距离越远，弹道越集中。旧枪保持原尺度，原稳定／不稳定随机偏移参数保留。选中 **ShotgunPatternPreview** 根节点，可拖入三个图样，独立调整预览的标定距离、面积和偏移；观察距离支持 1000 米及更大值。所有预览参数随场景保存，不读取实际武器资源，只有三个图样槽共享落点 `.tres`。

同一分组的 **偏移方式 → 不向圆心偏移** 可禁止弹丸朝图样中心偏移，仍允许侧向、小偏移；中心点保持全方向随机。旧武器默认原随机模式，预览有独立的 **预览偏移方式**，玩家与敌人共用采样算法。配置与效果边界见[霰弹说明](docs/gameplay/SHOTGUN.md#不向圆心偏移)。

关卡现在可用场景节点配置敌人波次：拖入 `scenes/world/enemy_waves.tscn`，在它下面添加 `enemy_wave.tscn`，再摆小队和敌人；复制整波并调整树中顺序即可增删和排序。全灭后自动进入下一波，刷新点被占用时等待。后续波默认在出生时取得一次玩家大概位置，先用原快速追查机制前往，再持续搜索；Wave 的“出生搜索”可关闭或调整默认3米误差，树序首波（第0波）始终排除。快速参数复用Training的Search，默认4秒／1.8倍。第一关已接入两波示例，原 `Squad` 是第一波，新增第二波可自行调整。见[波次使用说明](docs/gameplay/ENEMY_WAVES.md)，包含第一波引用位置、增删波次、其他地图接入和不刷怪排查。

团队意识在 `Arena/Squad` 小队节点的 `Profile` 中统一设置，提供仅视野共享、战术配合、强配合三档；竞技场使用所保存的 Profile 等级，新建 `scenes/world/squad.tscn` 默认仅共享情报。将敌人放在相应小队下面即可建立独立分工，个人 Training 继续独立。区域统一更新地图与公共预约，小队协调器安排任务，各成员实际执行。配置入口和验证限制见 [敌人 AI](docs/enemy-ai.md)。

接敌时，长期停在警戒岗位的成员会逐步尝试附近换位、其他射击站位及队友让路；正常射击、换弹和掩体同步仍由原任务执行。头顶可显示“寻找接敌位置／调整站位／调整射界／等待通道”，便于区分等待原因。恢复规则与验证限制见[接敌恢复](docs/enemy-ai.md#接敌后的持续警戒恢复2026-10-27)。

接敌规划已找到可行的全员任务表时，会经过原完整校验先发布并继续比较其他组合；同一移动目标不再反复打断在途准备。用于修复“方案已经可用、全队仍警戒数秒”的派发空窗，实际验证与性能限制见[派发连续性](docs/enemy-ai.md#接敌任务派发连续性2026-10-27)。

检查器中将三个配合预设 `.tres` 拖入 **Profile**，展开后在 **Level** 选择等级；自定义预设可新建 **EnemyCooperationSettings** 并另存为。只调整当前小队时先将共享资源设为唯一，具体操作及个人训练的接入边界见 [敌人 AI](docs/enemy-ai.md)。

五关当前都可分别打开 `scenes/world/levels/lvl_1.tscn` 至 `lvl_5.tscn` 按 F6 试玩，关卡布局、敌人波次和装备采用用户保存的配置。兵种预设位于 `scenes/enemy/levels/`：第一关近战，第二、三关近战／手枪／冲锋枪，第四、第五关另有各自的四类兵种（含霰弹兵）。各关预设引用 `resources/enemy/training/levels/` 下同关同名训练，同关同兵种实例共用配置；地图中已有跨关引用仍保留。公共身体、AI与翻越组件继续复用，操作见[关卡配置](docs/gameplay/LEVEL_MAPS.md)与[训练隔离](docs/enemy-ai.md#三关战术解锁与训练隔离2026-10-26)。

普通与强配合由协调器持续指挥，包括只剩一人；成员执行任务，不运行个人 Utility。仅视野共享与无绑定成员保留个人评分。各档的地图检查核对真实朝向和藏身空间；队级搜索保留面积观察历史，先调查合法线索，再沿多段路线扩展到本区其余未查空间。普通档异步分工，强档在关键入口等齐，普通路段按队伍间距调速。接敌按实际资格选择射击、侧翼与掩体步骤。战斗加载时冻结装配能力，改训练后重载生效；使用方式及验证范围见 [敌人 AI](docs/enemy-ai.md)。

掩体搜索按入口空间分配检查者，其余成员可寻找另一侧的有效掩护位；同一入口不再同时排入多个检查者。侧翼、远侧掩护转移和赶到队友等待的位置会使用奔跑，临近准备点/目的地减速；接敌移动保留合法威胁朝向。

掩体搜索按实际路线阶段切换关注区域：到入口拐点前检查近侧，实际到达后转向后续藏身区。提示更新保留近期完成的同一检查，避免反复重派；新的目击、不同观察区域、地图变化及到期复查仍可改变任务。

强配合两侧突袭准备期间，支援者看到仍在同一掩体后的玩家，会保留有效同步步骤；双方真实到位且所需掩护就绪后共同放行。支援仍正常前出和开火，目标脱离掩体或参与者／路线失效时重新分工，见[敌人AI](docs/enemy-ai.md)。

远近协同按实际装备安排：远程在空间允许时展开交叉射界，混编时比较近战接近路线和后侧射位；近战停点失效后会根据合法新目击调整。搜索掩护关联具体检查任务，入口前核对真实观察、弹药和身体状态，换弹、受压、减员或等待超时后重新分工。实际行为与现有验证限制见 [敌人测试](docs/enemy-tests.md)。

训练解锁的短程突进现可由普通、强配合的接敌任务调用，沿原路线有限加速，继续使用原冷却和近战命中流程。连续追击保留正在准备的有限规划，避免玩家每帧小幅移动使规划反复重启；支援长点射仍需真实关联任务和队友需求。

近战兵的 **Training → Profile → 战术解锁** 新增可选 **近战堵截**：依据合法目击预测短段路线，尝试跑到侧前方拦截，与远程火力配合；适用于全部配合等级。需要手动勾选并重新加载战斗场景，现有训练不会自动启用。参数与边界见[近战说明](docs/gameplay/MELEE.md#近战堵截)。

团队候选已接入统一动作提案入口：本场初始化读取训练并冻结装配，运行中只在需要规划时轮询这些动作，仍由协调器选择整队方案。默认行为、突进、掩体与撤退、攻击占位、近战掩体专用过程和有限压制均已接入；联合行为与性能验证范围见[实施记录](docs/superpowers/plans/2026-10-24-unified-command-actions.md)。

半身掩体操作：**C** 切换蹲／站，**空格** 翻越面前矮墙。蹲在矮墙后瞄准会按当前方向临时起身，普通蹲姿可直接瞄准；翻越后恢复手动姿态。竞技场新增绿色低掩体，参数与限制见 [移动说明](docs/gameplay/MOVEMENT.md)。

个人 Utility 与团队 AI 共用原生翻越连接，能执行步行／翻越／继续追击，普通步行导航仍避开实体墙。个人翻越落点受阻时可在同一墙面区域内改选具体起跳／落地点；该选择发生在运行时，烘焙仍保留地面面积与跨墙连接。编辑低墙碰撞后可使用 `NavigationRegion3D` 的原生烘焙按钮，并保存场景和导航资源；操作见 [关卡导航](docs/gameplay/LEVEL_MAPS.md#区域导航与空小队)，验证范围见 [敌人测试](docs/enemy-tests.md)。

玩家和相机可分别复用：拖入 `scenes/player/player.tscn` 与 `scenes/player/player_camera_rig.tscn`，在相机根节点的 **Player Path** 指定玩家（同级且名为 Player 时默认即有效）。相机随当前武器 **Aim Range** 调整，试玩两把枪采用18／22米初值；武器资源已移除独立相机视野分组，过渡时间在相机的 **View Transition Seconds** 调整。移动、战斗、生命和装备仍属于玩家，详见[相机与复用说明](docs/gameplay/CAMERA.md)。

敌人默认带无数字血条；远程视距取自身武器锁定距离加可调余量。屏幕外每次合法开火机会默认50%成功，失败跳过整枪且不耗弹，仍消耗射击间隔和点射次数；敌人根节点 **Shooting → Offscreen Fire Chance** 可调0～100%。波次全灭后保留静态尸体外观，回收AI、碰撞和血条，离场／重置后再清掉尸体。配置见[敌人 AI](docs/enemy-ai.md#血条视距与屏幕内开火2026-10-25)和[血条／尸体说明](docs/gameplay/PRESENTATION.md#临时敌人血条与波次尸体2026-10-25)。

医疗包操作：松开动作键后按 **H** 治疗，无需等待惯性停稳；默认两秒完成、恢复50生命，初始3个。动作输入或受击立即打断，中断不消耗。选中 `Player → Equipment`，在“医疗包”分组配置 **Medkit Count** 与 **Medkit** 资源，展开资源调整回血量／时间；Equipment（装备）为原 WeaponSlots 节点，统一管理武器与医疗包，见 [生命与医疗包](docs/gameplay/PLAYER_HEALTH.md)。

攻击武器可配置命中／压制精度损失（百分比）、擦过范围和击中速度损失。玩家 `Combat → 受击反应倍率`、敌人 `Training → Profile → tactics → 受击反应倍率` 各有三个可在检查器修改的倍率，射击与附带近战共用对应倍率；字段提示解释公式和关闭方式，见 [命中效果与倍率](docs/gameplay/COMBAT.md#命中压制与击中减速2026-10-24)。

## 打开工程

1. 使用本工程已验证的 Godot 4.7.2 标准版。
2. 在 Godot 项目管理器中导入 `movement_demo/project.godot`。
3. 等待资源和插件首次导入完成，按 F5 从第1关开始；关闭入场说明后游玩。打完本关全部波次后，点击按钮依次进入下一关。原 `scenes/main.tscn` 功能演示仍可单独按 F6 运行。

所需的 Dialogue Manager、Phantom Camera 和 Godot AI 插件源码及各自许可证随工程保存。Godot 可执行程序、导入缓存和临时文件不纳入仓库。
