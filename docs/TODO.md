# Demo 当前进度与待办

更新：2026-10-09。当前敌人结构、配置及验证入口见 [敌人模块化 AI](enemy-ai.md)。此页替代此前重复的历史交接记录。

## 已实现

- 玩家和 AI 的近战命中减速：默认0.5秒内保留50%自主移动速度，连续命中刷新、不叠乘，击退外力独立。减速／击退统一在武器资源的近战参数配置，玩家入口仍为 WeaponSlots，敌人仍为 Weapon，见 [近战说明](gameplay/MELEE.md)。

- 相机视野跟随槽内武器资源配置，切枪平滑过渡；仅明确标记的天花板／装饰物遮挡角色时渐变透明，纯视觉模型也可使用，现有高、低掩体保持不透明。主场景已加入天花板和悬挂方块试玩区，保留真实碰撞和原地面锚点跟随，见 [相机说明](gameplay/CAMERA.md)。

- 玩家医疗包：Health 下独立配置数量、回血效果和两秒使用时间；松开动作键后 H 立即使用，无需等待惯性停稳，任何新动作输入或有效受击打断且不扣包。头顶医疗十字／圆环、右下武器栏库存显示，沿用原生命结算和死亡重开，见 [医疗包](gameplay/PLAYER_HEALTH.md)。

- 补齐玩家与敌人的蹲起、蹲姿战斗、翻越下落／落地动作接口，跟随真实身体与战斗进度；WeaponData 可配置武器模型，角色 Presentation 指定手部挂点，空素材使用方块占位，切槽／卸装／复位同步。示例扩展为23种表现，见 [素材接入说明](gameplay/PRESENTATION.md)。

- 修复敌人低墙翻越入口与重烘焙导航边缘的偏差：有限范围选取同侧可达入口，再验证身体空间、完整翻越与严格路径；低墙近战快跑必须真实可步行，避免把翻越连接误作步行路线，沿用原 Utility 自主选择。

- 修复玩家翻越上升阶段受近战命中后误被抛出战斗区域、导致敌人复位：中断清除轨迹合成速度，保留伤害、无敌规则和真实击退；新增实际近战命中与正常离场对照回归，见 [移动与姿态](gameplay/MOVEMENT.md)。

- 玩家、敌人（含冲刺）、NPC 和掩体的可选模型与动画接口，以及双方真实子弹命中特效接口。默认留空保持原演示，见 [美术接入](gameplay/PRESENTATION.md)。

- 玩家移动、耐力、生命与战斗重开、对话、主副武器槽、实际弹道、弹匣与共享备弹。
- 半身掩体与角色姿态：角色站高统一1.75米，C切换可见胶囊蹲姿，按当前方向辅助起身、空格翻越；敌人以原Utility选择低墙蹲藏、同点起身和翻越路线。玩家蹲姿精度加0.25，双方脚步默认蹲行×0.5／快速×2；近距准确情报与原模糊提示分开，低墙点压制通过可调评分偏好参与决策。说明与验收见 [半身掩体实施记录](superpowers/plans/2026-10-08-half-cover-posture-vault.md)。
- 玩家 V 近战：仅战斗区内可用，当前枪械配置伤害与体力消耗、最近单目标、敌人准度清零与物理击退、短暂剑光和可选动画；执行位于现有 Combat。见 [近战说明](gameplay/MELEE.md)。
- 远程敌人近战：现有接敌行为提供近战推开方案，原 Utility 选择，独立敌人控制器与身体执行；挥击不单独装配为默认／战术行为。玩家受击准度清零及物理击退，含动画与剑光接口。近战兵的动作装配维持原状。
- 敌人执行接口整理：行为查询近战移动许可，身体统一检查基础能力冲突，表现读取独立快照；两种压制的环境推断距离归入 Selection。三层装配与评分职责保持原状。
- 玩家开始换弹时锁定快慢模式；敌人固定换弹耗时，换弹期间限制快速移动。见 [AMMO.md](gameplay/AMMO.md)。
- 移动／枪声事件、隔墙听觉衰减及 Debug 总开关。见 [HEARING.md](gameplay/HEARING.md)。
- 敌人身体执行、兵种与训练资源、独立动作库、共享记忆／射击／空间查询和通用 Utility 决策；训练检查器按兵种生成战术勾选项。
- 接敌、搜索、躲藏、攻击占位、两类压制、掩护撤离与换弹方案的共同决策。当前自动回归不能代替实机手感确认。
- 场景交互物基础：抽象交互物节点、可装配效果管线、门禁卡／酒杯／终端／唱片机实例、门禁通道与 Debug 状态面板。见 [INTERACTION.md](gameplay/INTERACTION.md)。
- 无提示搜索补强：缺少方向或预测失败时调查最后目击位置；覆盖复用实际视角、感知距离和遮挡，保留墙后未调查区域。原提示参数与有限搜索范围保持，见 [失视调查](enemy-ai.md#失视后的调查与搜索覆盖)。
- 近战兵可训练解锁掩体接近与短程突进；观察玩家换弹后形成短时接近机会。沿用原兵种／训练／Utility、预算化空间查询与基础挥击，见 [近战战术](gameplay/MELEE.md#近战兵的掩体接近与突进)。
- 掩体绕出连续性：已开始的有效绕出与观察按原路段时限完成，目击期限仍限制新推进；试玩继续关注不同长度路线、玩家离开和动态封堵时的接续。

- 近战掩体升级：基础躲藏支持近战，掩体接近自动包含它；按实际路径选择出口、近似等价时换侧，绕出重新目击后有限奔跑接敌。持续试玩受压避险与进攻的平衡、长掩体和单出口地图，见 [近战战术](gameplay/MELEE.md#近战兵的掩体接近与突进)。

- 失视接敌追查：原搜索动作内增加短时快速追查、先确认目击点再沿方向调查、优先检查邻近掩体出口，线索变旧后恢复区域搜索。继续试玩近战／远程的追查速度、转角接续和多次扑空的节奏；关注完整AI决策P99在16毫秒门槛附近的波动，见 [敌人搜索](enemy-ai.md#失视后的调查与搜索覆盖)和[验证记录](enemy-tests.md#当前回归)。

- 接敌后持续警戒：真实目击后搜索不再因总时限或单轮覆盖完成退出，按已知区域反复核实；保留短段超时、卡住换路及真实复位。继续试玩长期失视的重复搜索节奏，见 [搜索规则](enemy-ai.md#失视后的调查与搜索覆盖)。
