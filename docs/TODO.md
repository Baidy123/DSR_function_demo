# Demo 当前进度与待办

更新：2026-10-07。当前敌人结构、配置及验证入口见 [敌人模块化 AI](enemy-ai.md)。此页替代此前重复的历史交接记录。

## 已实现

- 玩家、敌人（含冲刺）、NPC 和掩体的可选模型与动画接口，以及双方真实子弹命中特效接口。默认留空保持原演示，见 [美术接入](gameplay/PRESENTATION.md)。

- 玩家移动、耐力、生命与战斗重开、对话、主副武器槽、实际弹道、弹匣与共享备弹。
- 玩家 V 近战：仅战斗区内可用，当前枪械配置伤害与体力消耗、最近单目标、敌人准度清零与物理击退、短暂剑光和可选动画；执行位于现有 Combat。见 [近战说明](gameplay/MELEE.md)。
- 远程敌人近战：现有接敌行为提供近战推开方案，原 Utility 选择，独立敌人控制器与身体执行；挥击不单独装配为默认／战术行为。玩家受击准度清零及物理击退，含动画与剑光接口。近战兵的动作装配维持原状。
- 敌人执行接口整理：行为查询近战移动许可，身体统一检查基础能力冲突，表现读取独立快照；两种压制的环境推断距离归入 Selection。三层装配与评分职责保持原状。
- 玩家开始换弹时锁定快慢模式；敌人固定换弹耗时，换弹期间限制快速移动。见 [AMMO.md](gameplay/AMMO.md)。
- 移动／枪声事件、隔墙听觉衰减及 Debug 总开关。见 [HEARING.md](gameplay/HEARING.md)。
- 敌人身体执行、兵种与训练资源、独立动作库、共享记忆／射击／空间查询和通用 Utility 决策；训练检查器按兵种生成战术勾选项。
- 接敌、搜索、躲藏、攻击占位、两类压制、掩护撤离与换弹方案的共同决策。当前自动回归不能代替实机手感确认。
- 场景交互物基础：抽象交互物节点、可装配效果管线、门禁卡／酒杯／终端／唱片机实例、门禁通道与 Debug 状态面板。见 [INTERACTION.md](gameplay/INTERACTION.md)。
- 无提示搜索补强：缺少方向或预测失败时调查最后目击位置；覆盖复用实际视角、感知距离和遮挡，保留墙后未调查区域。原提示参数与有限搜索范围保持，见 [失视调查](enemy-ai.md#失视后的调查与搜索覆盖)。
- 近战兵可训练解锁掩体接近与短程突进；观察玩家换弹后形成短时接近机会。沿用原兵种／训练／Utility、预算化空间查询与基础挥击，见 [近战战术](gameplay/MELEE.md#近战兵的掩体接近与突进)。
- 掩体绕出连续性：已开始的有效绕出与观察按原路段时限完成，目击期限仍限制新推进；试玩继续关注不同长度路线、玩家离开和动态封堵时的接续。

- 近战掩体升级：基础躲藏支持近战，掩体接近自动包含它；按实际路径选择出口、近似等价时换侧，绕出重新目击后有限奔跑接敌。持续试玩受压避险与进攻的平衡、长掩体和单出口地图，见 [近战战术](gameplay/MELEE.md#近战兵的掩体接近与突进)。
