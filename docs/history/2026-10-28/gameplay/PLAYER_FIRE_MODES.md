# 武器配置归属与单发／自动

2026-10-25 追加 **霰弹**：仍通过原 **Fire Mode** 下拉选择，编号为 3，原单发 0／自动 1／近战 2 不变。半自动每次有效按下发射一组弹丸，按住不连发；调大原 `Shot Interval` 可模拟泵动节奏。只在此模式显示 **Shotgun** 参数，切回原模式恢复旧参数且保留霰弹配置。详见[霰弹说明](../../../gameplay/SHOTGUN.md)。以下单弹自动射击规则继续有效。

用户确认按住左键持续开火，且每把武器可配置单发或自动。

- Equipment是玩家武器配置的唯一来源。Combat保留当前装备引用供运行使用，去掉检查器中的重复Weapon配置；combat.tscn统一当前v3脚本并移除默认武器。
- WeaponData新增FireMode，默认单发；自动时按住左键按shot_interval发射。沿用右键瞄准、精度惩罚、实际射线和伤害。
- 只接受未被UI消费的按下事件；松键停止。取消瞄准、离开战斗区域、对话、死亡、换枪清理待发与按住状态，需重新扣扳机，避免自动恢复时误射。
- 自动每个物理帧至多发一枪，长帧不补发弹雨；冷却持续沿用，切枪不能绕过射速。
- 翻越占用期间不执行射击，新点击直接忽略且落地不补发。自动武器仅能保留翻越前已通过未处理输入形成的 `fire_held`；松键、取消瞄准、换枪、换弹等原规则照常清除，不能因鼠标仍按住就重建扳机。解除旧目标锁定不改变扳机或基础准度，安全落地后按原冷却继续判断。
- 槽位展开武器时按同级Combat的Aim Mode过滤参数；Enemy和直接打开资源原规则保持。

## 在编辑器中使用

1. 打开 `scenes/main.tscn`，选中 `Player/Equipment`，展开 `Primary Weapon` 或 `Secondary Weapon`。
2. 在资源“基本信息”中将 `Fire Mode` 设为“自动”；“单发”仍是一按一枪。现有资源保持默认单发。
3. `Shot Interval` 是每枪间隔，例如0.2秒约每秒5枪。进入战斗区，按住右键瞄准，再按住左键验证连发；松开左键停火。
4. 玩家瞄准算法仍在 `Player/Combat > Aim Mode` 选择。槽位内只显示对应的概率或角度参数。

新模式不改变敌人的扳机决策：敌人已由AI按冷却逐枪调用 `try_fire()`，可以使用自动武器。普通射击的连射／停顿、出口压制每侧随机2～5枪仍归AI控制，本步不按Fire Mode区分敌人节奏。

## 代码与验证

- `scripts/weapons/weapon_data.gd` 保存每把枪的FireMode；`scripts/player/player_combat_v3.gd` 接收未处理的按下事件，记录扳机，逐帧复用原shoot流程。冷却接近零时消除浮点尾差，避免0.2秒在60Hz下多等一帧。
- `scenes/player/combat.tscn` 统一v3并移除默认武器。检查器插件从Equipment读取同级Combat模式，原资源编辑及撤销／重做仍有效。
- 自动射击21项、武器槽27项、玩家两种模式及散布／移动惩罚68项、敌人武器21项，共137项运行检查；实际检查器26项断言。新配置入口与自动射击测试先失败后通过，固定60Hz冷却测试亦先复现再修正。
- Main实际鼠标输入：自动按住0.75秒开火4次，松键停止；单发按住同样时间仅1枪。运行日志无本次错误或警告，游戏已停止，手感待用户试玩。
