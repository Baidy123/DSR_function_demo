# 敌人普通枪中心概率

敌人普通枪使用中心概率决定本次射线是否沿当前枪口方向发出，**不是直接抽取“玩家是否受伤”**。霰弹走独立的多弹丸图样分支，见[霰弹](SHOTGUN.md)。旧说明与历史验证见[历史记录](../history/2026-10-28/gameplay/ENEMY_PROBABILITY.md)。

## 参数与结果

在敌人 **Shooting → Weapon → 瞄准与散布 → 概率模式（百分比）** 配置普通枪：

| 保存字段 | 脚本默认值 | 含义 |
| --- | --- | --- |
| `initial_accuracy` | 0.5 | 初始中心概率50% |
| `shot_accuracy_penalty` | 0.25 | 每枪结束扣25个百分点 |
| `minimum_accuracy` | 0.1 | 仅射击惩罚的概率下限10%，不抬高其他原因造成的更低值 |
| `accuracy_recovery_delay` | 0.6秒 | 损失后的恢复等待 |
| `stabilize_seconds` | 2秒 | 敌人从初始概率恢复到100%的时间，不含等待 |

`stabilize_seconds` 位于同一大组的“敌人恢复（原算法）”；表中是资源类默认值，具体武器保存值优先。初始概率为100%时，恢复跨度按0到100%处理，避免受击后无法恢复。目标跟踪、移动、换弹、受击和压制仍按各自规则影响实时精度。

中心抽样成功时射线沿当前 `aim_direction`；失败时围绕它取8°～20°偏角。之后仍查询第一处物理碰撞：墙可以挡住中心射线，偏离射线也可能擦中目标。有限枪口跟转速度会造成瞄准滞后，不能把中心概率当作最终命中率或爆头率。

## 使用与结构

**Training → Profile → Tactics → Fire Stability Target** 是AI愿意等稳枪的目标值，默认0.7；它不替换武器的当前精度，也不保证每枪到达该值。反应、点射、弹药、射程、视线与屏外机会共同决定实际开火。配置总览见[敌人武器](ENEMY_WEAPON.md)。

实现沿 `WeaponData.get_aim_settings(false)`、敌人身体精度更新和 `_random_shot_direction()` 执行；普通枪不读取玩家的散布模式开关、收敛公式或25°免罚半角。检查器扩展只调整字段呈现，不另建一套概率状态。

调参时同时观察实时中心概率、枪口方向、实际碰撞和开火次数。概率专项不能替代遮挡与实射验证；历史通过次数只代表当时夹具。验证入口和未解决失败见[敌人测试](../enemy-tests.md)。
