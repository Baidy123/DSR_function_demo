# 玩家移动、耐力与翻越

玩家移动由 `scripts/player/player.gd` 执行，场景为 `scenes/player/player.tscn`。相机独立放置，接入方式见[相机](CAMERA.md)。移动参数在 Player 根节点保存，不放进武器资源。

## 操作与转向

- **W / A / S / D** 按画面方向输入；斜向归一化，不增加速度。
- 无锁定时先转向输入方向，再按加速度移动；松键按减速度停下，会有残余惯性，不是立即停止。
- 有锁定时保持瞄准目标并执行锁定移动，速度受当前武器倍率等状态限制；鼠标选敌后的平滑转身由 Combat 管理。
- **Shift** 请求奔跑，**C** 切换蹲站，**空格** 请求翻越；对话和死亡按对应状态限制动作。

项目开启 `physics/common/physics_interpolation`：移动、碰撞和战斗仍按物理帧更新，高帧率画面在相邻物理状态间插值。它改善显示连续性，不改变移动速度、加减速或输入规则；区域复位沿原流程清除插值历史。

## 移动与耐力参数

| Player 检查器字段 | 含义／脚本默认值 |
| --- | --- |
| Move Speed | 基础行走速度，3 米/秒 |
| Turn Speed Degrees | 普通移动转向速度，720°/秒；鼠标选敌转速另在 Combat |
| Acceleration Time / Deceleration Time | 加速／减速时间，0.3／0.2秒 |
| Sprint Speed Multiplier | 奔跑倍率，2 |
| Sprint Duration | 满耐力连续奔跑时间，5秒 |
| Stamina Recovery Duration / Delay | 空到满的恢复时间／停止消耗后的等待 |
| Crouch Move Multiplier | 蹲行倍率，0.5 |
| 姿态与翻越分组 | 身高、观察点、枪口高度、姿态过渡、翻越时长与接触推力 |
| 移动声音分组 | 行走半径、奔跑／蹲行倍率、发声间隔与 NoiseData |

这些是脚本默认值；场景覆盖值优先。枪械锁定慢走、受击减速、近战击退和翻越外力沿各自接口作用于身体。

## 奔跑与耐力

耐力为同一份 0～100 状态，奔跑与成功发起的近战共同消耗。停止消耗后经过恢复等待再回复；未耗尽可再次奔跑，耗尽后必须回满。一直按住 Shift 时，恢复满后可再次请求奔跑。

体力根据实际可通行的自主奔跑结算。正面顶墙或卡在墙角会退出奔跑、清掉储存的奔跑惯性并允许恢复；沿墙实际移动仍消耗体力。侧向击退不算自主奔跑。近战只检查本次消耗是否足够，不需要先回满。

左下角状态条只读取身体耐力，不保存第二套数值。声音与战斗使用碰撞后确认的移动／奔跑状态，见[听觉](HEARING.md)。

## 蹲姿、掩体与翻越

玩家按 **C** 切换手动蹲下／站起，蹲行仍使用 WASD。开阔处和背向矮墙可以保持蹲姿瞄准；只有当前瞄准方向被可利用的矮墙挡住时，右键才临时请求站起，松开右键或转离该墙后恢复手动蹲姿。手动选择站起会清除回蹲意图。头顶没有完整站立空间时保留实际姿态，不能穿过低顶。

右键自动起身期间按一次 **C**，表示改为手动站立：随后松开右键保持站立，再按一次 **C** 才正常蹲下。不按 C 时仍按默认规则松开右键回蹲；长按 C 的键盘重复事件不会连续切换姿态。

按 **Space** 翻越附近标记为可翻越的低掩体：有方向输入时按输入方向寻找墙面，静止时按当前朝向。预检覆盖入口、墙厚、整段胶囊通道和另一侧的地面及站立空间；失败不消耗弹药、体力或攻击冷却。执行中逐帧进行真实碰撞，动态受阻或近战推力会取消预定路径并安全下落，落地前继续占用动作，不能在墙顶提前开火。普通方向输入不覆盖空中轨迹。

翻越范围覆盖半身掩体整段墙面及两端。移除旧的墙端“身体半径＋3厘米”禁区，身体可以部分伸出开放的墙端，仍按真实位置检查完整胶囊、抬升通道和落点；端点射线保留1毫米的浮点容差。贴着其他墙体、低顶或没有安全落点的部分仍不能翻越。玩家与敌人共用这项几何判断，AI 的原生翻越连接也分布到墙面两端；重启运行即可生效，无需为此重新烘焙导航。

翻越接触推开：玩家翻越时接触墙对面的敌人，会沿越墙方向施加一次水平外力，默认1米、0.25秒，不造成伤害或触发受击、准度打断与减速。每次翻越对同一敌人最多推一次；外力期间仅限制敌人朝推力反方向的自主接近，侧移和同向移动仍正常。参数为当前试玩默认值，可在 Player 的 `Vault Push Distance / Vault Push Seconds` 调整。

玩家预检可以排除明确支持身体推力的活体敌人，因此落点已有人也能起跳；查询本身不推人，真实接触后才施力。静态实体、不可推动的目标、低顶、地面与完整胶囊通道仍参与预检；敌人原执行预检和通用几何查询默认规则不变。推力通过敌人原身体碰撞移动推进，不能穿墙。敌人被墙堵住时，玩家在墙顶停滞至少0.3秒且不短于推力时长后，尝试原轨迹的另一个合法端点，实际落地才结束翻越；两端均无空间时继续保持动作占用。

翻越期间禁止射击、近战和换弹推进，但仍受伤；保留原切枪能力。落地沿当前观察方向重新索敌，不恢复旧目标牵引，按手动姿态恢复，仍按右键也可以继续蹲瞄。暂停冻结轨迹；对话取消轨迹并安全落地；死亡沿原暂停／重开流程处理。镜头使用 `get_camera_ground_height()` 保持地面高度，避免跟着跨墙过程上下跳动。

翻越首次中断时清除轨迹产生的合成速度，再交给重力与独立近战击退推进；后续重复中断不清除已积累的下落速度。上升段挨打不会把翻越速度当成向上的物理冲量。伤害、无敌和水平击退仍按原规则执行，真正离开战斗区域仍会触发该区域的敌人复位。

玩家站姿固定 **1.75 米**；当前胶囊半径沿场景原值。站／蹲外观和实体胶囊逐实例独立更新，根节点保留脚底位置，正面标记、观察点和枪口跟随实际姿态。蹲姿网格模板为 `resources/models/crouch_capsule.tres`，实例保留旧材质；`Player/Visual/Body` 等路径不变。

| Player 检查器参数 | 默认值 | 用途 |
| --- | --- | --- |
| Crouch Height | 1.0 米 | 完成蹲姿时的身体高度 |
| Posture Transition Seconds | 0.2 秒 | 站蹲连续过渡 |
| Crouch Move Multiplier | 0.5 | 蹲行相对普通移动速度；蹲姿不奔跑、不额外耗耐力 |
| Standing / Crouching Eye Height | 1.55 / 0.88 米 | 实际观察点，影响可见性 |
| Standing / Crouching Muzzle Height | 1.30 / 0.72 米 | 实际射线起点，枪口被挡仍会打墙 |
| Vault Duration | 0.8 秒 | 翻越基准时长，几何查询会限制极快的长轨迹 |
| Vault Push Distance / Seconds | 1.0 米 / 0.25 秒 | 翻越接触敌人时的水平推开距离与时长；实际位移受碰撞限制 |
| Cover Interaction Distance | 1.5 米 | 玩家查找低掩体的距离 |

1.75 米站高为用户要求；表中姿态、速度、时间和点位为当前可调试玩初值。移动声音配置见 [听觉](HEARING.md)，蹲姿精度见 [射击](COMBAT.md)。蹲姿 V 先验证资格、体力和起身空间，完成起身后再次验证才扣一次体力并挥击；等待期间切枪、翻越、离场或对话取消请求。

身体执行仍在 `scripts/player/player.gd`；Combat 执行枪械、近战和换弹。`character_geometry.gd`／`low_cover_geometry.gd` 只读查询空间，不控制身体或战斗。`get_eye_position()`、`get_muzzle_position()`、`get_torso_position()`、`get_visibility_points()`、`get_body_height()`、`is_crouching()`、`is_vaulting()` 向原感知和表现提供实际身体信息；`get_posture_*_position()` 仅用于假定姿态查询。

翻越接触由 `player.gd` 消费真实碰撞并调用敌人 `can_receive_body_push()`／`receive_body_push(direction, distance, duration)`；敌人继续在 `enemy_actor.gd` 的原外力和移动入口执行，AI 不拥有推力进度。几何接口末尾的可选 `ignore_pushable_characters` 默认关闭，只用于玩家这次预检，不改变原规划的隐藏信息边界。

动作素材读取 `get_posture_presentation_state()` 的独立快照，按真实高度播放蹲起，翻越轨迹与物理下落分开表现；活体完成翻越时发出一次 `vault_landed`，死亡／复位不伪造落地。玩家原手动姿态、右键辅助起身、落地朝向与攻击许可仍由身体和 Combat 决定。武器模型跟随指定手部挂点或实际枪口高度，不改变射线起点。配置与空素材回退见 [美术接入](PRESENTATION.md)。

## 治疗与受击移动

医疗包 **H** 在松开方向和其他动作键后即可开始，不要求移动速度完全归零；医疗组件不清除身体惯性，也不修改加减速，残余滑行按原逻辑停止。治疗中重新输入移动或受到有效攻击仍会打断；未启用移动治疗或0.75米／秒的医疗慢走，见 [医疗包](PLAYER_HEALTH.md)。

近战命中减速由攻击者武器配置，默认持续0.5秒、保留50%自主移动速度。玩家的普通、奔跑、蹲行、锁定及挥击中移动均先取原状态速度再乘该比例，已有速度受限；敌人经原身体移动接口执行同一规则。击退、重力独立，翻越受击仍按原中断／下落规则处理。暂停冻结、对话／死亡／复位清理；参数位置与连续命中规则见 [近战命中效果](MELEE.md#命中减速与击退2026-10-09)。

## 接口与验证

`player.gd` 独占实际移动、碰撞、耐力和姿态；Combat 在移动前后通过 `begin_frame()`／`end_frame()` 处理锁定与实际位移精度损失。`get_camera_ground_height()` 为相机提供地面锚点，翻越抬升不改变它；`try_consume_stamina()` 供近战使用。

手感参数改变后重点验证转向、停步惯性、顶墙、锁定移动、蹲站空间与翻越落点。已有 `sprint_test -- --walls` 专门核对实体墙；`player_half_cover_test` 覆盖蹲站、身体可见点与翻越；`player_vault_hit_reset_test` 覆盖真实近战受击，追加 `-- --blockers` 核对占位、背墙、暂停和每目标一次推力。旧默认移动夹具含早期瞬时速度假设，不能据此回退现有加减速；历史结果与边界见[测试说明](../testing.md)。
