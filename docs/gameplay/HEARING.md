# 声音与敌人听觉

当前声音系统传递AI听觉事件与调试范围，不负责播放实际音频。`NoiseData.audio_stream` 是预留字段。旧接入过程与测试记录见[历史记录](../history/2026-10-28/gameplay/HEARING.md)。

## 配置接口

| 声源或接收方 | 配置入口 | 脚本默认值 |
| --- | --- | --- |
| 玩家移动 | Player → 移动声音 | 半径3米、冲刺倍率2、蹲姿倍率0.5、事件间隔0.4秒 |
| 敌人移动 | 敌人根节点 → 移动声音 | 半径3米、快速移动倍率2、蹲姿倍率0.5、间隔0.4秒 |
| 枪声 | Weapon → Shot Noise / Shot Noise Radius | 半径14米；事件资源与半径分别配置 |
| 遮挡衰减 | NoiseData → Occluded Range Multiplier | 0.4 |
| 敌人听觉资格 | Training → Profile → Perception → Hearing Enabled | 默认开启；仍受行为装配与实际感知规则限制 |

这些是脚本默认值，场景和资源保存值优先。声音资源为空或半径为0时不发事件。半径属于角色或武器，`NoiseData` 保存公共事件与遮挡设置；旧独立冲刺／快速半径通过兼容入口转换，不应再增加第二处半径来源。

只有实际水平移动才产生脚步声；原地按方向、翻越过程不会按普通走路循环发脚步。蹲姿过渡按身体当前过渡量改变移动声音范围。枪声不乘蹲姿倍率；被冷却或其他资格拒绝的射击不发枪声。

## 敌人如何使用声音

听觉保存事件发生时的位置和时间，不持续读取发声者隐藏后的实时坐标。当前敌人感知只接受玩家来源的相应声音，不把敌人的脚步和枪声当作玩家线索。能听见仍不等于能看见或开火，调查必须具备搜索行为及训练资格。

从未建立交战警戒的普通声音调查可以按原条件结束并恢复巡逻。已经取得本人／合法共享目击，或收到后续波出生搜索提示的敌人，会保持交战搜索；声音不能把真实目击年龄刷新成现在。团队共享与个人搜索边界见[敌人AI](../enemy-ai.md)。

遮挡以环境射线判断，再将可听半径乘遮挡倍率。这是简化的范围模型，不模拟绕墙传播、衍射或多段房间声学。

## 调试、结构与验证

开启项目 Debug 总开关和声音范围显示，可观察玩家蓝色、敌人橙色范围；实线外圈表示无遮挡半径，虚线内圈表示遮挡后的半径，短暂显示约0.4秒。圆圈是范围参考，不是实际声音路径。Debug 总开关还包含玩家无敌等调试行为，验证伤害时须核对其状态。

事件资源位于 `resources/noise/`，发送入口为 `scripts/systems/noise_data.gd::emit_from(source, radius)`，移动声由双方身体发送，枪声由实际武器发射发送；敌人接收归 `enemy_perception.gd`，显示归 `scripts/debug/noise_debug.gd`。所有路径相对 `movement_demo/`。

相关测试为 `hearing_test`、`movement_noise_modes_test`、`noise_debug_test`，并需结合搜索和换弹实跑。显示正确不能证明AI已经调查；事件被接收也不能证明路线可达。测试运行入口、旧声音断言失败与复验边界见[敌人测试](../enemy-tests.md)。
