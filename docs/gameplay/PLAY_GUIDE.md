# 游玩操作与五关流程

打开 `movement_demo/project.godot` 后按 **F5**，或直接运行工程，即从酒馆开始。本次运行首次进入酒馆时先显示黑场，淡入后镜头沿玩家朝向平移到任务 NPC A，停留约1秒，再回到玩家最新画面；镜头期间玩家和场景暂停。演示完成后玩家恢复操作，之后返回酒馆不会再次播放；重新启动游戏视为新一次运行。先与 A 对话接取任务，再到门口传送门按 **E** 进入第1关。酒馆、进入关卡和死亡重开均不自动弹出操作说明；需要时按 **Esc → 设置 → 操作说明** 查看。正文可用滚轮滚动，底部 **返回设置** 按钮或 Esc 返回设置，继续保持暂停。界面使用原生锚点随视口铺开，首次全屏与窗口缩放无需手动刷新尺寸。

完整配置入口见[项目总览](../../README.md)，专项说明见[文档导航](../README.md)。

正在对话或逛商店时触发普通演出，会等当前交互结束后播放；死亡立即中断。清场后仍可走到返程门返回酒馆。传送失败不会提前记录完成、发奖或消费玩家快照，普通门会恢复操作并允许重试；死亡／结果界面保留原重试按钮。搭建这些流程见[导演接线教程](SCENE_DIRECTOR.md)。

## 玩家操作

| 操作 | 作用 |
| --- | --- |
| W / A / S / D | 按画面方向移动；角色需要转身，并有加减速 |
| 按住 Shift | 奔跑并消耗体力；耗尽后需回满才能再次奔跑 |
| C | 切换蹲下／站起；蹲行更慢、脚步更轻、最大散布更小 |
| 空格 | 翻越面前半身掩体，需要安全通道与落点；途中不能攻击，仍会受伤 |
| 按住鼠标右键 | 按角色朝向自动锁定范围内、方向合适且可见的敌人，并持续跟踪 |
| 右键按住时拨动鼠标（辅助开启） | 无目标时朝敌人相对玩家的屏幕方向选敌；有目标时按两目标相对屏幕方向换锁。击杀后不用松开右键；近邻轻拨、远处多拨一点，连续换锁无需停顿 |
| 瞄准时按鼠标左键 | 开火；单发与霰弹每次点击一枪，自动武器可按住连射 |
| 1 / 2 或鼠标滚轮 | 选择主／副武器；右下角显示弹匣和共享备弹 |
| R | 主动换弹，空匣不会自动装填 |
| V | 向当前朝向近战；瞄准时使用瞄准方向，消耗当前武器配置的体力 |
| H | 使用医疗包；先松开动作键，治疗中输入动作或受击会打断，中断不消耗 |
| Esc | 打开暂停菜单；子页返回上一级，菜单首页再次按 Esc 恢复游戏 |

蹲在矮墙后向墙外瞄准时会临时起身，松开右键恢复手动蹲姿；此时按 C 可改为保持站立。锁定不保证命中：墙体会挡子弹，观察点能看见也不代表枪口没有被挡住。

## 暂停与设置

暂停菜单提供 **继续游戏、设置、退出游戏**。暂停时冻结玩家、敌人及随世界处理的动作和计时，显示鼠标；设置和操作说明之间切换保持暂停。菜单首页选择继续游戏或按 Esc 才恢复。退出游戏需确认，当前进度仍仅为本次运行内的状态，没有新增磁盘存档。

设置页分为 **基础设置** 和 **战斗设置**。基础设置包含窗口模式、分辨率和垂直同步；战斗设置包含鼠标辅助锁定和换锁灵敏度（低／标准／高）。分辨率同时更新窗口尺寸和项目的2D虚拟画布：窗口模式会直接改变外框与菜单/界面坐标，全屏模式仍由显示器输出分辨率决定画面像素，但2D画布按所选尺寸缩放。控件变化先显示“有未保存的更改”，必须点击 **保存设置** 才会应用并写入 `user://settings.cfg`；按返回或 Esc 会丢弃未保存改动。**恢复默认**只把控件恢复为待保存的默认值，仍需点击保存；从操作说明返回设置时保留待保存值。首次没有配置文件时显示“默认设置，尚未保存”。配置文件只保存用户偏好，不保存关卡、货币、装备或检查点，重新启动后仍会应用。窗口模式提供窗口和无边框全屏；支持独占全屏的平台额外提供独占档，macOS 不显示无法兑现的独占选项。保存失败时页面会提示“保存失败，设置未应用”，本次运行也不会改用未保存值。商店、对话、引导、演出、死亡或加载占用控制时不叠加打开暂停菜单；死亡与切场会撤下菜单，只释放菜单自身的暂停。按键映射和难度仍留待后续实现。

## 两种锁定模式

操作说明将锁定操作分为两种模式，两者都只锁定范围内且可见的敌人，锁定后持续跟踪：

- **模式一：方向键转向锁定（鼠标辅助关闭）。** 用 W / A / S / D 调整朝向，再按住右键，自动锁定朝向附近的敌人。需要换目标时松开右键、调整朝向，再重新瞄准；鼠标移动不参与选敌。
- **模式二：鼠标辅助锁定（默认）。** 保留方向键转向和自动锁定；右键持续按住时，无目标可朝敌人相对玩家的屏幕方向拨动选敌，有目标可按两目标相对屏幕方向拨动换锁。击杀后继续拨向下一人，无需松开右键重按，也无需把光标放在敌人身上。

在 **Esc → 设置 → 战斗设置 → 鼠标辅助锁定** 选择模式：关闭为模式一，开启为模式二；点击保存设置后生效。检查器中的 **Player → Combat → 目标切换 → Mouse Target Assist Enabled** 仍是场景默认值，玩家运行时会以已保存的用户设置覆盖该默认值。

鼠标辅助默认只搜索拨动方向左右各45°，该方向没有合格目标时保持原状态，不让角色空转。侧面或背后的可见敌人也可以切过去，但仍受屏幕、锁定距离和遮挡限制。辅助开启的右键瞄准期间，无论是否已有目标，鼠标都临时隐藏并捕获，不会被窗口边缘卡住；松开瞄准或打开暂停界面后恢复。鼠标选敌或换锁后角色平滑转向，转得越多、目标越远，跟枪损耗越大；转身中可以继续换目标，也可以立即开火，子弹沿当时朝向、按实时准度射出。“转向中”标记只表示下一目标，对准后才恢复普通准星及符合条件的爆头菱形。参数入口见[战斗说明](COMBAT.md#鼠标方向换锁2026-10-28)。

## 战斗与补给

停步、减少连续开火，让准星逐渐收拢后再射击。玩家移动、目标横向移动、开火、受击和近弹压制会干扰精度。**精度达到一定程度后，实际命中就有概率爆头；精度越高，爆头概率越大。**金色菱形出现后随概率升高收小，满精准时发光，实际命中必爆头；秒杀仍取决于武器和敌人防护。

**近战命中可让敌人短暂眩晕，提高对该敌人的爆头概率。**头顶星环表示眩晕尚未结束；爆头加成在首次枪击命中后消耗，打空不消耗，眩晕结束也会失效。利用掩体换弹和治疗，留意生命与体力；敌人会听声音、搜索和配合。

普通整匣换弹中不能开枪。非奔跑时开始较快，途中奔跑或切枪时，不到半程会取消；达到半程则保留50%，条件允许后自动续换。奔跑时按 R 开始较慢，但可边跑边换。启用逐发装填的武器保留已装入的子弹，可新按右键中断；具体进度看武器栏提示。

当携带弹药严格少于对应半匣、该弹种允许掉落且本区还有名额时，击杀敌人可得到最缺弹种的一包补给。靠近自动拾取到备弹，仍需 R 装填；每区地面最多两包，拾取后允许后续击杀再次掉落。具体武器、生命和医疗包数以各关保存配置及游戏界面为准。

## 过关与重生

五关都使用同一条闭环：清空全部波次后不弹“进入下一关”面板、不暂停游戏，出生点附近出现橙色返回传送门；按 **E** 回酒馆。回酒馆后门口传送门先保持锁定，必须再次与 A 交互，A 才会解锁下一关。随后走到门口按 **E** 进入下一关。第1关返回时还会写入任务 A 的交差字段，酒馆任务面板显示“已完成”；第5关返回后与 A 交互会显示五关完成，不再解锁新关卡。

任务面板包含五条主线任务“通关第1关”至“通关第5关”。A 解锁第 N 关时，第 N 关任务进入进行中；从该关返回酒馆后任务完成，下一关任务在下一次 A 对话前保持未接。因此任务状态会与实际关卡进度同步。

跨关保留生命、当前武器槽、两把武器资源、各自弹匣余弹、共享备弹、医疗包数量和货币。回酒馆时这些状态会先恢复到酒馆玩家，因此商店购买的急救包、弹药补给或武器会影响下一关。瞄准、换弹进度、受击减速等临时战斗状态不跨关。

每关返回后都能找蓝色“商店”NPC 打开货币商店。初始商品医疗包（40，库存+1，按 H 使用）、弹药补给（30，补满弹匣与备弹）、思维接入装置（500，购买后拥有）。急救包与弹药补给可重复购买；装置只可购买一次，购买后设置拥有旗标并隐藏。未解锁商品和已购买的一次性商品完全隐藏。五个主线任务各固定发放 100 货币，首次完成时发一次。商品目录与价格见[货币商店与任务奖励](REWARDS.md)。

暂停菜单没有手动重试或返回酒馆入口，**只有死亡后**的界面提供这两个选项，对应两个恢复点：

- **重新挑战当前关卡**：恢复进入本关时的状态，进关前买好的装备和补给保留。
- **返回酒馆**：恢复上一关完成、刚返回酒馆时的状态。这个恢复点更早，货币、装备、医疗包、商品旗标及购买记录一起回退，之后的消费和购买不保留。

恢复酒馆状态不等于返回上一关地图，也不撤销已完成关卡和对应任务奖励；回酒馆后仍由 A 解锁下一关。第1关尚未完成时没有通关返程恢复点，返回酒馆会保留当前任务接取情况，回到第1关可进入的初始状态。恢复点目前只在本次运行中保存，退出游戏后重置。

只有正常清场并经返回传送门离开时，才会更新酒馆检查点和下一场景使用的一次性跨关状态。若刷新点被玩家占用，需先让开，等后续波次出场并清空后才会出现返程门。原 `scenes/main.tscn` 保留为功能演示，仍可单独 F6 运行。

## 界面与维护入口

五关各自有一个 `LevelFlow` 实例（`scenes/ui/level_flow.tscn`），`level_number` 为1至5，并在 `return_portal_path` 指向本关 `TavernReturnPortal`。波次完成经导演授权后，由 LevelFlow 启用返程门，不暂停切场景。`QuestPortal` 读取 `GameState.available_level` 动态更新目标，向导演准备一次性玩家快照和 `level_entry_player_state`；`TavernReturnPortal` 准备 `completed_level`、玩家快照和酒馆检查点。引擎接受加载后才提交，`PlayerCampaignState` 只消费一次。商店的打开／关闭与暂停由导演安排，`ShopController` 执行购买。敌人、AI、波次完成判定与 Health 的死亡通知职责保持不变；死亡按钮意图由 SceneDirector 处理。

Debug 总开关开启后，右上角 Debug 栏出现可用的 **一键通关当前关** 按钮。它调用当前关卡 `SceneDirector.debug_complete_encounter()`，清理当前与尚未生成的波次并发出原 `encounter_completed`，因此仍只开放返程门，不直接跳关或跳过酒馆流程。重复点击不会重复完成。

原 `EnemyWaves` 入口按用户要求改名 `SceneDirector`，Wave/Squad 层级不变；总调度接收入场、波次完成与 `Health.died`，可统一处理暂停、结果和加载。该结果按钮与自动加载下一关是可复用的场景编排能力，当前五关没有启用“清场后按钮进入下一关”：本关完成仍只开放 `TavernReturnPortal`，返回酒馆并与 A 交互后才解锁下一关。`LevelFlow` 保留五关路径表与结果视图，当前接入只使用返程门流程。配置见[场景调度教程](SCENE_DIRECTOR.md)。

说明组件仍为 `scenes/ui/play_guide.tscn` 与 `scripts/ui/play_guide.gd`，正文保存在 `GUIDE_TEXT`，保留 `begin()/cancel()/finished` 接口。暂停菜单复用该场景，覆盖提示和返回按钮文字，关闭说明只返回设置。原 `LevelFlow/PlayGuide` 节点保留，导演入口的 `Guide Path` 默认留空；独立场景仍可显式绑定其他开场教程。原酒馆任务与剧情系统保持各自职责。
