# 五关游玩说明

打开 `movement_demo/project.godot` 后按 **F5**，或直接运行工程，即从第1关开始。无需逐个打开场景按 F6。每关入场会显示同一份 2D 游玩说明：阅读时暂停战斗，正文可用滚轮滚动，底部 **关闭 / 开始游玩** 按钮恢复游戏。界面使用原生锚点随视口铺开，首次全屏、窗口缩放和后续换关均无需手动刷新尺寸。

## 玩家操作

| 操作 | 作用 |
| --- | --- |
| W / A / S / D | 按画面方向移动；角色需要转身，并有加减速 |
| 按住 Shift | 奔跑并消耗体力；耗尽后需回满才能再次奔跑 |
| C | 切换蹲下／站起；蹲行更慢、脚步更轻、最大散布更小 |
| 空格 | 翻越面前半身掩体，需要安全通道与落点；途中不能攻击，仍会受伤 |
| 按住鼠标右键 | 按鼠标方向瞄准，并尝试自动锁定范围内、方向合适且可见的敌人 |
| 瞄准时按鼠标左键 | 开火；单发与霰弹每次点击一枪，自动武器可按住连射 |
| 1 / 2 或鼠标滚轮 | 选择主／副武器；右下角显示弹匣和共享备弹 |
| R | 主动换弹，空匣不会自动装填 |
| V | 向当前朝向近战；瞄准时使用瞄准方向，消耗当前武器配置的体力 |
| H | 使用医疗包；先松开动作键，治疗中输入动作或受击会打断，中断不消耗 |

蹲在矮墙后向墙外瞄准时会临时起身，松开右键恢复手动蹲姿；此时按 C 可改为保持站立。锁定不保证命中：墙体会挡子弹，观察点能看见也不代表枪口没有被挡住。

## 战斗与补给

停步、减少连续开火，让准星逐渐收拢后再射击。玩家移动、目标横向移动、开火、受击和近弹压制会干扰精度。最准时的金色菱形只表示获得概率爆头资格，效果由当前武器和敌人防护决定，不代表每枪必定爆头。利用掩体换弹和治疗，留意生命与体力；敌人会听声音、搜索和配合。

普通整匣换弹中不能开枪。非奔跑时开始较快，途中奔跑或切枪时，不到半程会取消；达到半程则保留50%，条件允许后自动续换。奔跑时按 R 开始较慢，但可边跑边换。启用逐发装填的武器保留已装入的子弹，可新按右键中断；具体进度看武器栏提示。

当携带弹药严格少于对应半匣、该弹种允许掉落且本区还有名额时，击杀敌人可得到最缺弹种的一包补给。靠近自动拾取到备弹，仍需 R 装填；每区地面最多两包，拾取后允许后续击杀再次掉落。具体武器、生命和医疗包数以各关保存配置及游戏界面为准。

## 过关与重开

清空本关全部敌人波次后，显示暂停的过关界面。**点击“进入第 N 关”才切关，不会自动跳转**。第5关完成后显示通关，可点击“从第1关重新开始”。若刷新点被玩家占用，需先让开，等后续波次出场并清空后才会过关。

死亡界面原按钮只重开当前关。换关和重开都重新读取该关保存的生命、武器、弹药与医疗包，不继承上一关的剩余状态；对话 GameState 继续遵循原生命周期。本功能不新增跨关存档。原 `scenes/main.tscn` 保留为功能演示，仍可单独 F6 运行。

## 维护入口

五关各自增加一个 `LevelFlow` 实例（`scenes/ui/level_flow.tscn`），`level_number` 为1至5；原 Player、Camera3D、EnemyWaves、根脚本和资源引用不变。`scripts/systems/level_flow.gd` 只监听原 `EnemyWaves.encounter_completed` 并在按钮点击后延迟切换场景，不改变敌人、AI、波次完成判定或 Health 的死亡重开实现。第五关显示通关；切换失败时保留重试按钮。

说明组件为 `scenes/ui/play_guide.tscn` 与 `scripts/ui/play_guide.gd`，文案保存在脚本 `GUIDE_TEXT`，修改操作时同步本文。组件只在显示期间持有暂停，关闭或卸载恢复先前状态；正文滚动，关闭按钮独立保留在底部。关卡衔接不是酒馆任务的 StageController，原任务与剧情系统保持各自职责。
