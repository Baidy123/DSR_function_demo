# 游玩操作与五关流程

打开 `movement_demo/project.godot` 后按 **F5**，或直接运行工程，即从酒馆开始。先与 A 对话接取任务，再到门口传送门按 **E** 进入第1关。第1关入场会显示同一份 2D 游玩说明：阅读时暂停战斗，正文可用滚轮滚动，底部 **关闭 / 开始游玩** 按钮恢复游戏。界面使用原生锚点随视口铺开，首次全屏与窗口缩放无需手动刷新尺寸。

完整配置入口见[项目总览](../../README.md)，专项说明见[文档导航](../README.md)。

## 玩家操作

| 操作 | 作用 |
| --- | --- |
| W / A / S / D | 按画面方向移动；角色需要转身，并有加减速 |
| 按住 Shift | 奔跑并消耗体力；耗尽后需回满才能再次奔跑 |
| C | 切换蹲下／站起；蹲行更慢、脚步更轻、最大散布更小 |
| 空格 | 翻越面前半身掩体，需要安全通道与落点；途中不能攻击，仍会受伤 |
| 按住鼠标右键 | 按角色朝向自动锁定范围内、方向合适且可见的敌人，并持续跟踪 |
| 右键按住时拨动鼠标（辅助开启） | 无目标时朝敌人相对玩家的屏幕方向选敌；有目标时按两目标相对屏幕方向换锁。击杀后不用松开右键；近邻轻拨、远处多拨一点，连续换锁无需停顿 |
| 瞄准时按鼠标左键 | 开火；单发与霰弹每次点击一枪，自动武器可按住连射 |
| 1 / 2 或鼠标滚轮 | 选择主／副武器；右下角显示弹匣和共享备弹 |
| R | 主动换弹，空匣不会自动装填 |
| V | 向当前朝向近战；瞄准时使用瞄准方向，消耗当前武器配置的体力 |
| H | 使用医疗包；先松开动作键，治疗中输入动作或受击会打断，中断不消耗 |

蹲在矮墙后向墙外瞄准时会临时起身，松开右键恢复手动蹲姿；此时按 C 可改为保持站立。锁定不保证命中：墙体会挡子弹，观察点能看见也不代表枪口没有被挡住。

## 两种锁定模式

开局说明将锁定操作分为两种模式，两者都只锁定范围内且可见的敌人，锁定后持续跟踪：

- **模式一：方向键转向锁定（鼠标辅助关闭）。** 用 W / A / S / D 调整朝向，再按住右键，自动锁定朝向附近的敌人。需要换目标时松开右键、调整朝向，再重新瞄准；鼠标移动不参与选敌。
- **模式二：鼠标辅助锁定（默认）。** 保留方向键转向和自动锁定；右键持续按住时，无目标可朝敌人相对玩家的屏幕方向拨动选敌，有目标可按两目标相对屏幕方向拨动换锁。击杀后继续拨向下一人，无需松开右键重按，也无需把光标放在敌人身上。

在 **Player → Combat → 目标切换 → Mouse Target Assist Enabled** 选择模式：关闭为模式一，开启为模式二。这是既有开关的操作说明，开局说明界面不新增模式选择控件。

鼠标辅助默认只搜索拨动方向左右各45°，该方向没有合格目标时保持原状态，不让角色空转。侧面或背后的可见敌人也可以切过去，但仍受屏幕、锁定距离和遮挡限制。辅助开启的右键瞄准期间，无论是否已有目标，鼠标都临时隐藏并捕获，不会被窗口边缘卡住；松开瞄准或打开暂停界面后恢复。鼠标选敌或换锁后角色平滑转向，转得越多、目标越远，跟枪损耗越大；转身中可以继续换目标，也可以立即开火，子弹沿当时朝向、按实时准度射出。“转向中”标记只表示下一目标，对准后才恢复普通准星及符合条件的爆头菱形。参数入口见[战斗说明](COMBAT.md#鼠标方向换锁2026-10-28)。

## 战斗与补给

停步、减少连续开火，让准星逐渐收拢后再射击。玩家移动、目标横向移动、开火、受击和近弹压制会干扰精度。**精度达到一定程度后，实际命中就有概率爆头；精度越高，爆头概率越大。**金色菱形出现后随概率升高收小，满精准时发光，实际命中必爆头；秒杀仍取决于武器和敌人防护。

**近战命中可让敌人短暂眩晕，提高对该敌人的爆头概率。**头顶星环表示眩晕尚未结束；爆头加成在首次枪击命中后消耗，打空不消耗，眩晕结束也会失效。利用掩体换弹和治疗，留意生命与体力；敌人会听声音、搜索和配合。

普通整匣换弹中不能开枪。非奔跑时开始较快，途中奔跑或切枪时，不到半程会取消；达到半程则保留50%，条件允许后自动续换。奔跑时按 R 开始较慢，但可边跑边换。启用逐发装填的武器保留已装入的子弹，可新按右键中断；具体进度看武器栏提示。

当携带弹药严格少于对应半匣、该弹种允许掉落且本区还有名额时，击杀敌人可得到最缺弹种的一包补给。靠近自动拾取到备弹，仍需 R 装填；每区地面最多两包，拾取后允许后续击杀再次掉落。具体武器、生命和医疗包数以各关保存配置及游戏界面为准。

## 过关与重开

五关都使用同一条闭环：清空全部波次后不弹“进入下一关”面板、不暂停游戏，出生点附近出现橙色返回传送门；按 **E** 回酒馆。回酒馆后门口传送门先保持锁定，必须再次与 A 交互，A 才会解锁下一关。随后走到门口按 **E** 进入下一关。第1关返回时还会写入任务 A 的交差字段，酒馆任务面板显示“已完成”；第5关返回后与 A 交互会显示五关完成，不再解锁新关卡。

任务面板包含五条主线任务“通关第1关”至“通关第5关”。A 解锁第 N 关时，第 N 关任务进入进行中；从该关返回酒馆后任务完成，下一关任务在下一次 A 对话前保持未接。因此任务状态会与实际关卡进度同步。

跨关保留生命、当前武器槽、两把武器资源、各自弹匣余弹、共享备弹和医疗包数量。回酒馆时这些状态会先恢复到酒馆玩家，因此“结算奖励”NPC 的急救包或弹药补给会影响下一关。瞄准、换弹进度、受击减速等临时战斗状态不跨关。

每关返回后都能找蓝色“结算奖励”NPC 领取本关三选一。五关各自记录领取状态：第1关领过不会关闭第2关，第2关领过不会影响第3～5关；同一关只能领取一次。每关按钮标题、说明、效果类型和数值都在奖励配置资源中独立调整，见[关卡奖励配置](REWARDS.md)。

死亡保持现有规则：不经过酒馆，原按钮只重开当前关；重开按该关保存的初始生命、武器、弹匣、备弹和医疗包恢复。只有正常清场并经返回传送门离开时，才生成下一场景使用的一次性跨关状态。若刷新点被玩家占用，需先让开，等后续波次出场并清空后才会出现返程门。原 `scenes/main.tscn` 保留为功能演示，仍可单独 F6 运行。

## 界面与维护入口

五关各自有一个 `LevelFlow` 实例（`scenes/ui/level_flow.tscn`），`level_number` 为1至5，并在 `return_portal_path` 指向本关 `TavernReturnPortal`。`scripts/systems/level_flow.gd` 接收 `SceneDirector.encounter_completed`，转交总调度完成生命周期，并在有返程门时只启用返程门、不暂停切场景。`QuestPortal` 读取 `GameState.available_level` 动态更新目标；`TavernReturnPortal` 写入 `completed_level`，并由 `PlayerCampaignState` 保存/恢复跨关玩家状态。敌人、AI、波次完成判定与 Health 的死亡重开职责保持不变。

Debug 总开关开启后，右上角 Debug 栏出现可用的 **一键通关当前关** 按钮。它调用当前关卡 `SceneDirector.debug_complete_encounter()`，清理当前与尚未生成的波次并发出原 `encounter_completed`，因此仍只开放返程门，不直接跳关或跳过酒馆流程。重复点击不会重复完成。

原 `EnemyWaves` 入口按用户要求改名 `SceneDirector`，Wave/Squad 层级不变；总调度接收入场、波次完成与 `Health.died`，可统一处理暂停、结果和加载。该结果按钮与自动加载下一关是可复用的场景编排能力，当前五关没有启用“清场后按钮进入下一关”：本关完成仍只开放 `TavernReturnPortal`，返回酒馆并与 A 交互后才解锁下一关。`LevelFlow` 保留五关路径表与结果视图，当前接入只使用返程门流程。配置见[场景调度教程](SCENE_DIRECTOR.md)。

临时说明组件仍为scenes/ui/play_guide.tscn与scripts/ui/play_guide.gd，正文保存在GUIDE_TEXT。它提供begin/cancel/finished，由总调度选择是否显示并持有暂停；关闭只报告完成。移除它或清空Guide Path即可省略，以后可换互动教程。正文滚动和底部关闭按钮保持。原酒馆任务与剧情系统仍保持各自职责。
