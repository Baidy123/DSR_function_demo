# 玩家与敌人近战

玩家近战、远程敌人的基础挥击与近战兵的专用武器已接入，双方各自实现攻击与受击。近战兵保留原接近与攻击，并可通过训练增加掩体接近、短程突进和近战堵截；换弹机会来自实际视觉观察。

## 操作与试玩

2026-10-27：原 **近战 → 命中反馈** 的移动参数改用“眩晕持续时间”“眩晕时保留移速”“眩晕命中精度损失”描述，原保存键和受方倍率保留；新增玩家近战命中敌人的爆头破绽及头顶星环，见[近战眩晕与爆头破绽](#近战眩晕与爆头破绽2026-10-27)。眩晕不表示额外禁止攻击或暂停AI。

按 F5 运行主场景，进入战斗区域后走到敌人面前按 **V**。近战与射击使用相同的 `Combat.can_combat()` 区域限制；场外按 V 不会开始攻击、消耗冷却、打断换弹或播放剑光。无需瞄准或切换近战武器；使用当前手持枪械的近战参数。V 每次按下攻击一次，按住不会自动连击。

默认前摇 0.12 秒，之后在正面 90 度、水平距离 1.6 米以内选择最近的一个可命中目标，造成 25 点伤害。墙、门和掩体会阻挡；目标可以在前摇期间离开范围。挥空也会出现剑光并进入冷却。

近战按攻击武器的瞬时精度损失乘受方倍率扣除精度，默认100%损失、倍率1时可归零，之后沿用原有恢复等待和移动惩罚。默认眩晕持续0.5秒、保留50%自主移速；双方从攻击者武器读取，仍受原速度损失倍率影响。默认向远离攻击者的方向击退约1米、持续0.2秒；减速不缩小击退外力，碰撞仍决定实际距离。固定训练靶沿用命中计数／生命规则，不获得这次敌人专属眩晕破绽。NPC 不属于可攻击目标。

近战期间可以普通移动，朝向保持本次挥击方向，不能冲刺、射击、换弹或切枪。收招结束即可恢复其他武器操作；默认两次近战开始至少间隔 0.6 秒，切枪不能刷新冷却。

蹲姿按 V 时，玩家先请求起身，站稳并重新通过原资格检查后才开始挥击、扣除体力；低顶阻挡、切枪、翻越或资格失效会取消这次等待。挥击结束按手动姿态恢复。敌人也必须实际站稳才能挥击；双方翻越期间都禁止近战，仍可受伤，真实落地后才能恢复攻击。1.75米角色身高不改变原1.6米近战距离，见 [移动与姿态](MOVEMENT.md)。

战斗区内有效的 V 近战可以打断换弹：未完成半程则按既有规则取消，完成半程则保留 50%，收招后恢复续换。被打断的开火请求会清除，继续开枪需要重新按下左键。近战不消耗子弹；每次成功开始挥击时扣除当前武器配置的体力，默认20点，体力不足则不能发起，也不打断换弹或消耗冷却。挥空、离场或中途取消均不返还已扣体力；一次挥击只扣一次，换枪不补充体力。把“近战体力消耗”设为0可关闭消耗。

体力沿用玩家现有的0～100数值与状态条。有效扣除后重新等待 `Stamina Recovery Delay`（默认0.5秒），再按原速度恢复；扣至0时，奔跑仍需等体力回满后才能恢复。近战只要求体力足够本次消耗，不额外要求回满。未装备武器、对话、死亡和暂停时不能发起近战；死亡、进入对话、本次所属靶场复位或失去有效战斗区域时，会取消未完成的挥击并清理剑光，不刷新已消耗的冷却。区域判定沿用射击规则：玩家必须与至少一个开启监测、属于 `combat_zone` 组的 Area3D 重叠；离开全部区域或区域停用、删除后，前摇中的攻击不再结算。

试玩重点：武器配置的范围是否合适、前摇与收招是否自然、击退能否创造需要的空间，以及近战与换弹的衔接。文中的默认值是脚本缺省值，资源中已保存的调参优先。

## 近战眩晕与爆头破绽（2026-10-27）

在 **Equipment → 当前武器 → 近战 → 命中反馈** 调整；当前显示顺序为眩晕时长、保留移速、瞬时精度损失、破绽开关／门槛倍率、击退距离／时长。普通减速与击退仍适用于原玩家／敌人受击，破绽仅由玩家近战向实际命中的敌人施加。

| 参数／原字段 | 初值 | 含义 |
| --- | --- | --- |
| 眩晕持续时间 `melee_slow_seconds` | 0.5秒 | 原减速时长及该次敌人眩晕记录初始时长；0关闭持续状态 |
| 眩晕时保留移速 `melee_slow_multiplier` | 50% | 原受方倍率仍生效；100%只关闭减速，不关闭眩晕／破绽 |
| 眩晕命中精度损失 `melee_accuracy_loss` | 100% | 一次扣减，不作为持续上限，不禁射 |
| 眩晕爆头破绽 `melee_headshot_opening_enabled` | 开启 | 仅玩家近战命中敌人；关闭后不附加门槛优惠 |
| 眩晕破绽门槛倍率 `melee_headshot_threshold_multiplier` | 0.8倍 | 可调0～1；射击武器的普通爆头起始准度乘该倍率，80%×0.8=64%；0将门槛降至0，1不降低门槛 |

攻击开始时冻结这次配置，命中后状态归该敌人身体。敌人保存的是倍率；切枪后以实际射击武器的普通门槛计算，已施加倍率不被新武器的近战设置替换。玩家受敌方近战仍按原方式扣血、丢精度、减速和击退，但**不会获得爆头破绽**；共用同一武器资源也不例外。敌人挥空、普通枪击、近弹、翻越推人和被爆头状态都不产生新破绽。

对眩晕敌人使用“射击武器普通门槛×已保存倍率”，再走同一线性公式。倍率0不代表必爆头，此时爆头率等于基础准度，满准度才必爆头。第一次有效玩家枪击后消费，未爆头／0概率／关闭爆头／零伤害枪击都消费；打空、墙挡不消费。消费后原移动减速和眩晕星环仍持续至各自到期。霰弹每枪每目标只处理一次，不给其他命中目标共享优惠。原绝对门槛字段 `melee_headshot_accuracy_threshold` 已删除；新倍率不是百分比输入。

当前眩晕记录未到期前，重复近战不延长它、不替换倍率、不补发已消费机会；原近战伤害、击退、瞬时精度损失和普通减速刷新仍正常。普通枪击刷新减速也不续期破绽。暂停冻结，死亡／复位／退场／对话清理；切枪、换AI动作不刷新。头顶星环表示这段眩晕尚未结束，是否仍有破绽优惠由当前目标的爆头菱形反映。

这些参数是实现初值。默认0.5秒含近战收招后的短补枪窗口；需结合实际武器收招、精度及交叉火力试玩，不自动调整用户原武器平衡值。结构与验收见[设计和实施记录](../superpowers/specs/2026-10-27-headshot-curve-melee-opening-design.md)。

## 远程敌人

近战和射击、移动一样，属于敌人的基础执行能力，不是单独的默认行为或战术行为。未受团队指挥或小队仅共享视野（等级0）时，现有“远程接敌”根据情况提供站定射击、直接退让、近战推开以及推开后退让等方案，交给既有 Utility 统一比较；近战方案标记为 `id = engage`、`plan = melee`，可附带已验证的退路。只在本竞技场激活、玩家可见、位于正面有效范围、没有遮挡且冷却完成时提供近战候选。个人评分中近战不强制优先，但玩家持续贴近时能够实际选择。估计包含目标背后的碰撞空间、前摇期间已观察到的逼近，以及出手后的退让收益；不会把持续追近在整个窗口内一次性扣掉，也不会把挥击后的敌人一律当作原地站立。

战术配合和强配合（等级1/2）沿用已确认协调器方案的最小近身反应规则：所有已装配的任务执行器都可请求武器已有的近战自卫，包括支援、侧翼、警戒、搜索和换弹；既检查战斗档案，也检查当前武器与原有真实命中条件。挥击不另选战术或改变任务目标，持续提交原动作身份并上报身体占用；当前实现停步完成前摇和收招，随后接续协调器任务，不启动个人 Utility。失视、死亡、换武器和失去权限仍按原规则取消；关闭武器近战后不会挥击。近战打断换弹后，换弹执行器按实际弹药状态恢复，实际补弹前不能误报完成。

选中后在前摇期间停步，前摇结束时再次检查目标，玩家可通过离开范围或躲到障碍后避免受击。命中后扣血、按攻击武器近战基础值×受方倍率扣除精度并物理击退；玩家收起槽的准度记忆也扣同次损失，不能通过切枪跳过惩罚。默认100%基础损失且受方倍率×1仍可降到0，其他倍率不再被强制清零覆盖。伤害沿用生命入口，Debug 无敌仍只免除扣血。个人 Utility 方案附带退路时，出手后即可在收招期间按原移动逻辑退让；路径失效则停步，不跳过收招。个人模式收招结束后重新交回 Utility，继续选择退让或射击。

玩家翻越中被命中时取消预定轨迹，清除首次中断时的轨迹合成速度，再以重力和真实水平击退安全下落；不把上升段的位移速度转换成额外抛升。无敌仍会触发击退和翻越中断。该行为及误离场复位回归见 [移动与姿态](MOVEMENT.md)。

敌人参数在 `Enemy → Weapon → 近战`，使用自己装备的 WeaponData；原有 `Shooting Enabled` 仅控制射击，近战由武器 `Melee Enabled` 控制。敌人没有体力系统，**“近战体力消耗（仅玩家）”在敌人这里无效**。挥击期间不能同时开枪或换弹；开始近战会取消自身换弹，之后仍由原换弹动作决定是否重新换弹。

身体冷却独立推进，切换动作、取消挥击和换枪不刷新冷却；死亡、失去区域资格、对话、动作权限撤销或装备变化取消未完成攻击，区域复位重置运行状态。暂停冻结计时。敌人 `EnemyPresentation` 提供可选近战动画和剑光，空素材不影响玩法。

基础能力存在于敌人共用的身体和服务中，由已选行为提交请求。远程 `ranged.tres` 保留原四个默认行为及原战术目录，没有近战训练勾选项。现有 `melee.tres` 保留巡逻、搜索、近战接近三个默认行为；接近行为在合法范围内提交同一底层挥击请求。关闭敌人武器的 `Melee Enabled` 可禁用挥击。2026-10-07 的近战战术扩展见下文；挥击仍是底层能力。

仅情报共享（0级）的多人近战在接近停点被队友占用时，会由个人接近行为比较其他合法侧向位置，实际沿选中的路线靠近；有效侧向点不会随每次重评任意换边。基础接近与已训练突进共用这套准备，仍核对真实身体、导航、攻击距离和遮挡；不取消占位保护，也不让未训练成员自动突进。头顶“待命”表示没有个人动作，不能等同于团队的“警戒”岗位。该修复的复现及性能限制见[测试记录](../enemy-tests.md)。

## 近战兵装备近战武器

在已有敌人的 `UnitType → Profile` 选择 `resources/enemy/units/melee.tres`，再给该敌人的 `Weapon` 选择 `resources/weapons/enemy_test_melee.tres`。无需创建另一个兵种、攻击节点或默认行为；地图中原有敌人的配置不会自动替换。

WeaponData 原有的 **基本信息 → Fire Mode** 现在可选“单发／自动／近战”，原单发0、自动1保持，近战为2；没有额外 Weapon Type。选近战后沿用下表数值，不能发射子弹或换弹，没有可用弹匣；检查器隐藏枪械字段但保留其保存值，切回单发／自动会恢复显示。

模式下拉框沿用原字段和原生撤销历史，由现有武器检查器在切换完成后延迟刷新；撤销／重做也会更新参数显示。这样即使已打开的资源在脚本热更新后漏发即时通知，直接资源面板和敌人内嵌 Weapon 面板仍能隐藏远程字段。维护时必须通过真实下拉框验证，不能只用代码直接赋值代替界面操作；专项覆盖见 [测试说明](../enemy-tests.md)。

专用近战武器只允许已有近战兵装备，其兵种通过原 capabilities 列表声明 `melee_weapons` 资格。玩家和远程兵不具备该资格：出生误配会提示并按未装备处理；玩家优先使用另一有效槽。运行时错误换装请求保留原有效武器，切换兵种导致资格失效时取消未完成挥击并卸下该武器。单发／自动枪械的附带近战仍可使用，玩家继续持枪按 V，远程敌人继续用枪械参数推开玩家。敌人体力消耗字段仍不生效。

2026-09-30 的最小接入只补挥击请求及必要的攻击占用，见 [该阶段设计](../superpowers/specs/2026-09-30-melee-weapon-and-melee-enemy-design.md)。停止距离仍限制在当前武器范围内，避免短武器够不到。2026-10-07 按用户确认的方案增加以下接敌策略。

## 近战堵截

用户要求将预测路线、跑到玩家前方堵截作为个人训练动作，适用于全部配合等级。选择近战兵后，在 **Enemy → Training → Profile → 战术解锁** 勾选 **近战堵截**（`melee_intercept`），重新加载战斗场景即可装配。共享训练需要分别配置时，先复制或设为唯一；原 `arena.tres`、`melee_assault.tres` 不自动增加勾选。

当前实现从本人或队友合法目击的位置、平滑速度和时间预测短段路线。能及时到位、有身体空间和攻击通路时，沿目标路线的侧面奔跑到侧前方，保留远程队友的射界；没有合适机会仍可普通追击。0级由个人 Utility 选择，1/2级由协调器统一遍历已训练动作并选择整队任务，不要求特定兵种比例。

预测点与原截止时间在执行中保持，目标停步、明显折返、偏离路线、失视过久或到期便退出。短暂失视可完成原有有限抢位，但预测不等于看见玩家，真实挥击仍需原视线、范围和冷却。堵截使用普通奔跑，**不包含或消耗短程突进**；突进仍需单独训练并参与选择。

参数在同一训练的 **Action Overrides** 中，展开使用 `config/melee_tactics_settings.gd` 的参数资源，再展开 **近战堵截**。没有该资源时，可复制 `melee_assault.tres` 的 Action Overrides 参数项；不必替换训练的战术勾选。以下为实现默认值，不是强制战术优先级：

| 字段 | 默认 | 用途 |
| --- | --- | --- |
| `intercept_horizon_seconds` | 1.8秒 | 预测时间上限 |
| `intercept_max_distance` | 6米 | 预测路程上限 |
| `intercept_memory_seconds` | 0.6秒 | 已开始堵截可使用的最后目击年龄 |
| `intercept_speed_multiplier` | 2倍 | 抢位时的普通奔跑倍率 |
| `intercept_min_gain_seconds` | 0.25秒 | 相比普通追赶的最小预计时间收益 |

每次准备至多两个时间点；不是每帧重读训练或全地图找堵点。运行验证及原0级性能限制见[敌人测试](../enemy-tests.md#2026-10-24-可训练的近战堵截)。

## 近战兵的掩体接近与突进

用户确认的要求：借掩体靠近玩家、观察玩家换弹后利用机会接近、能够突然短程冲刺；继续采用兵种／训练／Utility 分层，保留原基础挥击执行。掩体接近与短程突进是可训练解锁的战术，默认近战接近仍可独立工作。

当前按配合等级分流：上述个人 Utility 用于无绑定或仅视野共享；普通、强配合持续由协调器选择任务。2026-10-24 补齐短程突进的命令入口，已训练的近战成员可在合格接敌/侧翼路线中使用有限加速，未训练者不会自动获得。距离、速度、时限和冷却使用下表原配置并在本场装配时冻结；真实通行、碰撞、挥击前摇及收招仍有效，任务切换不刷新冷却。团队不会为了使用战术临时交回个人 Utility。

在 **Enemy → Training → Profile** 的战术解锁中可单独勾选 **掩体躲藏与探头**；勾选升级 **掩体接近** 会自动包含基础躲藏。**短程突进** 仍独立选择。也可使用 `resources/enemy/training/melee_assault.tres`，其中已勾选升级与突进，并在 **Action Overrides** 中提供近战参数资源。使用共享训练时先复制或设为唯一。现有地图、武器、竞技场训练勾选和远程兵配置不会自动替换。

- **基础躲藏**：实际受伤、近弹压制会使近战考虑前方、侧面或后方的安全掩体，由共同评分决定是否值得移动，不是每挨一枪强制退走。新压力消退后不再因低血量无限躲藏，正在进行的转移可完成，到位后重新比较探出与接敌；贴脸能够有效出手时保留攻击。近战不因此获得枪械或掩护射击资格。
- **掩体接近**：从已有掩体中评估可达、遮挡有效且能缩短已知目标距离的落点，也能从已躲好的掩体继续进攻。全身掩体根据当前躲藏面比较两端到已知目标的完整导航路线及暴露，优先更快、安全的接敌路线；两边代价接近时从实际入口的另一侧出来。只有一个有效出口就用该出口，两边都不通则退出。主动进入遮挡后在同一段中绕出，选定出口后保持路线，重新目击后可有限奔跑接敌，到出手距离交回原近战执行。新受击、换弹机会等仍可触发共同重评。短期排除已到达掩体的其他落点，避免刚绕出又退回同一墙后；目标位置明显改变、复位或期限结束后可重新评估。无合法出口、路线失败／超时或有限观察结束后仍未发现玩家，允许原搜索接管。旧证据不能开始新推进，已经开始的绕出／观察可用完原路段时限。基础躲藏与升级保留独立实例、候选和评分，升级不保证每次胜出。
- **换弹机会**：只有看见玩家正在换弹并完成观察反应后才形成证据。看到换弹结束或取消立即撤销；失视后仅保留短时推断，不读取隐藏玩家位置、枪械参数或精确换弹进度。未看见的墙后换弹不产生机会。
- **短程突进**：近距离可以突然加速；观察到换弹时，可以从单次突进可覆盖的更远距离发起。路径、时间与冷却限制仍有效。到达出手距离后交回原接近行为挥击；目标持续逃跑时到时结束。普通动作切换或提前取消不返还冷却，暂停不推进，死亡／区域复位清理。失去训练资格会取消并移除该战术实例。

半身掩体也参与近战的“掩体接近”。沿用低墙外围环带，选中后到位蹲稳、短暂躲藏，再在同一点起身观察；不新增墙角区域或侧向 Peek 点。真实重见玩家并站稳后，沿用本动作原有的有限奔跑接敌段；原 Utility 仍可让更好的普通接近、已解锁突进或既有单次翻越方案接管，最终由原基础近战完成攻击。未重见玩家时只有限观察，之后由搜索接管；近距准确情报仍只是调查线索，不能替代近战出手所需的真实视线。姿态时间计入方案代价，沿用 Cover 的 `low_cover_hide_seconds`（默认0.6秒），奔跑时间与速度沿用下表原近战参数；不继承远程低墙射击的8分偏好，也不保证每次选低墙或翻越。

低墙后这一段奔跑必须具有通往实际接敌停靠点的完整步行路线；只有翻墙才能接近时，退出普通奔跑段，让原 Utility 选择带真实翻越执行的接敌／突进方案。可绕行时仍按实际路线和原有限速度比较，不强制翻越。

以下是当前实现默认参数，可调数值不是用户指定的固定要求：

| 参数位置 | 字段 | 默认值 |
| --- | --- | --- |
| Training → Perception | `reload_observation_seconds` | 连续观察 0.15 秒 |
| Training → Perception | `reload_memory_seconds` | 换弹机会保留 0.8 秒 |
| Action Overrides → Melee Tactics | `cover_minimum_progress` | 掩体落点至少接近 0.6 米 |
| 同上 | `cover_memory_seconds` | 新推进及跑向掩体的目击期限 5 秒；已开始的绕出／观察沿用原路段时限；到达过的掩体也记住 5 秒 |
| 同上 | `cover_exit_speed_multiplier` | 绕出及出掩体接敌的速度倍率 2.0 |
| 同上 | `cover_charge_seconds` | 重新目击后继续奔跑最多 2 秒；贴脸、失视或受阻可提前结束 |
| 同上 | `cover_exit_side_tolerance_seconds` | 接敌时间及对应共同代价差在 0.25 秒内时，优先换侧 |
| 同上 | `rush_distance` | 无换弹证据时在 3.5 米内考虑突进 |
| 同上 | `rush_speed_multiplier` | 移动速度的 2.5 倍 |
| 同上 | `rush_seconds` | 单次最多 1 秒 |
| 同上 | `rush_cooldown_seconds` | 预定结束时刻后冷却 4 秒 |

进入掩体的速度、绕行和出口观察时长 `watch_seconds` 仍由 Training → Cover 控制。原 `peek_speed_multiplier` 用于基础／远程探头，近战升级绕出使用上表独立速度，不覆盖已有的 Cover 保存值。绕出与观察不刷新目击期限，也不读取隐藏玩家位置；原“路径长度／实际请求速度＋余量”的路段时限和有限观察继续有效，不能靠反复重选延长路线。自己的训练资源没有近战参数组时，可复制预设里的 Action Overrides，或添加使用 `config/melee_tactics_settings.gd` 的资源；缺省值仍有效。升级自动包含基础躲藏，与短程突进不互相包含。

默认接近、突进和掩体推进估计可攻击位置、武器冷却与前摇，掩体推进同时计入进出掩体的路径与暂时失视。各段速度用于计算到达时间，暴露采用等效速度近似；只在最近的已知目标位置上规划，不保证目标还在那里。它们都提交原三项结果给统一评分器，没有按动作 ID 强制优先。空间候选继续使用共享分帧预算；实际移动保留导航和身体碰撞。

玩家贴墙站在导航边界外时，近战接敌会检查导航内可停靠且仍够得到玩家的位置，保留武器距离、高差、身体空间和墙体遮挡限制。绕出重新目击后可继续接近并挥击，避免脚底不能寻路时在待命与掩体间循环；未解锁战术的普通接近也使用这项校验。

试玩重点：受压时是否选择有推进意义的掩体、换弹时是否抓住机会、突然突进是否可读且有间歇、冲到近处能否自然接续攻击。自动化结果不代替手感确认。

## 从枪械资源调参

选择 `Main → Player → Equipment`，展开 `Primary Weapon` 或 `Secondary Weapon`，找到 **近战**。也可直接打开对应 `.tres`。射击伤害与近战伤害分别设置；两槽若引用同一资源，也会共享该资源的静态配置，单独调整时先复制资源。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `melee_enabled` | 开启 | 当前枪械能否近战 |
| `melee_damage` | 25 | 近战伤害，与 `damage` 子弹伤害独立 |
| `melee_stamina_cost` | 20点 | 开始挥击时的体力消耗；0关闭，不足则拒绝 |
| `melee_range` | 1.6 米 | 自身与目标脚底之间的最大水平距离 |
| `melee_angle_degrees` | 90 度 | 正面扇形总角度 |
| `melee_height_tolerance` | 1 米 | 允许的脚底高度差 |
| `melee_windup_seconds` | 0.12 秒 | 开始动作到实际出手 |
| `melee_recovery_seconds` | 0.25 秒 | 出手到恢复其他武器操作 |
| `melee_interval` | 0.6 秒 | 两次开始的最短间隔，至少覆盖前摇加收招 |
| `melee_knockback_distance` | 1 米 | 无障碍且目标不主动移动时的参考击退距离 |
| `melee_knockback_seconds` | 0.2 秒 | 击退外力衰减至零的时间 |
| `melee_slow_multiplier` | 0.5（50%） | 检查器显示“眩晕时保留移速”；目标在原移动状态速度上保留的比例，100%只关闭减速 |
| `melee_slow_seconds` | 0.5 秒 | “眩晕持续时间”；0关闭持续效果，与击退时长独立 |

旧枪械资源没有保存这些字段时使用默认值。每次按 V 时固定本次参数，开始后的资源修改不会改变这一击。原有枪械伤害、弹药和瞄准参数未被改写。

“近战体力消耗（仅玩家）”只由玩家读取。敌人当前没有体力系统，即使敌人武器资源里显示此字段，修改它也不会影响敌人近战。

## 命中减速与击退（2026-10-09）

用户确认：玩家和 AI 的近战命中使目标自主移动降为原速度50%，持续0.5秒；连续命中刷新时间、不叠乘速度，击退独立计算。减速和击退均属于武器配置。玩家从 `Equipment → Primary Weapon / Secondary Weapon → 近战` 修改；AI 沿用 `Enemy → Weapon → 近战`，不新增敌人武器槽或改变兵种装配。

2026-10-24 按用户要求扩展为通用命中效果：子弹在武器的“命中效果 → 枪击与压制”配置基础速度损失和时长；近战沿用 `melee_slow_multiplier`（保留速度）和 `melee_slow_seconds`，先换算基础损失 `1 - melee_slow_multiplier`，再乘与射击共用的受方 `Hit Speed Loss Multiplier`。例如近战基础保留50%、受方倍率×0.5，实际只损失25%、保留75%。玩家倍率在 Combat，敌人在 Training → Profile → tactics；三个倍率和百分比精度规则见 [战斗说明](COMBAT.md#命中压制与击中减速2026-10-24)。

当前实现：行走、奔跑、蹲行、瞄准横移及近战中的移动先应用各自原速度规则，再乘命中后保留速度；敌人换弹／挥击限速也先于减速。受击时会限制已有主动移动惯性，不能靠原奔跑速度穿过整个减速期。计时属于受击角色，每物理帧独立推进一次；AI 停步或未激活时也会到期，行为和换枪不能重置效果。射击与近战复用各自身体唯一状态，有效新命中覆盖强度并刷新完整时长，不叠乘；无减速攻击不清除或续期已有减速，擦过不减速。

暂停冻结计时；进入对话、角色死亡或区域复位时清除，死亡重开从无减速状态开始。翻越中受击仍中断原轨迹并安全下落，不缩放重力或击退。Debug 无敌沿用原规则：只免除扣血，仍受到近战的准度、击退与减速影响。挥空、前摇未完成、目标被墙挡住时不施加命中效果。

双方的 `receive_melee_hit(damage, attacker_position, distance, duration, fallback_direction, effects)` 在原方向参数后统一接收攻击效果字典，旧的两个直接减速参数已删除；没有攻击快照时不凭空施加准度／速度损失。正式挥击传入起手时保存的 `WeaponData.get_attack_effects(true)`。近战基础精度损失为 `Melee Accuracy Loss`，默认100%，再乘与射击共用的受方命中精度倍率；不会在倍率后再次强制清零。玩家收起的武器也减去同次已缩放损失，保留原恢复等待与切槽约束。

各自身体的 `get_hit_movement_multiplier()` 提供当前保留速度，`clear_hit_effects()` 清理本角色的击退和减速；旧近战专用名称及强制准度清零路径已退出。运行状态不写回共享 WeaponData，玩家与敌人不共用攻击或受击执行函数。

## 动画与剑光

玩家 `Visual/Presentation` 和敌人 `Presentation` 的 Animation Profile 提供 **Melee** 动画槽，填写模型中的片段名称即可。片段进度分别由玩家 Combat、敌人近战控制器的前摇加收招时间驱动，出手点位于 `前摇 / (前摇 + 收招)` 的归一化位置；默认约为 32.4%。素材的击打动作应与该位置对齐。没有该动画时回退 Idle，没有模型时仍正常攻击。

Combat 发出 `melee_started()`、`melee_struck(target)`（挥空时 target 为 null）及 `melee_finished()`；表现适配器读取 `melee_phase`、`is_melee_active()` 和 `get_melee_progress()`。结束或取消都会发出 finished；不要用动画回调来造成伤害。

Combat 的“近战表现 / Melee Effect Scene”默认引用 `scenes/effects/melee_slash.tscn`，留空仅关闭剑光。剑光约 0.14 秒后淡出，属于 Combat 的子节点，随角色卸载。替换场景需使用纯表现 Node3D 根节点，实现 `start(origin, direction, reach, angle_degrees)` 并自行结束释放；局部 -Z 为挥击正面。其脚本位于 `scripts/systems/effects/melee_slash.gd`，没有伤害或碰撞判定。

## 代码边界与验证

- 玩家攻击直接位于现有 `scripts/player/player_combat_v3.gd` 的近战函数区，没有新增玩家近战执行脚本或 Melee 节点。
- `player.gd` 配合移动、转向和对话取消，并通过 `try_consume_stamina()` 管理自身的体力扣除与恢复等待；Combat 检查攻击资格后调用。Equipment 只配合切枪限制及提示，消耗参数仍保存在槽内武器资源。
- 敌人 `enemy_actor.gd.receive_melee_hit()` 独立处理扣血、准度、击退和减速。击退经 `move_and_slide()`，已由正常移动推进的帧不会重复推进；AI 未激活时身体仍能完成受击移动和减速计时。死亡和复位清除效果；AI 原停用分支在对话时通知身体清理，不管理效果进度。
- 敌人调用链为 `远程接敌的近战方案被选中 → AI 转交 melee 意图 → enemy_melee_controller → enemy_actor`，选择器和统一评分公式不按动作 ID 特判。候选与请求位于现有 `actions/enemy_tactics.gd`，不新增默认／战术行为，保留原训练选择与其他配置；敌人不调用玩家 Combat 的近战攻击函数。
- 敌人行为通过 `allows_movement(owner)` 查询是否允许近战期间退让，不读取近战阶段枚举。身体的移动、转向、开火与换弹入口自行维护冲突规则，直接调用也不能绕过前摇限制；受击推移仍独立生效。表现适配器只读取 `presentation_state()` 快照。接口详见 [敌人基础执行](../enemy-ai.md#基础执行接口与冲突规则)。

`tests/run_combat_regressions.py` 默认包含近战功能、表现、物理、战斗区域及体力五组专项；分别验证真实 V 输入与伤害、动画／移动／区域清理、30／60／120 Hz 下有无正常移动调用时的击退、区域限制，以及当前武器体力消耗、不足拒绝、恢复等待和状态条同步。结果及其他回归见 [实施记录](../superpowers/plans/2026-09-30-player-melee.md)。
