# 玩家主、副武器槽

当前只通过检查器配置装备；运行中按 `1` 选择主武器、`2` 选择副武器，滚轮上下在两槽间切换。换枪不暂停游戏。游戏内挑选、购买和装备武器留到商人系统完善后再做。

## 在 Godot 中配置

打开 `scenes/main.tscn`，选中 `Player/WeaponSlots`：

- `Primary Weapon`：拖入主武器的 WeaponData 资源。
- `Secondary Weapon`：拖入副武器资源；允许留空。
- `Starting Slot`：选择出生／死亡重开时默认使用的槽位。

展开槽内资源可以调整枪械参数。已有主武器为 `resources/weapons/test_pistol.tres`，用户原参数保持；新增 `resources/weapons/test_sidearm.tres` 为单发测试副武器，伤害15、间隔0.4秒，其余采用 WeaponData 初值，仅用于比较切换效果，非最终平衡设定。槽位不限制枪械种类，但拒绝 Fire Mode 为“近战”的专用武器；该模式仅供近战兵使用。出生误配按空槽选择另一有效槽，切槽时拒绝错误资源；玩家 V 近战仍取手持枪械的近战参数。

装备来源统一为 WeaponSlots，初始化与切槽时将选中资源交给 Combat。Combat 保留运行时武器引用，检查器不再提供重复的 Weapon 配置；它继续负责瞄准模式、稳定度计算、射线和伤害。展开槽内资源会按 Combat 的 Aim Mode 显示对应模式参数；从文件系统直接打开资源才显示两组。

每把武器的 `Fire Mode` 可选“单发／自动”：单发每次点击发一枪，自动在瞄准时按住左键持续开火；射速仍由 `Shot Interval` 决定。现有资源默认单发，切枪后需要重新按下左键。完整规则及测试见 [PLAYER_FIRE_MODES.md](PLAYER_FIRE_MODES.md)。

## 操作与边界

每份远程武器资源现有独立的“近战参数”分组，玩家进入战斗区域后按 V，使用当前枪械的近战伤害、范围、击退和体力消耗配置。其中“近战体力消耗”默认20点，可在 `WeaponSlots → Primary Weapon / Secondary Weapon → 近战参数` 中修改；0关闭消耗，体力不足不能发起近战。无需额外装备近战武器；挥击期间暂停切枪，收招后恢复，切枪不刷新近战冷却或补充体力。详细参数与换弹衔接见 [玩家近战](MELEE.md)。

- 右下角显示两格和武器名称，黄色箭头高亮当前槽；左下角生命／体力不变。
- 空槽不会被按键或滚轮选中；默认槽为空时自动使用另一个非空槽，两槽都为空则无武器。
- 对话时隐藏装备栏并禁止切换；死亡／暂停时也禁止切换。场外可以先选好武器，射击和近战均需进入战斗区。
- 重复选择当前槽和长按重复键事件不会刷新武器状态。切换会取消旧锁定和待发射请求；继续按住右键时，下一帧用新枪重新检查锁定。
- 上一枪的冷却继续计时，切枪不能绕过射速。各槽单独保存精度惩罚和恢复等待；收起期间暂不自动恢复，拔枪至多恢复到初始精度，已有更差精度继续保留。没有增加切枪动画或额外换枪耗时。
- 换弹不足50%时切枪取消，切回可用余弹开火；达到50%后切枪仅保留半程，切回强制续换。两槽即使引用同一WeaponData也分别保存半程和快慢方式；收起期间不计时。另一把枪可以正常使用，具体奔跑与备弹边界见 [换弹规则](AMMO.md)。
- 死亡重开恢复检查器配置的初始槽位与枪械运行状态，继续保留对话选择。
