# 玩家装备与主、副武器槽

原 WeaponSlots 节点已按用户要求改名为 Equipment（装备），医疗包资源、数量与主、副武器统一在该节点的检查器配置。保留 `player_weapon_slots.gd/.tscn` 文件路径和脚本 UID。当前只通过检查器配置装备；运行中按 `1` 选择主武器、`2` 选择副武器，滚轮上下在两槽间切换。换枪不暂停游戏。游戏内挑选、购买和装备武器留到商人系统完善后再做。

## 在 Godot 中配置

打开 `scenes/main.tscn`，选中 `Player/Equipment`：

- `Primary Weapon`：拖入主武器的 WeaponData 资源。
- `Secondary Weapon`：拖入副武器资源；允许留空。
- `Starting Slot`：选择出生／死亡重开时默认使用的槽位。
- “医疗包”分组的 `Medkit`：拖入 MedkitData 资源，默认 `resources/player/default_medkit.tres`；展开设置 `Heal Amount`（回血量）和 `Use Seconds`（时间），也可新建资源并另存。
- “医疗包”分组的 `Medkit Count`：初始数量，默认3；运行时显示该装备实例的实际余量。

展开槽内资源可以调整枪械参数。已有主武器为 `resources/weapons/test_pistol.tres`，用户原参数保持；新增 `resources/weapons/test_sidearm.tres` 为单发测试副武器，伤害15、间隔0.4秒，其余采用 WeaponData 初值，仅用于比较切换效果，非最终平衡设定。槽位不限制枪械种类，但拒绝 Fire Mode 为“近战”的专用武器；该模式仅供近战兵使用。出生误配按空槽选择另一有效槽，切槽时拒绝错误资源；玩家 V 近战仍取手持枪械的近战参数。

装备来源统一为 Equipment，初始化与切槽时将选中资源交给 Combat。Combat 保留运行时武器引用，检查器不再提供重复的 Weapon 配置；它继续负责瞄准模式、稳定度计算、射线和伤害。展开槽内资源会按 Combat 的 Aim Mode 显示对应模式参数；从文件系统直接打开资源才显示两组。

相机范围直接跟随当前武器的 **Aim Range**（锁定距离），武器资源不再提供独立的相机视野分组。相机订阅已有 `Combat.weapon_changed`，武器槽不管理镜头；切枪过渡时间在 **Camera3D → 视野过渡 → View Transition Seconds** 统一配置，默认0.25秒。详见 [相机与遮挡透明](CAMERA.md)。

每把武器的 `Fire Mode` 可选“单发／自动”：单发每次点击发一枪，自动在瞄准时按住左键持续开火；射速仍由 `Shot Interval` 决定。现有资源默认单发，切枪后需要重新按下左键。完整规则及测试见 [PLAYER_FIRE_MODES.md](PLAYER_FIRE_MODES.md)。

## 操作与边界

每份远程武器资源现有独立的“近战”分组，玩家进入战斗区域后按 V，使用当前枪械的近战伤害、范围、击退、减速和体力消耗配置。在 `Equipment → Primary Weapon / Secondary Weapon → 近战 → 命中反馈` 可设置“命中后移动速度”（默认50%）、“命中减速时长”（默认0.5秒），以及原“击退距离／击退时长”（默认1米／0.2秒）。减速只影响受击目标的自主移动，击退独立计算；0秒或100%关闭减速。AI 在原 `Enemy → Weapon` 中使用相同武器字段。

“近战体力消耗”默认20点，0关闭消耗，体力不足不能发起近战。无需额外装备近战武器；挥击期间暂停切枪，收招后恢复，切枪不刷新近战冷却、补充体力或清除自身的受击减速。效果参数在出手开始时固定；运行状态保存在各角色，两个槽共享武器资源时也不会共享受击计时。详细参数与换弹衔接见 [玩家近战](MELEE.md)。

- 右下角显示两格和武器名称，黄色箭头高亮当前槽；左下角生命／体力不变。
- 医疗包数量与 H 键提示显示在同一个右下角面板中，随装备栏在对话／死亡时隐藏；头顶只显示治疗进度环。Equipment 直接挂载医疗包资源并保存库存，子组件 Equipment/Medkit 只负责使用执行；治疗进度环位于 Equipment/MedkitIndicator。`Panel/Content/MedkitCount` 通过独立 UI 脚本只读订阅，槽位／提示在装备节点内的相对路径不变，见 [医疗包](PLAYER_HEALTH.md)。
- 空槽不会被按键或滚轮选中；默认槽为空时自动使用另一个非空槽，两槽都为空则无武器。
- 对话时隐藏装备栏并禁止切换；死亡／暂停时也禁止切换。场外可以先选好武器，射击和近战均需进入战斗区。
- 重复选择当前槽和长按重复键事件不会刷新武器状态。切换会取消旧锁定和待发射请求；继续按住右键时，下一帧用新枪重新检查锁定。
- 上一枪的冷却继续计时，切枪不能绕过射速。各槽单独保存精度惩罚和恢复等待；收起期间暂不自动恢复，拔枪至多恢复到初始精度，已有更差精度继续保留。没有增加切枪动画或额外换枪耗时。
- 换弹不足50%时切枪取消，切回可用余弹开火；达到50%后切枪仅保留半程，切回强制续换。两槽即使引用同一WeaponData也分别保存半程和快慢方式；收起期间不计时。另一把枪可以正常使用，具体奔跑与备弹边界见 [换弹规则](AMMO.md)。
- 死亡重开恢复检查器配置的初始槽位与枪械运行状态，继续保留对话选择。

## 代码与验证

- `player_weapon_slots.gd/.tscn`：装备检查器配置（主副武器、备弹、医疗包资源与数量）、数字／滚轮输入、当前槽位、各枪精度记忆与装备栏显示；场景根名为 Equipment，同时挂载独立 Medkit 执行与 MedkitIndicator 显示组件。
- `scripts/player/player_combat_v3.gd`：`equip_weapon(data, preserve_cooldown=false, ammo_state=null, resume_slow_reload=false)` 接收该枪的运行时弹药状态和原换弹方式；已有单参数调用保持兼容，双槽切换传入冷却保留及各槽状态。
- `project.godot`：新增 weapon_primary / weapon_secondary / weapon_previous / weapon_next 四个输入动作。
