# 弹匣、备弹与换弹

玩家按R主动换弹，打空不会自动换；敌人由AI在弹匣打空后请求换弹。双方换弹时都能移动、转向，不能开枪。

2026-09-29：双方成功开始换弹时准度立即降到最低，并在换弹期间及完成帧保持最低，随后按各自武器的延迟和速度恢复；取消不会恢复旧准度，失败请求不触发准度变化。受伤仍不打断换弹。具体角度/概率参数及回归见 [射击与准度](COMBAT.md)。

敌人头顶独立显示真实换弹百分比和剩余秒数，关闭 Debug 也显示，切换到接敌或攻击站位时保留；完成或取消后自动隐藏。动作与生命文字仍仅在 Debug 中显示：先到掩体再换弹为“前往掩体，准备换弹”，边走边换已补满但尚未抵达为“换弹完成，继续前往掩体”。之前统一显示“换弹安排”可能让此时靠近后的恢复射击看似瞬间换好；实际换弹计时不受玩家距离影响。

## 在哪里调整

| 位置 | 参数 | 作用 |
| --- | --- | --- |
| Main → Player → WeaponSlots → 初始共享备弹 | Starting Rifle / Pistol / Smg / Shotgun Ammo | 四类备弹的出生初值，脚本默认各36发；修改后重新运行生效 |
| WeaponSlots的主／副武器资源 → 弹匣与换弹 | Ammo Type | 步枪、手枪、冲锋枪、霰弹枪；同类主副枪共用一个备弹池 |
| 同上；敌人则展开Enemy的Weapon | Magazine Capacity | 弹匣容量，脚本默认12发；每把枪独立保存余量 |
| 同上 | Reload Seconds | 正常换弹秒数，脚本默认2秒 |
| Player → Combat | Sprint Reload Speed Multiplier | 奔跑中开始的慢速换弹进度倍率，默认0.5；整次耗时为快速换弹的两倍，途中停跑不加速 |

以上是已同意的试玩初值，后续检查器调参优先，未覆盖用户已有武器设置。弹匣出生时装满，这部分子弹不占初始备弹。武器类型不等于射击模式，单发／自动与弹药类型分别配置。

右下角原武器栏显示每槽`当前弹量/容量 · 备弹数量`，换弹时显示进度百分比和“快速／奔跑会中断”或“慢速／可跑”。快速换弹暂停在半程时提示停跑后继续；收起的武器也标记已保留的50%。这些信息不依赖 Debug。备弹显示的是该武器所用类型的共享备弹，不是两份独立存量。

## 玩家规则

- R只在有枪、非死亡、非对话和非暂停时生效，场外也能准备换弹。满匣、无备弹或已经换弹时不重启。
- 按 R 成功开始时读取 Player 的 `is_sprinting`，整次换弹方式固定。非奔跑时开始＝快速换弹；奔跑中主动按 R＝慢速换弹，允许边跑边换，途中停跑也不会加速。切枪后的续换保留原快慢方式。
- 快速换弹中允许开始奔跑，但会立即中断。不到50%时清零并保持取消：停跑后可用匣内余弹开火，必须再按 R 才从零开始；达到50%（含恰好50%）时只保留50%，奔跑期间暂停，停跑后自动从半程续换，完成前余弹也不能开火。
- 再次中断强制续换仍只保留50%，不会保留后半程的额外进度。R不能在奔跑中把已保留的快速半程转换成慢速以绕过暂停。耐力与瞄准锁定原有的奔跑限制继续生效。
- 切枪对快、慢换弹都使用上述半程规则。不到50%时取消；达到50%时该枪保留半程，收起期间不计时，切回自动续换。奔跑中切回快速半程枪先等待停跑；慢速半程枪可边跑续换。另一把枪的弹量、开火能力与换弹进度独立。
- 普通受击不中断。进入对话或死亡按原生命周期规则清理当前枪的换弹，暂停世界时不推进也不自动续换。
- 完成时只补足弹匣缺口，保留旧弹匣余弹；备弹不足则全部装入。未完成时不提前扣备弹。
- 若收起期间同类备弹被另一枪用尽，仍允许完成保留的后半程；只装入届时实际可用的备弹，完成后恢复匣内余弹可用，避免永久禁射。
- 切回武器保留弹量；共享同一个WeaponData的两槽也各有独立弹匣。开始换弹清理待发扳机，完成后重新按左键开火。
- 重新开始恢复配置的初始武器、满弹匣、四类备弹及其他场景初态，仍保留对话选择。

## 敌人规则与结构

2026-09-28更新：敌人空匣不再通过独立入口立即换弹。原地换、先到掩体再换、边转移边换，与交战／躲藏等在同一Utility候选池竞争。换弹计时固定，期间可普通移动和转向、不能快移，结束恢复动作速度；战术切换保留已经开始的基础换弹进度。下方旧入口描述是历史记录，以[敌人 AI](../enemy-ai.md)为准。

`scripts/weapons/weapon_ammo.gd`是小型RefCounted弹药状态对象，负责消耗、计时和补充，供玩家与敌人共用；WeaponData只保存配置。玩家WeaponSlots持有四类共享备弹字典与各枪状态，Combat引用当前枪；Enemy自己持有无限备弹状态。

半程策略由玩家 Combat 决定；共用 Ammo 只提供通用 `suspend_reload(checkpoint)`、阶段保存和续换能力，不读取奔跑输入或训练配置，敌人未启用暂停策略。WeaponSlots 为各槽保留弹药状态与快慢方式，收起武器不推进计时；没有把运行进度写入共享 WeaponData 资源。

AI的`_update_reload_request()`只在竞技场激活且非玩家死亡／对话时，发现空匣就调用Enemy的`request_reload()`。基础执行不自行决定何时换弹，`update_weapon()`以固定速度推进；不新增动作库资源或训练权限。兵种枪械资格仍由`can_use_firearms()`检查，近战不能请求换弹。

换弹期间沿用当前移动和转向、跟枪与冷却，头顶状态追加“换弹中”。普通受击不取消换弹；死亡、换枪、失去兵种枪械资格、对话取消，离场刷新恢复满匣并等待再次激活。暂停随世界停止计时。压制仍按原定时规则结束，只统计实际开出的枪；本步没有新增先找掩体再换弹或美术动画。
