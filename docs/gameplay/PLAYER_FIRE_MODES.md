# 武器开火方式

每把武器用 **WeaponData → 基本信息 → Fire Mode** 选择开火方式。玩家装备入口为 **Player → Equipment → Primary Weapon / Secondary Weapon**。它与 Combat 的 Aim Mode（弹道算法）、鼠标辅助开关（锁定操作）分别配置。

## 模式与参数

| Fire Mode | 编号 | 玩家输入 |
| --- | --- | --- |
| 单发 | 0 | 瞄准时每次有效点击左键发射一枪 |
| 自动 | 1 | 瞄准时按住左键，按 Shot Interval 连续开火 |
| 近战 | 2 | 仅专用近战兵装备，玩家武器槽拒绝此模式 |
| 霰弹 | 3 | 每次点击发射一组弹丸，按住不连发；配置见[霰弹](SHOTGUN.md) |

`Shot Interval` 是枪与枪之间的间隔；0.2 秒约为每秒 5 枪，仍受实际帧流程和战斗条件限制。各关可能保存不同模式，不将示例枪固定视为单发。

## 输入与战斗边界

- 仅未被 UI 消费的按下事件可启动射击；松键会停止自动射击。
- 取消瞄准、离场、对话、死亡、切枪与换弹会清理对应扳机状态；恢复后不能仅凭鼠标仍按住而自动重建请求。
- 每物理帧至多发一枪，长帧不补发多枪；切枪保留原冷却。
- 鼠标转向途中点击即时开枪，采用真正发射时的准度和角色朝向；不等待转完，不追加延后枪。
- 翻越时不射击，新点击忽略，落地不补发。翻越前已合法建立且未被松键或其他中断清理的自动扳机，落地后按原冷却继续判断。
- 无目标也能沿当前朝向射击；真实射线决定命中，锁定不绕过墙体。

敌人通过 AI 的 `try_fire()` 请求按冷却执行射击，点射、停顿和压制节奏仍由其 AI 决定，不直接套用玩家的按住左键行为。

## 配置与维护

WeaponData 保存模式及参数，`player_combat_v3.gd` 处理输入、冷却、弹药与真实射击，Equipment 交接武器。图样、精度、收敛、伤害和换弹规则分别见[战斗](COMBAT.md)、[霰弹](SHOTGUN.md)与[弹药](AMMO.md)。

专项为 `player_automatic_fire_test` 和 `combat_compatibility_test`；前者的部分旧断言假定保存主枪为单发，当前本地保存为自动枪时应保留并解释失败，不为测试改写用户配置。结果入口见[测试说明](../testing.md)。
