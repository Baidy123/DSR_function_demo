# 霰弹配置、图样与装填

武器 Fire Mode 选择霰弹后使用 ShotgunSettings。每次有效点击发射一组弹丸，按住左键不连发；原 Shot Interval 决定枪间间隔。参数在 **Player → Equipment → 武器资源 → Shotgun**，敌人也可引用同类武器。

玩家收敛统一在 **瞄准与散布 → 玩家收敛** 配置；Shotgun 的“敌人恢复（原算法）”只影响敌人。精度改变随机偏移，不整体缩放固定图样；蹲姿只降低最大随机偏移，不提高基础准度或爆头率。

## 配置步骤

1. 在 **Player → Equipment → Primary Weapon / Secondary Weapon** 展开武器；敌人仍在自己的 **Weapon** 配置。
2. 将 **Fire Mode** 设为 **霰弹**。会自动创建 ShotgunSettings 并引用默认图样；展开同一资源里的 **Shotgun**。
3. 在 **Pattern** 选择图样，在 **Pellet Damage** 调每颗伤害。其余先用默认值即可。
4. **Shot Interval（射击间隔）** 位于武器的“射击与弹药”。当前霰弹是半自动：每按一次左键打一组弹丸，按住不会持续射击。调大间隔可模拟泵动节奏，暂时没有额外的泵动动作。
5. 弹药种类仍由 **Ammo Type** 独立指定。如果要使用霰弹备弹池，选 **SHOTGUN**；更改 Fire Mode 不会擅自修改已有弹药类型、弹匣、伤害或间隔。
6. 想一发一发装填：在 **Shotgun → 逐发装填** 勾选 **Shell By Shell Reload**，用 **Shell Reload Seconds** 设置装一发的时间。默认关闭、每发默认 0.6 秒；现有资源不会自动改变换弹方式。

已有 `.tres`、主场景、关卡和玩家／敌人节点结构没有为此修改。`Fire Mode` 原编号单发 0、自动 1、近战 2 不变，只追加霰弹 3。切回原模式后原参数恢复显示，霰弹参数保留待下次使用。编辑共享武器或图样之前，若只想影响一个实例，先“设为唯一”或另存新资源。

## 在画板上设计弹丸位置

玩家霰弹另支持[精准爆头](COMBAT.md#精准爆头2026-10-25)：参数在原武器的 **命中效果 → 精准爆头（仅玩家）**，不在 ShotgunSettings 内。当前为超过起始准度后线性增长、满准度实际命中必爆头；近战破绽按各实际目标单独降低门槛。每枪每目标只判定一次并至多消费一次破绽，弹丸数不增加概率。触发后无防护且允许秒杀则击杀，否则按该目标实际命中弹丸总伤害乘武器倍率，存活者进入原被爆头状态。每枪基础伤害为该目标命中弹丸数乘每颗伤害；敌人霰弹仍沿原伤害规则。

1. 在文件系统双击 `resources/weapons/patterns/balanced.tres`，或展开武器的 **Shotgun → Pattern**。检查器里的 **弹丸落点画板** 就是编辑入口，不需要写坐标数组。
2. 要保留原图样，**先点“另存副本…”**，选择自己的 `.tres` 文件名。保存后检查器自动切到新副本；它不会自动替换武器的 Pattern 引用。
3. **左键点空白处加一颗、拖动已有点移动、右键点已有点删除**。支持原生撤销／重做；拖动中按 Esc 取消这次移动。“清空”清除当前点。按用户要求已移除“载入图样…”下拉框，避免把其他图样的点写进当前资源后误保存覆盖；需要更换图样时，将目标 `.tres` 拖到武器的 **Shotgun → Pattern**。
4. 点 **保存当前**，再把新的 `.tres` 拖到武器的 **Shotgun → Pattern**。内嵌或未保存的资源先用“另存副本”；直接修改共享图样会影响所有引用它的武器。

画板中心是瞄准方向，X 向右、Y 向上；点数就是弹丸数，最多 64 颗。画板只编辑固定图样，整体大小在同一武器的 **Shotgun → 霰弹图样 → 图样覆盖范围** 调整；各颗随机偏差仍由原稳定度参数决定。清空后运行时会回退为中心一颗，检查器会明确提示。

画板属于项目原有 **武器模式参数** 插件（`weapon_mode_inspector`）。若只看到普通 Points 数组，先在“项目设置 → 插件”确认该插件启用。

## 用距离与面积标定枪械散布

展开武器的 **Shotgun → 霰弹图样 → 图样覆盖范围**：

- **散布标定距离（m）**：规定这把枪到多远才扩散到下方的面积。修改距离时面积保持不变，距离越远，固定弹道越集中。
- **标定覆盖面积（m²）**：该距离处整个正方形落点画板的面积，包含没有弹丸的空白。修改面积时距离保持不变，面积越小，固定弹道越集中。
- 下方显示画板宽高、当前固定落点的宽高／包围矩形面积，以及实际角度尺度。固定落点读数不包含随机偏移，包围矩形也不表示内部所有位置都能被弹丸覆盖。

例如“4 m、1 m²”表示 4 米处画板为 1 × 1 米；只把距离改为 8 米，面积仍为 1 m²，枪在 4 米处的画板就缩为 0.5 × 0.5 米。两个输入都调整枪械散布，不是临时预览距离。它们不改变武器的锁定距离或最大射程。

距离和对应角度随当前 Shotgun 配置保存，修改可原生撤销／重做；面积由二者换算，不另存第二份尺度。修改覆盖不会改动共享图样点位，也不会改动另一把使用相同图样的枪。旧资源首次显示默认标定距离 4 米，面积由原角度计算，已有弹道保持不变；原默认 3°对应约 0.176 m²。

距离必须大于零、面积不能为负，组合后的角度尺度沿用原 0～15°限制；不合法时提示“未修改”并恢复原数值。面积为零只合拢固定落点，随机偏移仍可生效。原 **Stable Jitter Degrees／Unstable Jitter Degrees** 的位置、数值和最大偏差插值规则保持不变；偏移方向由下述模式选择。

## 不向圆心偏移

在 **Shotgun → 霰弹图样 → 偏移方式** 选择：

- **随机偏移**：原模式，每颗弹丸可朝任意方向偏移，包含靠近瞄准中心的方向。
- **不向圆心偏移**：以每颗原落点相对图样 `(0, 0)` 的方向为准，排除朝内分量；侧向、斜外侧和正外侧都允许。中心点没有朝内方向，仍可向四周偏移。偏移可以很小或为零，不强制拉出一个空心弹圈。

两种模式共用原最大偏差参数。满稳定时仍有 Stable Jitter 允许的小偏差，设为0才严格回到图样。更低稳定度扩大可能偏移的范围，不代表每一枪伤害必然更低；偏心瞄准、距离和目标形状仍影响命中。按住瞄准也不等于立即满稳定，移动、跟枪、连射与恢复仍沿原流程计算。

模式随当前 Shotgun 资源保存，可原生撤销／重做；只读资源不能修改。要比较现有示例枪，请在它的 Shotgun 中切换此项后保存。新模式不会自动启用，也不会自动调整图样、伤害或偏差强度。

## 两个独立预览场景

- 选中 **ShotgunPatternPreview** 根节点，在“独立预览参数”的 **预览偏移方式** 切换同样两种模式。修改后自动重采样，状态栏显示当前模式；该选项随预览场景保存，独立于实际武器。旧预览默认随机偏移，三个图样槽保持原结构。
- 打开 `scenes/presentation/shotgun_pattern_preview.tscn`，切到 **2D**，选中根节点 **ShotgunPatternPreview**。在“预览图样”分组的 **Pattern 1／2／3** 拖入 `ShotgunPattern.tres`，分别对应左／中／右面板；空槽显示“未指定图样”。替换槽位只是替换引用，不会把点复制进原图样文件。
- 在根节点“独立预览参数 → **预览图样覆盖范围**”中调整预览自己的**散布标定距离＋标定覆盖面积**，规则与武器相同：改距离保持面积，改面积保持距离，两者都改变固定散布。此控件替代原 `Preview Pattern Angle Degrees` 数值输入；下方显示三栏各自的固定落点尺寸。初始标定距离 4 米，面积沿用预览原角度计算，旧场景不自动改变散布。
- 同一分组中的 **Preview Stable Jitter Degrees／Preview Unstable Jitter Degrees**（稳定／不稳定时最大偏移）、**Preview Initial Stability**（初始稳定度）和 **Preview Distance M**（观察距离）也由预览自己保存。默认偏移 0.08°／0.55°、角度 3°、稳定度 100%、观察距离 10 米。三个面板共用这些数值；保存／重开场景及原生撤销均保留预览自己的配置，所有参数都不读取或同步实际武器 `.tres`，只有图样槽引用落点资源。
- **Preview Distance M** 和 F6 后的“预览观察距离”都支持输入 **1000 米及更大值**，最小为 0.1 米，不按武器的 `Fire Range` 截断。旧版的 30 米上限来自预览控件本身；它已解除。远距离落点超出原视野时，三个面板同时扩大米制比例尺，查看网格上的米数判断实际覆盖大小。
- 检查器修改后 2D 预览自动更新。按 **F6** 后可滑动稳定度、修改观察距离，点击“试射”或按空格重新采样；运行时调整只影响本次试验，不自动保存回场景。空心圆是固定落点，实心点是本枪弹丸；算法仍与真实射击共用。观察距离仅决定显示哪个截面，与上文会改变枪械性能的“散布标定距离”分开。
- 预览是 Control 界面，3D 视图没有模型。若编辑器画面显示不全，可缩小 2D 编辑器缩放。自定义点位仍在图样资源的画板编辑；预览调参和采样不写入武器或图样文件。
- 打开 `scenes/presentation/shotgun_range.tscn` 按 **F6**：原玩家、相机和靶场的独立组合。右键瞄准、左键射击、R 换弹；1 是霰弹示例，2 是原副武器。训练靶的“命中次数”按整枪计，测试靶按实际命中弹丸累计扣血。离开靶区再进入可复位靶场。

## 图样资源

图样资源位于 `resources/weapons/patterns/`。它们最初以九点示例提供，点数和分布可在画板修改，当前落点以保存资源为准。

| 文件 | 图样 | 用途与取舍 |
| --- | --- | --- |
| `balanced.tres` | 均衡 | 默认引用的图样，用于比较各方向覆盖；当前点位由资源保存。 |
| `horizontal.tres` | 横向 | 左右展开、上下较窄，便于观察横向覆盖和多目标命中；远处单体容易漏掉两侧弹丸。 |
| `vertical.tres` | 纵向 | 上下展开、左右较窄，便于比较竖向目标覆盖；要考虑矮墙、头部和地面遮挡。 |

**Pattern → 弹丸落点画板** 对应资源的 `points` 数组，格式仍为 `PackedVector2Array`，原图样可直接复制和复用。每个二维点对应一颗弹丸：X 向右，Y 向上，`(0, 0)` 对应瞄准中心。点数就是弹丸数，无需另填一个可能不一致的数量。

坐标通常在 `-1～1`；乘原 `pattern_angle_degrees` 得到水平／垂直角偏移，现在该尺度可由“图样覆盖范围”的距离和面积标定。例如尺度 3°、点 `(1, 0)`，在垂直瞄准轴的 10 米平面上约向右偏 0.52 米。距离增加，实际覆盖自然扩大。保存新的 `ShotgunPattern` 资源并拖入 Pattern 即可复用。运行时忽略非有限坐标、限制坐标范围，最多使用 64 点；空图样回退到一颗中心弹丸。

## 瞄准如何影响霰弹

**固定落点不随精度缩放或整体偏移；稳定度改变每颗弹丸自己的偏差。** 每次射击各颗弹丸独立取样，不共用一次随机方向，也不再先抽“这一枪是否命中中心”。

| Shotgun 字段 | 初值 | 含义 |
| --- | --- | --- |
| 偏移方式（Spread Mode） | 随机偏移，编号0 | 编号1为不向圆心偏移；只约束每颗偏移方向，旧资源不自动切换。 |
| 图样覆盖范围（原 Pattern Angle Degrees） | 原尺度 3°、标定距离 4 m | 距离与面积共同决定固定尺度，显示实际角度；不改变已有默认弹道。 |
| Stable Jitter Degrees | 0.08° | 完全稳定时，每颗随机偏差的最大角度；设为 0 可以精确复现图样。 |
| Unstable Jitter Degrees | 0.55° | 稳定度为 0 时，每颗随机偏差的最大角度；在两端之间连续插值。 |
| Starting Stability | 0.65 | 初始稳定度；0 最不稳定，1 最稳定。 |
| 敌人霰弹恢复时间（Settle Seconds） | 1.2 秒 | 仅敌人：从初始稳定度恢复到1；初始为1时按0到1计算，另计等待。玩家统一使用武器的收敛时间。 |
| Shell Stability Loss | 0.18 | 每枪的稳定度损失，只扣一次。 |
| Stability Recovery Delay | 0.35 秒 | 新损失发生后，恢复前的等待。 |

同一组配置还提供移动、跟枪和下限参数，字段悬停说明解释各自含义。受击、压制、蹲姿缩减资格和切枪状态沿用原生命周期；玩家两种 Aim Mode 与敌人读取这组惩罚／等待／上限，玩家恢复公式与时间由武器资源的“瞄准与散布 → 玩家收敛”决定。霰弹模式下原中心概率与单弹散布角参数隐藏，避免同时调两套实际弹道。

原锁定准星的圆圈仍表示稳定度，不是弹丸覆盖边界。需要看真实图样，使用上面的图样实验台；实际弹道与伤害由三维物理射线决定。

## 一发一发装填

用户要求逐发装填配置放在 ShotgunSettings，并支持右键打断。当前实现的入口是 **Shotgun → 逐发装填 → Shell By Shell Reload**；只对 **Fire Mode = 霰弹** 生效。`ShotgunSettings` 的源文件是 [`scripts/weapons/shotgun_settings.gd`](../../movement_demo/scripts/weapons/shotgun_settings.gd)，图样资源类型则是 [`shotgun_pattern.gd`](../../movement_demo/scripts/weapons/shotgun_pattern.gd)。通常直接改检查器即可，无需修改脚本。

- 按 **R** 连续补入，每完成一发才增加弹匣弹量、扣一发备弹；满匣或备弹用完即结束。每枪消耗的是一发霰弹，不按弹丸数扣弹。
- **新按右键瞄准即可中断**，装填间隙或本发进行中都有效。已装好的保留，尚未完成的一发清零、不扣备弹；右键本身不会开枪。按住右键再按 R 仍能正常装填，需松开再按右键才中断。
- 已有余弹时，瞄准状态下新按左键也会中断并尝试射击，仍受原冷却等限制。空匣扣扳机不会自动取消装填。中断后再次按 R 继续补弹。
- 切枪、快速装填被奔跑中断等情况同样保留已入匣弹药，不保存原整匣模式的 50% 检查点。奔跑中按 R 仍按原慢速倍率装填；暂停不计时，对话等生命周期仍可取消。
- 容量继续用原 **Magazine Capacity**；开启后使用 **Shell Reload Seconds**，不使用整匣的 **Reload Seconds**。例如缺 4 发、每发 0.6 秒，正常补满需 2.4 秒；0.6 秒是当前默认值，可自行修改。
- 敌人也可开启同一配置。身体持续装填到满匣，原 AI 仍决定请求和取消时机；不会因为第一发装好就自动开枪。原规划与协调快照读取真实剩余装填时间，不新增霰弹专用决策。

默认关闭逐发装填，因此现有武器和示例仍保持原换弹行为。关闭时，原整匣换弹及玩家半程中断规则不变。当前没有装填动画或额外起手／收尾时长。

## 结算与边界

每枪只消耗一发弹药，执行一次冷却、射击惩罚、枪声和 `shot_fired` 通知。每颗弹丸各自被第一个碰撞体挡住，因此同枪可以命中多个目标，部分弹丸被挡不影响其他未被挡住的弹丸。

所有射线先查询完，再结算伤害。同一个前排目标即使被打死，也不会导致同枪后面的弹丸临时穿过它。同一目标的弹丸伤害合计后调用一次原受击接口，只施加一次命中干扰／减速；已经命中的目标不再重复吃近弹压制。其他目标取最近且无遮挡的实际弹道，每枪最多通知一次。命中特效按真实弹丸碰撞点表现。

玩家的区域、对话、翻越、近战占用、空弹匣、换弹和冷却限制继续生效。敌人仍通过原身体射击入口、兵种资格、瞄准、视野和 AI 请求开枪；屏幕外按敌人的 Offscreen Fire Chance 抽样，默认50%，每次合法机会按整枪判定；失败消耗间隔与点射机会，不扣弹药。此功能不新增个人 Utility、协调器策略或霰弹专用站位决策，也不实现新的伤害衰减或弹丸穿透。

## 配置值与代码职责

`resources/weapons/test_shotgun.tres` 和 `resources/weapons/patterns/` 是可编辑资源，弹匣、点数、点位均值和偏移模式以当前保存内容为准；三种图样名称表示用途，不保证编辑后仍保持初始九点或零均值。

WeaponData 保存开火方式与共用爆头参数，ShotgunSettings 保存霰弹配置，ShotgunPattern 保存固定点位；`shotgun_ballistics.gd` 共用采样／射线，双方战斗入口各自结算。检查器和预览只编辑／展示资源，运行逻辑不依赖编辑器。

## 验证

霰弹、偏移、逐发装填和图样检查器使用各自专项。已有部分旧测试假设固定点数、图样零均值、固定弹匣及 RANDOM 模式，用户编辑资源后会出现假设不一致；保留断言与差异，不把资源调参误说成新功能失败。记录见[测试说明](../testing.md)。
