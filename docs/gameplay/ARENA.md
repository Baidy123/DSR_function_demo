# 竞技场配置与试玩

`scenes/main.tscn` 实例化 `scenes/arena.tscn`。敌人在 `Arena/Enemy`，玩家进入区域后启用 AI，离场按区域规则复位。当前敌人结构与战术勾选见 [敌人模块化 AI](../enemy-ai.md)。

## 编辑场景

- 敌人身体、生命与武器在 `Enemy`；兵种资源在 `Enemy/UnitType`，训练资源和战术勾选在 `Enemy/Training`。
- `Enemy/AI` 协调运行，`Perception` 和 `Cover` 子节点提供感知与空间查询。动作按资源装配，无需逐个添加动作节点。
- 掩体位于 `NavigationRegion3D/Environment`，可以实例化 `scenes/world/cover.tscn` 添加。改动墙体、地板或掩体布局后，应重新烘焙导航。

半身掩体使用 `scenes/world/low_cover.tscn`，当前 Arena 的 `NavigationRegion3D/Environment/LowCover` 是绿色示例，原 CoverA–F 保留。预设宽 3 米、高 1.1 米、厚 0.6 米；根节点默认位于地面上方 0.55 米。它沿用原掩体节点与碰撞，可单独关闭 `Vault Enabled`。修改形状时同步网格与碰撞；查询按实际碰撞、缩放和朝向判定，过高、过厚、墙角空间不足、低顶或落点无地面都会拒绝翻越。

玩家、敌人和 NPC 站高为 1.75 米，Arena 导航资源按这一高度重烘。烘焙入口 `tests/bake_arena.gd` 保留导航资源原 UID；翻越路线是敌人动作提交的另一种路线，不把矮墙内部烘成普通可步行空间。

## 掩体与站位

高掩体碰撞盒提供四面躲藏区域和墙角攻击区域。半身掩体只保留包围墙体的一圈站／蹲共用带，不生成墙角扇环、内圈禁区或侧向 Peek 点；同一点可站起架枪、蹲下躲藏。`Wall Gap` 控制离墙间距，`Hide Depth` 控制环带宽度。编辑器与运行预览沿用同一几何，实际候选仍检查身体空间、导航可达性、遮挡和真实射界，并非线框内每一点都能站立。

半身掩体补充蹲藏与同一落点站起射击候选；实际姿态、枪口与视线各自检测。敌人绕行和一次翻越路线交给现有 Utility 评分，翻越期间没有攻击收益，执行仍会受伤。准确近距情报与两种压制的规则见 [敌人 AI](../enemy-ai.md)，不会因此把被墙挡住的玩家认作真实目击。

高掩体墙角区域几何与参数见 [ATTACK_POINTS.md](ATTACK_POINTS.md)。攻击占位在训练中开放后参与统一评分，旧版本的目击触发概率和固定优先级已被替代。低墙站姿射界检查已知头肩／躯干采样，避免只因躯干被墙挡住而漏掉能越墙射击的站位；真实开火仍复核当前枪口与可见目标。

## 试玩

按 F5 进入竞技场，观察交战、换弹、绕掩体、失视搜索及重新目击。游戏内 Debug 总开关可显示攻击候选、声音范围和敌人状态；需要时启用无敌。

当前验证入口见 [敌人测试](../enemy-tests.md)。CoverB 东北侧偶发卡住、视野边缘切换和整体手感仍按真实复现处理。
