# 玩家射击与武器调参

已修正[目标移动对玩家跟枪精度的影响](../superpowers/specs/2026-10-25-directional-tracking-accuracy-design.md)：平行靠近／远离不扣目标移动精度，并允许按原规则逐渐恢复到最准；斜向按有效横向部分计算，横向移动保留跟枪损失。只调整玩家侧，敌人自身瞄准和 AI 保持原规则。

在 **Player → Combat → 目标跟枪精度 → Tracking Parallel Tolerance Degrees** 调整平行免罚半角，默认15°（两侧合计30°）、范围0～45°；0使用纯横向投影。容差前后对称，超出后连续增加损失。原武器的慢速／高速每米跟枪参数与跟枪下限仍有效，玩家侧按有效横向距离和速度使用；概率、散布锥和霰弹共用这个方向规则。玩家自己的移动、开火和受击等待继续生效，目标前后移动不会瞬间恢复满精度。

之后再实现[概率爆头](../superpowers/specs/2026-10-25-headshot-mechanics-proposal.md)：玩家达到最准精度后，每次实际命中按武器概率触发伤害倍率，鼓励精准射击。已明确不分身体部位、不追加0.4秒等待、不强制等待敌人动作破绽；敌人射击保持现状。当前尚未实施。

## 霰弹（2026-10-25）

在原武器的 **Fire Mode** 选择 **霰弹**，展开自动创建的 **Shotgun** 配置图样与每颗伤害。当前为半自动，较长的原射击间隔可模拟泵动节奏。固定图样加各颗独立小偏差，稳定度不整齐缩放图样；同枪伤害按目标合计，附加干扰与扣弹等按整枪处理。两种原 Aim Mode 保留用于单弹，霰弹使用独立稳定度配置。具体操作、图样和试玩见 [SHOTGUN](SHOTGUN.md)。

## 锁定距离与画面范围（2026-10-25）

玩家武器的 **Aim Range** 现在默认同时决定锁定距离和正交相机范围，试玩主副武器初值为18米／22米。调整入口为 **Player → Equipment → 对应武器资源**；可关闭 `Camera Follows Aim Range` 恢复手动 Size。计算方式、切枪和窗口适配见[相机说明](CAMERA.md#当前用法锁定距离带动视野2026-10-25)。

目标必须在实际相机画面内，仍沿用原锁定距离、瞄准方向扇区、身体可见点及墙体射线规则。镜头扩大不会穿墙锁定，也不改变子弹 Fire Range。敌人离开画面即停火，回到画面后重新通过原反应、瞄准、冷却和弹药检查，详见[敌人 AI](../enemy-ai.md#血条视距与屏幕内开火2026-10-25)。

## 半身掩体、局部可见与蹲姿精度（2026-10-08）

实际观察点和枪口跟随玩家当前站蹲高度。自动锁定依次检查目标身体可见点，可锁定墙上方露出的头部；准星与射击方向使用同一个选定点。可见性从实际观察点查询，子弹仍从实际枪口发出并止于第一个碰撞物，因此能看见目标不保证枪口也能打到。完全被遮住时解除锁定，不保留旧准星点。没有姿态接口的旧固定靶仍使用原 0.8 米点位。

在 **Player → Combat → 蹲姿精度** 调整 `Crouch Accuracy Bonus`，用户确认默认 **0.25**，范围0～1，0关闭。完成蹲伏且不在翻越时，两种模式、准星和状态显示统一读取 `get_effective_accuracy()`：基础稳定度加0.25，封顶1；概率模式为加25个百分点，散布模式按该稳定度收拢半角。敌人不读取此参数。起身或翻越立即撤去加成，不改写基础 `accuracy`、武器资源或槽位保存值，连续蹲起不能累加。

换弹、完成帧及原恢复等待，近战受击精度损失及其恢复等待，优先于蹲姿加成。近战损失由攻击武器与受方倍率计算，不再绕过倍率无条件清零。切枪仍保存该枪的基础精度、恢复等待和加成禁用状态；普通开枪／移动产生的等待不单独禁用加成。临时站起越墙射击按实际站姿处理，开阔或背向矮墙的蹲姿射击可以获得加成。

翻越期间直接调用射击、近战或换弹入口也会拒绝；安全落地后沿用原冷却、区域与扳机规则。清除旧目标通过 `clear_target_lock()`，不借用会改变基础精度与扳机的 `cancel_aim()`。换弹半程与输入细则见 [AMMO](AMMO.md)、[PLAYER_FIRE_MODES](PLAYER_FIRE_MODES.md)，动作规则见 [MOVEMENT](MOVEMENT.md)。

## 命中、压制与击中减速（2026-10-24）

基础影响统一来自**攻击者武器**，在玩家 Equipment 或敌人 Weapon 展开 WeaponData 的“对目标命中与压制效果”配置。精度损失显示百分比、内部0～1，按百分点扣减：精度80%、武器命中损失20%、受方倍率×0.5，结果为70%。散布模式把同一稳定度映射到受方当前枪的散布角，不再使用玩家固定角度和敌人固定概率两套受击基础值。

| 攻击武器字段 | 脚本默认值 | 含义 |
| --- | --- | --- |
| 命中精度损失 `hit_accuracy_loss` | 15% | 子弹直接命中时的基础百分点损失 |
| 被压制精度损失 `suppression_accuracy_loss` | 2% | 真实敌方弹道擦过时的基础百分点损失 |
| 擦过检测范围 `near_miss_radius` | 1.5米 | 目标胸部到实际弹道线段的最大距离，0关闭检测 |
| 击中速度损失 `hit_speed_loss` | 50% | 子弹命中损失的自主速度比例，0关闭 |
| 击中减速时长 `hit_speed_loss_seconds` | 0.5秒 | 只由武器决定，受方倍率不改变时长 |
| 近战命中精度损失 `melee_accuracy_loss`（近战参数） | 100% | 附带／专用近战的独立基础精度损失，同样乘受方命中倍率 |

这些默认值是当前实现初值，不保证与旧3°／0.4°或用户原训练数值平衡等价。武器各字段和三个受方倍率在检查器均有说明与例子；自定义百分比控件也提供悬停提示。

**Player → Combat → 受击反应倍率** 和 **Enemy → Training → Profile → tactics → 受击反应倍率** 分别提供三个独立入口：`Hit Accuracy Loss Multiplier`、`Suppression Accuracy Loss Multiplier`、`Hit Speed Loss Multiplier`，默认均×1，×0免除对应损失、×0.5减半、×2加倍。射击与远程武器附带近战共用命中精度及速度损失倍率，压制倍率只处理真实弹道擦过。敌人倍率遵守原训练显式覆盖与本场装配读取规则，不在身体另存一份检查器配置。

速度倍率乘在“损失”上：武器减速30%×受方倍率0.5=只减速15%、保留85%自主速度。双方复用各自身体唯一减速状态，实际行走、奔跑、蹲行、锁定横移及原移动惯性受限；击退与重力独立。有效新命中覆盖强度并刷新武器时长，不叠乘；无减速的命中不清除或续期已有减速。擦过只影响精度和原敌人近弹警戒事实，不减速。暂停、对话、死亡及复位沿原身体生命周期处理，详见 [命中减速](MELEE.md#命中减速与击退2026-10-09)。

开火／近战起手时取得纯值武器快照，之后切枪或改资源不改变这一击。真实碰撞点截断弹道，墙后延长线、自己的弹道及同阵营弹道不参与；同发对直接命中目标不再叠加擦过，但仍可影响其他符合条件的敌方目标。精度损失最多降到0，沿用当前模式恢复等待，不被射击／移动下限瞬间抬高，固定角度武器也保持有限状态。

2026-10-24 追加确认：玩家走路时，如果受击、擦过等使散布超过武器的“移动最大散布”，经过原恢复等待后仍会按武器速度逐渐收拢到移动限制，不再因持续走路而永久停在最大散布。当前枪示例为移动时恢复到8°，停步且未瞄准时恢复到初始4°；瞄准停稳仍可收拢到最小散布。新的命中、擦过或射击会重新等待；正常移动仍逐米扩大散布，恢复不绕过移动／跟枪限制。概率模式使用同样规则，未瞄准不恢复到初始概率以上。

真实武器入口为 `receive_weapon_hit(damage, attacker_position, effects)`；附带近战使用 `receive_melee_hit(..., effects)`。通用 `receive_hit(damage, attacker_position)` 只保留生命与原命中通知，不再凭空追加武器精度或速度损失；Debug测试受伤按钮也是无攻击来源扣血。Debug无敌仍接收真实武器效果但不扣血，原有效命中信号继续打断医疗。旧角色损失字段、Cover擦过半径、旧FireController惩罚订阅及资源覆盖键已移除，不保留旧值回退。

成功开始换弹立即降到最低稳定度（散布模式为最大半角，概率模式为0%），整个换弹及完成帧保持最低，之后按原延迟与速度恢复。取消换弹不返还旧准度；满匣、无备弹等失败请求不降低准度。切槽仍各自保存准度和恢复等待。概率模式初始为100%时，恢复按 `Stabilize Seconds` 内从0到100%计算，避免新惩罚触发后恢复速度为零。

玩家快速换弹可被奔跑中断；奔跑／切枪是否取消或保留半程，遵循 [换弹规则](AMMO.md)。保留半程期间禁止使用匣内余弹，停跑或切回后按原快慢方式继续；恢复执行时同样保持最低准度。

换弹自身导致的最低准度与恢复仍独立于三个受方倍率。维护边界及结构验证见 [敌人 AI](../enemy-ai.md) 和 [回归说明](../enemy-tests.md)。

## 在哪里切换模式（2026-09-19）

选中 **Main → Player → Combat**，在 **Aim Mode** 选择旧概率模式或新散布锥模式，再展开下方 **Weapon** 资源：

## 两种模式怎样工作

两种模式共用右键瞄准、左键单发、自动锁定、惩罚/等待/恢复流程，以及射线碰撞和伤害结算。**输入参数分别保存、按模式读取，修改一种模式的专用参数不会影响另一种。**

- 概率模式先决定是否直射中心，否则在距中心8°～20°的三维范围内随机偏转。HUD显示中心概率，不保证最终命中。
- 散布锥模式每枪都在完整三维锥内按立体角均匀随机取方向；越稳定锥越小。角度输入由代码换算成内部稳定度，你不需要换算。HUD仍显示稳定度，50%稳定度不等于50%命中率。
- 弹道是瞬时射线，只处理第一个碰撞物，支持瞄A打B，不穿墙。有无锁定都使用当前模式。
- 切换模式不清空当前稳定程度、锁定或冷却。基础combat.tscn与主场景均使用现有v3，以上模式选择针对主场景Combat。

两模式均保留原圆形准星和四向短线：稳定时收缩/变绿，移动和连射时扩大。它提示稳定程度，不投影实际散布截面，弹道仍是三维的。

## 散布锥参数

角度均指**半角**：瞄准中心轴到锥边的夹角。实际值限制在最小/最大半角之间；最大值小于最小值时按最小值处理。最小为0°时可完全收拢，大于0°时始终保留随机散布。

| 检查器名称 | 含义 | 当前测试枪 |
| --- | --- | --- |
| 最小散布半角 | 完全稳定时仍保留的散布 | 3° |
| 最大散布半角 | 最不稳定时的总上限 | 24° |
| 初始散布半角 | 装备后、松开瞄准后的散布基准 | 12° |
| 每秒收拢角度 | 停稳且等过延迟后，每秒缩小多少度 | 9.5°/秒 |
| 移动最大散布 | 玩家移动逐渐扩大到此半角；已更散则保留 | 16.4° |
| 玩家每米扩大角度 | 玩家实际水平移动每米增加多少度；0表示不增加 | 3°/米（试玩值） |
| 每枪扩大角度 | 本枪结束后增加多少度，影响后续射击 | 0.95° |
| 连射最大散布 | 仅连射惩罚能扩到的上限，不收拢其他来源的更大散布 | 12° |
| 收拢等待时间 | 停步、停火后多久开始收拢 | 0.4秒 |
| 慢速/高速目标每米扩散 | 玩家锁定目标每产生1米有效横向位移增加多少度 | 0.19° / 0.95° |
| 跟枪最大散布 | 仅跟枪惩罚能扩到的上限 | 9° |
| 高速目标速度 | 玩家按有效横向速度选择慢/高速每米惩罚；敌人沿用原目标速度 | 6米/秒 |

表内保留用户最新角度调参；新增每米惩罚为可调试玩值。索敌总角度45°是另一项共用参数，不是散布角。

概率模式的数值在检查器显示为0～100%，资源和代码保留原0～1存储以兼容已有数据。比如面板的每枪降低5%，资源中的shot_accuracy_penalty仍保存0.05。

## 玩家移动时逐渐增加惩罚

两种模式都按实际水平位移累积，移动一小步只增加相应的一小份惩罚，不再立刻跳到移动限制值。顶墙和原地转向没有位移，不增加；同样距离的惩罚相同，因此跑得快时每秒增加更多。正常移动惩罚保留原恢复等待；若正在恢复额外损失，停步不重新开始等待。

散布锥调整“玩家每米扩大角度”，默认3°/米；旧概率调整“玩家每米降低概率”，默认15个百分点/米（例如80%走一米变65%）。各自达到“移动最大散布”或“移动惩罚概率下限”后停止累积，不瞬间抬高其他来源已经造成的更差精度；更差部分经过等待后允许逐渐恢复到移动限制。0可关闭移动的额外累积。

移动恢复修复的定向验证：`aim_disruption_test` 由修复前47/57变为57/57，包含真实玩家持续走路、命中／擦过等待、两种模式、移动上限、左上角显示及停步初始值；原 `player_move_spread_test` 14/14通过。未瞄准的帧尾恢复不再略微越过初始精度。相关检查器属性文档和自定义数值控件的悬停提示同步说明恢复规则。

本次新增移动距离14项、散布回归27项、独立参数16项，共57项运行检查通过；实际检查器26项断言通过。试玩时先站稳瞄准，再短距离走动，观察准星逐步扩大；切换两种模式并调整各自每米惩罚比较速度。
