# 玩家射击与武器调参

## 换弹、受伤与近弹（2026-09-29）

玩家在 **Main → Player → Combat → 受击准度** 调整 `Damage Spread Degrees`（默认 +3°）与 `Nearby Shot Spread Degrees`（默认 +0.4°），均指散布半角增量，0可关闭。`Nearby Shot Radius` 默认 1.5 米。直接命中通过 Health 的 `hit_received` 信号触发，不以实际扣血为条件；Debug 无敌时仍施加惩罚，测试受伤按钮也可验证。无效伤害参数与死亡后的命中不触发。近弹依据敌方子弹实际碰撞截断后的弹道，墙体隔开、自己的射击和同一发直接命中不会再叠加近弹惩罚。

内部沿用已有稳定度，角度增量按当前武器最大/最小半角差换算，最多扩大到最大半角；固定角度武器不会除零。旧概率模式保留，同样按这个角度差换算稳定度损失。新惩罚沿用当前模式的恢复延迟，不受“每枪下限”或“移动下限”抬高。

成功开始换弹立即降到最低稳定度（散布模式为最大半角，概率模式为0%），整个换弹及完成帧保持最低，之后按原延迟与速度恢复。取消换弹不返还旧准度；满匣、无备弹等失败请求不降低准度。切槽仍各自保存准度和恢复等待。概率模式初始为100%时，恢复按 `Stabilize Seconds` 内从0到100%计算，避免新惩罚触发后恢复速度为零。

玩家快速换弹可被奔跑中断；奔跑／切枪是否取消或保留半程，遵循 [换弹规则](AMMO.md)。保留半程期间禁止使用匣内余弹，停跑或切回后按原快慢方式继续；恢复执行时同样保持最低准度。

敌人使用概率而非玩家角度参数：Training → Profile → tactics 中 `Damage Accuracy Penalty` 默认0.15、`Nearby Shot Accuracy Penalty` 默认0.02，分别为15和2个百分点。维护边界及结构验证见 [敌人 AI](../enemy-ai.md) 和 [回归说明](../enemy-tests.md)。

> 2026-09-20：主、副武器现在由 Main/Player/WeaponSlots 配置，1/2或滚轮切换；Combat仍选择瞄准模式。槽位资源展开后显示两组参数，按Combat模式调整对应一组。见 [WEAPON_SLOTS.md](WEAPON_SLOTS.md)。下方直接展开Combat/Weapon的说明保留用于单武器配置与模式过滤介绍。

## 在哪里切换模式（2026-09-19）

选中 **Main → Player → Combat**，在 **Aim Mode** 选择旧概率模式或新散布锥模式，再展开下方 **Weapon** 资源：

- 共用参数一直显示：伤害、射程、索敌范围、射击间隔、锁定移动倍率。
- 旧概率模式只显示概率参数，面板直接输入百分比，例如每枪降低5%。
- 新散布锥模式只显示角度参数，例如每枪扩大0.95°、每秒收拢9.5°。

模式已从Player移到Combat。当前主场景使用用户最新选择的新散布锥模式；新建Combat脚本实例也默认新散布锥模式。直接在文件系统里打开test_pistol.tres时，没有Combat的模式上下文，因此显示两组；要按模式调参，请在Combat下面展开Weapon。

中文名称、百分比输入和自动隐藏由工程自带的 weapon_mode_inspector 编辑器扩展提供，已在项目设置中启用。修改的仍是真实武器资源，支持原生撤销/重做；修改后Ctrl+S保存。

## 两种模式怎样工作

两种模式共用右键瞄准、左键单发、自动锁定、惩罚/等待/恢复流程，以及射线碰撞和伤害结算。**输入参数分别保存、按模式读取，修改一种模式的专用参数不会影响另一种。**

- 概率模式先决定是否直射中心，否则在距中心8°～20°的三维范围内随机偏转。HUD显示中心概率，不保证最终命中。
- 散布锥模式每枪都在完整三维锥内按立体角均匀随机取方向；越稳定锥越小。角度输入由代码换算成内部稳定度，你不需要换算。HUD仍显示稳定度，50%稳定度不等于50%命中率。
- 弹道是瞬时射线，只处理第一个碰撞物，支持瞄A打B，不穿墙。有无锁定都使用当前模式。
- 切换模式不清空当前稳定程度、锁定或冷却。基础combat.tscn仍引用旧v2，主场景覆盖为v3；以上模式选择针对主场景Combat。

两模式均保留原圆形准星和四向短线：稳定时收缩/变绿，移动和连射时扩大。它提示稳定程度，不投影实际散布截面，弹道仍是三维的。

## 散布锥参数

角度均指**半角**：瞄准中心轴到锥边的夹角。实际值限制在最小/最大半角之间；最大值小于最小值时按最小值处理。最小为0°时可完全收拢，大于0°时始终保留随机散布。

| 检查器名称 | 含义 | 当前测试枪 |
| --- | --- | --- |
| 最小散布半角 | 完全稳定时仍保留的散布 | 3° |
| 最大散布半角 | 最不稳定时的总上限 | 24° |
| 初始散布半角 | 装备后、松开瞄准后的散布基准 | 12° |
| 每秒收拢角度 | 停稳且等过延迟后，每秒缩小多少度 | 9.5°/秒 |
| 移动最大散布 | 玩家移动逐渐扩大到此半角；已更散则保留 | 16.4° |
| 玩家每米扩大角度 | 玩家实际水平移动每米增加多少度；0表示不增加 | 3°/米（试玩值） |
| 每枪扩大角度 | 本枪结束后增加多少度，影响后续射击 | 0.95° |
| 连射最大散布 | 仅连射惩罚能扩到的上限，不收拢其他来源的更大散布 | 12° |
| 收拢等待时间 | 停步、停火后多久开始收拢 | 0.4秒 |
| 慢速/高速目标每米扩散 | 锁定目标每移动1米增加多少度 | 0.19° / 0.95° |
| 跟枪最大散布 | 仅跟枪惩罚能扩到的上限 | 9° |
| 高速目标速度 | 达到此速度使用高速每米惩罚 | 6米/秒 |

表内保留用户最新角度调参；新增每米惩罚为可调试玩值。索敌总角度45°是另一项共用参数，不是散布角。

概率模式的数值在检查器显示为0～100%，资源和代码保留原0～1存储以兼容已有数据。比如面板的每枪降低5%，资源中的shot_accuracy_penalty仍保存0.05。

## 玩家移动时逐渐增加惩罚

两种模式都按实际水平位移累积，移动一小步只增加相应的一小份惩罚，不再立刻跳到移动限制值。顶墙和原地转向没有位移，不增加；同样距离的惩罚相同，因此跑得快时每秒增加更多。停步后仍经过原恢复等待时间再恢复。

散布锥调整“玩家每米扩大角度”，默认3°/米；旧概率调整“玩家每米降低概率”，默认15个百分点/米（例如80%走一米变65%）。各自达到“移动最大散布”或“移动惩罚概率下限”后停止累积，不覆盖其他来源已经造成的更差精度。0可关闭移动的额外累积。

本次新增移动距离14项、散布回归27项、独立参数16项，共57项运行检查通过；实际检查器26项断言通过。试玩时先站稳瞄准，再短距离走动，观察准星逐步扩大；切换两种模式并调整各自每米惩罚比较速度。
