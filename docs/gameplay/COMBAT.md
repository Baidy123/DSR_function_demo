# 玩家锁定、精度与射击配置

本页说明当前玩家战斗规则和武器调参。武器配置在 **Player → Equipment → Primary Weapon / Secondary Weapon**；Combat 保存瞄准算法、鼠标辅助和玩家受击倍率，负责执行当前武器。

[锁定操作](PLAY_GUIDE.md#两种锁定模式)、[开火方式](PLAYER_FIRE_MODES.md)、[弹药换弹](AMMO.md)、[霰弹](SHOTGUN.md)和[近战](MELEE.md)分别说明对应系统。Fire Mode、Aim Mode 与鼠标辅助开关不是同一个设置。

## 弹道算法与入口

在 **Player → Combat → Aim Mode** 选择概率模式或散布锥模式，再到 Equipment 展开槽内武器调参；直接打开武器资源可查看两组参数。Combat 不提供重复的 Weapon 配置槽。

- **概率模式**：先判断是否直射中心，否则在中心外 8°～20° 的三维范围内偏转；中心概率不等于最终命中率。
- **散布锥模式（默认）**：每枪在完整三维锥内采样，稳定度控制半角。50% 稳定度不表示 50% 命中率。
- 霰弹使用独立弹丸图样和稳定度参数；玩家三种分支共享收敛公式。
- 射线只处理第一个碰撞物；可以瞄 A 打 B，不穿墙。改变 Aim Mode 不清空锁定、准度或冷却。

模式对应字段由项目自带检查器过滤，修改的是实际资源，支持原生保存和撤销。

## 鼠标方向换锁

鼠标辅助默认开启，**按住右键即可使用，不要求先锁住敌人**。无目标时，以玩家位置为参照，朝敌人所在的屏幕方向拨动即可选敌；已有目标时，朝另一名敌人相对当前目标的屏幕方向拨动即可换锁，随后继续自动跟踪，无需把光标放在敌人身上。目标死亡后继续按住右键即可选下一人。

鼠标只补充主动选择：没有有效鼠标请求时，仍按角色当前朝向执行原自动选敌；不改朝向评分、保持锁定和失效后的自动重选规则，不新增自动近处优先。同一帧有有效鼠标选择时先受理它，避免自动选敌先抢走请求。无目标且拨动方向没有敌人时保持原朝向，不用鼠标驱动空转。关闭辅助后，鼠标选敌和换锁均停用；原方向键转向、自动锁定与跟踪继续有效。

鼠标辅助可选择玩家周围360°内、屏幕可见、武器锁定距离内且通过原身体可见点／视线检查的目标，不套用首次锁定锥角。一次拨动只搜索对应方向默认左右各45°，没有合格目标就保持原锁定。方向接近最佳角度5°内时优先选择距参照点屏幕位置最近的候选（无锁定用玩家，有锁定用当前目标），再按玩家距离及稳定标识打破平局；投影间距不超过4逻辑像素时忽略该候选关系。

在 **Player → Combat → 目标切换** 调整以下参数，使用原生开关／数值控件和中文帮助：

| 检查器字段 | 默认值／范围 | 含义 |
| --- | --- | --- |
| Mouse Target Assist Enabled | 开启／布尔 | 鼠标辅助锁定开关；关闭立即清理鼠标请求并释放捕获，已取得的锁定继续保持 |
| Target Switch Travel Ratio | 0.12／0.01～1 | 所需行程为参照点到候选的屏幕间距×本比例，再按上下限夹取 |
| Target Switch Min Distance | 10／1～100逻辑像素 | 近邻目标的最小行程，防止轻微抖动误切 |
| Target Switch Max Distance | 48／1～200逻辑像素 | 远目标的最大行程，不低于实际最小值 |
| Target Switch Half Angle Degrees | 45°／1～89° | 单次拨动搜索半角，与武器跟枪免罚半角无关 |
| Target Switch Turn Speed Degrees | 360°/秒／30～1080 | 主动换锁后平滑转身的速度，90°默认约0.25秒 |

继续移动即可累计下一次换锁行程，不要求停顿。每帧最多切一次，切换后丢弃本段多余位移，避免一次大输入在后续无输入时连跳；方向内无候选也会清掉当前段，可立即改向重试。旧固定行程和停顿重置接口已删除。内部0.12秒只让过期的小位移失效，0.15逻辑像素以内的单次噪声忽略，均不形成切换冷却。辅助开启且右键瞄准期间临时捕获鼠标，避免窗口边缘限制；无目标时也保持捕获并允许跨帧累计。目标死亡／失效清掉旧目标和旧手势，继续保持有效瞄准的捕获，不增加重捕获空窗；新移动从玩家位置选敌。松开瞄准、关闭辅助、切枪、暂停、对话、近战、翻越、玩家死亡、失焦或退场时清理并释放，界面获得焦点时也暂停手势并释放捕获。

接受换锁请求本身不重置准度、恢复等待、射击冷却、弹药及原换弹进度，并重建新目标的移动跟踪基准；两敌人间的位置跳变不计作移动。实际转身则逐帧损耗精度：用“实际转角（弧度）×玩家到目标的水平距离”换算跟枪位移，固定乘当前枪械的低速跟枪每米损失，不再按转身等效速度插值到高速项。真实目标横移仍按自己的速度在慢／快系数间插值；分别算出两项损耗后取较大值，沿用原最低精度和恢复限制，不双扣。小于原跟枪下限的精度不被抬高或继续扣低；该枪低速跟枪损失为0时主动转身不扣损，真实目标移动仍按原速度规则执行。武器跟枪免罚半角只影响敌人的位移分量，不作为主动转身的免费角度。目标立即选中，鼠标首次选敌和换锁后的转身均按设定角速度推进；转身中点击立即射击，按发射当帧的实时准度和角色当前朝向进入原弹道，不等转完、不冻结点击时准度。每帧继续追踪敌人的最新位置；遮挡、超距和死亡仍按原规则解除锁定。首次自动选敌和普通跟踪的转向保持原行为。转身期间只显示浅蓝色“转向中”括号，对准后恢复精度圆和新目标的爆头菱形；旧目标的破绽不会转移或被换锁消耗。结构、默认值来源与验证边界见[实施记录](../superpowers/specs/2026-10-27-mouse-direction-target-switch-design.md#10-实施记录2026-10-28)。

## 锁定距离与画面范围

玩家武器的 **Aim Range** 同时决定锁定距离和正交相机范围，具体范围读取当前保存的武器值。调整入口为 **Player → Equipment → 对应武器资源**；武器资源已移除独立相机视野分组，切枪过渡时间统一在相机上调整。计算方式、切枪和窗口适配见[相机说明](CAMERA.md#视野配置)。

目标必须在实际相机画面内，仍沿用原锁定距离、身体可见点及墙体射线规则。首次自动选敌保留原瞄准方向扇区；主动换锁使用上文的屏幕方向扇区。镜头扩大不会穿墙锁定，也不改变子弹 Fire Range。敌人屏外合法开火机会默认50%成功，可在敌人根节点 **Shooting → Offscreen Fire Chance** 调整；失败跳过整枪、不耗弹，但仍消耗原间隔和点射配额，屏内正常射击。原反应、瞄准、冷却、弹药和枪线检查继续有效，详见[敌人 AI](../enemy-ai.md#感知交战与搜索)。

## 散布与跟枪参数

角度均为半角。最小／最大值限定整体范围；初始值控制装备及非瞄准状态的恢复基准。移动、开火、跟枪各有自己的累积系数和限制，不会把其他来源造成的更差精度抬高。

| 字段类型 | 作用 |
| --- | --- |
| 玩家每米扩大角度／降低概率 | 按实际水平移动距离扣精度；顶墙无实际位移时不计 |
| 每枪扩大角度／降低概率 | 在本枪发射后结算，影响后续射击 |
| 慢速／高速目标每米跟枪损耗、高速目标速度 | 对真实目标的有效横向速度插值；主动鼠标转身固定使用当前枪械低速项 |
| 跟枪免罚半角（仅玩家） | 默认25°、可调0～45°；沿瞄准连线靠近／远离允许恢复，超出容差按横向分量损耗 |
| 移动／连射／跟枪限制 | 各来源只能扣到自身限制；受击造成的更差精度按原等待逐渐恢复 |
| 恢复等待 | 惩罚后开始恢复前的等待，与完整收敛时间分开 |

概率参数在检查器显示为百分比，资源中按0～1保存；角度参数按度输入。具体枪械数值读取当前资源，不用早期测试枪的数值代替。

## 瞄准收敛公式

在 **Player → Equipment → 武器资源 → 瞄准与散布 → 玩家收敛** 选择 **收敛公式**，再设置 **收敛时间（最大→最小）**。也可以直接打开武器 `.tres` 调整。已有锁定、受击、射击、换弹、移动和跟枪流程继续负责恢复资格；不增加另一套计时组件。

**玩家三种公式统一使用这一个时间**，玩家装备面板移除旧角速度、概率恢复时间与霰弹恢复时间入口，取消旧参数置灰／解锁逻辑。“恢复等待”另设同名子组，仍按模式显示；霰弹自己的稳定度恢复等待仍在 Shotgun 内。

敌人收敛使用独立的原算法接口：**瞄准与散布 → 敌人恢复（原算法） → 敌人概率恢复时间**，霰弹为 **Shotgun → 敌人恢复（原算法） → 敌人霰弹恢复时间**。仍按原初始值到最准的用时换算匀速恢复；原 AI 掩体估时继续读取原字段。玩家公式／时间不影响这些参数，敌人面板隐藏玩家收敛字段。独立打开共享武器或霰弹资源可编辑对应接口，标签明确作用对象。原散布锥角速度保存键也保留，但当前敌人身体使用概率模式，不读取它。

令 `x` 为完整收敛过程的进度，`M`、`m` 分别为最大／最小散布半角，散布为 `m + (M-m) × g(x)`：

| 收敛公式 | 剩余散布 `g(x)` | 效果 |
| --- | --- | --- |
| 线性 | `1-x` | 匀速收拢 |
| 二次 | `(1-x)²` | 前快后慢，接近最准时逐渐减速 |
| 指数 | `(exp(-k*x)-exp(-k))/(1-exp(-k))` | 前快后慢；指数强度 `k` 调整前后速度差 |

**时间是最大散布到最小散布的完整用时，不含恢复等待。** 当前状态从曲线对应位置继续，受击或开火不会重启一整段时间；移动／跟枪上限仍是限制，不会当成新的最准点。三种公式在相同完整时间到达终点；想增加等待最准的成本，可以选二次／指数并适当延长时间。例如最大6°、最小2°，线性1秒在0.60秒到3.6°、1秒到2°；二次1.6秒约0.59秒到3.6°、1.6秒到2°。这是比较模板，不是已写入资源的平衡值。

**玩家默认完整时间4秒，最小0.01秒**；这是实现默认值，不是用户指定的武器平衡值。已保存的正时间保留；缺少新字段、旧0标记或非法值使用4秒，不再回退旧速度。因此未设置过新时间的玩家武器需要按手感确认，不能声称旧玩家速度全部不变。指数强度默认3、范围0～10，接近0按线性处理；达到终点明确结束，不会无限接近却永远达不到。

三种玩家分支共用公式：散布锥控制散布半角，霰弹控制随机偏移的收拢，旧概率模式控制中心概率恢复。它们的惩罚、等待、初始值与移动／跟枪限制仍各自保存。现有武器资源的伤害、射程、概率和调参未批量改写。具体接口、兼容与验证记录见[实施设计](../superpowers/specs/2026-10-26-aim-convergence-models-design.md)。

## 玩家移动时逐渐增加惩罚

两种模式都按实际水平位移累积，移动一小步只增加相应的一小份惩罚，不再立刻跳到移动限制值。顶墙和原地转向没有位移，不增加；同样距离的惩罚相同，因此跑得快时每秒增加更多。正常移动惩罚保留原恢复等待；若正在恢复额外损失，停步不重新开始等待。

散布锥调整“玩家每米扩大角度”，默认3°/米；旧概率调整“玩家每米降低概率”，默认15个百分点/米（例如80%走一米变65%）。各自达到“移动最大散布”或“移动惩罚概率下限”后停止累积，不瞬间抬高其他来源已经造成的更差精度；更差部分经过等待后允许逐渐恢复到移动限制。0可关闭移动的额外累积。
## 半身掩体、局部可见与蹲姿精度

实际观察点和枪口跟随玩家当前站蹲高度。自动锁定依次检查目标身体可见点，可锁定墙上方露出的头部；准星与射击方向使用同一个选定点。可见性从实际观察点查询，子弹仍从实际枪口发出并止于第一个碰撞物，因此能看见目标不保证枪口也能打到。完全被遮住时解除锁定，不保留旧准星点。没有姿态接口的旧固定靶仍使用原 0.8 米点位。

在 **Player → Combat → 蹲姿精度 → Crouch Spread Reduction** 调整最大散布缩减比例 `n`，默认0.25、范围0～0.99，0关闭。合法蹲姿最大半角为 `max(最小半角, 最大半角×(1-n))`：最大4°、最小1°时，蹲下变为最大3°、最小仍1°。使用同一基础收敛进度映射到新范围，公式、时间、等待和基础状态不变；起身恢复原端点，连续蹲起不能累加。

霰弹只缩小“不稳定随机偏移”的最大值，稳定时偏移和固定图样不变。旧概率模式保留中心概率与8～20°失准弹道，取消原蹲姿概率加法。准星大小通过 `get_spread_stability()` 反映散布变化；颜色、Debug稳定度与爆头资格仍用 `get_effective_accuracy()` 的基础收敛进度，不把更小散布显示成已完成收敛。旧场景的 `crouch_accuracy_bonus` 自定义比例会读取为新缩减比例，保存使用新字段。

换弹、完成帧及原恢复等待，近战受击精度损失及其恢复等待，优先于蹲姿缩减。近战损失由攻击武器与受方倍率计算，不绕过倍率无条件清零。切枪仍保存该枪的基础精度、恢复等待和姿态收益禁用状态；普通开枪／移动产生的等待不单独禁用缩减。临时站起越墙射击按实际站姿处理，开阔或背向矮墙的蹲姿射击可以缩小最大散布。

翻越期间直接调用射击、近战或换弹入口也会拒绝；安全落地后沿用原冷却、区域与扳机规则。清除旧目标通过 `clear_target_lock()`，不借用会改变基础精度与扳机的 `cancel_aim()`。换弹半程与输入细则见 [AMMO](AMMO.md)、[PLAYER_FIRE_MODES](PLAYER_FIRE_MODES.md)，动作规则见 [MOVEMENT](MOVEMENT.md)。

## 命中、压制与击中减速

基础影响统一来自**攻击者武器**，在玩家 Equipment 或敌人 Weapon 展开 WeaponData 的“命中效果 → 枪击与压制”配置。精度损失显示百分比、内部0～1，按百分点扣减：精度80%、武器命中损失20%、受方倍率×0.5，结果为70%。散布模式把同一稳定度映射到受方当前枪的散布角，不再使用玩家固定角度和敌人固定概率两套受击基础值。

| 攻击武器字段 | 脚本默认值 | 含义 |
| --- | --- | --- |
| 命中精度损失 `hit_accuracy_loss` | 15% | 子弹直接命中时的基础百分点损失 |
| 被压制精度损失 `suppression_accuracy_loss` | 2% | 真实敌方弹道擦过时的基础百分点损失 |
| 擦过检测范围 `near_miss_radius` | 1.5米 | 目标胸部到实际弹道线段的最大距离，0关闭检测 |
| 击中速度损失 `hit_speed_loss` | 50% | 子弹命中损失的自主速度比例，0关闭 |
| 击中减速时长 `hit_speed_loss_seconds` | 0.5秒 | 只由武器决定，受方倍率不改变时长 |
| 近战命中精度损失 `melee_accuracy_loss`（近战参数） | 100% | 附带／专用近战的独立基础精度损失，同样乘受方命中倍率 |

这些默认值是当前实现初值，不保证与旧3°／0.4°或用户原训练数值平衡等价。武器各字段和三个受方倍率在检查器均有说明与例子；自定义百分比控件也提供悬停提示。

**Player → Combat → 受击反应倍率** 和 **Enemy → Training → Profile → tactics → 受击反应倍率** 分别提供三个独立入口：`Hit Accuracy Loss Multiplier`、`Suppression Accuracy Loss Multiplier`、`Hit Speed Loss Multiplier`，默认均×1，×0免除对应损失、×0.5减半、×2加倍。射击与远程武器附带近战共用命中精度及速度损失倍率，压制倍率只处理真实弹道擦过。敌人倍率遵守原训练显式覆盖与本场装配读取规则，不在身体另存一份检查器配置。

速度倍率乘在“损失”上：武器减速30%×受方倍率0.5=只减速15%、保留85%自主速度。双方复用各自身体唯一减速状态，实际行走、奔跑、蹲行、锁定横移及原移动惯性受限；击退与重力独立。有效新命中覆盖强度并刷新武器时长，不叠乘；无减速的命中不清除或续期已有减速。擦过只影响精度和原敌人近弹警戒事实，不减速。暂停、对话、死亡及复位沿原身体生命周期处理，详见 [命中减速](MELEE.md#命中减速与击退2026-10-09)。

开火／近战起手时取得纯值武器快照，之后切枪或改资源不改变这一击。真实碰撞点截断弹道，墙后延长线、自己的弹道及同阵营弹道不参与；同发对直接命中目标不再叠加擦过，但仍可影响其他符合条件的敌方目标。精度损失最多降到0，沿用当前模式恢复等待，不被射击／移动下限瞬间抬高，固定角度武器也保持有限状态。

玩家走路时，如果受击、擦过等使散布超过武器的“移动最大散布”，经过原恢复等待后仍会按武器速度逐渐收拢到移动限制，不再因持续走路而永久停在最大散布。例如武器的移动限制为8°、初始散布为4°，移动时可恢复到8°，停步且未瞄准时可继续恢复到4°；瞄准停稳仍可收拢到最小散布。新的命中、擦过或射击会重新等待；正常移动仍逐米扩大散布，恢复不绕过移动／跟枪限制。概率模式使用同样规则，未瞄准不恢复到初始概率以上。

真实武器入口为 `receive_weapon_hit(damage, attacker_position, effects)`；附带近战使用 `receive_melee_hit(..., effects)`。通用 `receive_hit(damage, attacker_position)` 只保留生命与原命中通知，不再凭空追加武器精度或速度损失；Debug测试受伤按钮也是无攻击来源扣血。Debug无敌仍接收真实武器效果但不扣血，原有效命中信号继续打断医疗。旧角色损失字段、Cover擦过半径、旧FireController惩罚订阅及资源覆盖键已移除，不保留旧值回退。

成功开始换弹立即降到最低稳定度（散布模式为最大半角，概率模式为0%），整个换弹及完成帧保持最低，之后按原延迟与速度恢复。取消换弹不返还旧准度；满匣、无备弹等失败请求不降低准度。切槽仍各自保存准度和恢复等待。玩家概率模式也按“玩家收敛”的统一时间与公式恢复，初始概率100%不会使受罚后的恢复速度变为零。

玩家快速换弹可被奔跑中断；奔跑／切枪是否取消或保留半程，遵循 [换弹规则](AMMO.md)。保留半程期间禁止使用匣内余弹，停跑或切回后按原快慢方式继续；恢复执行时同样保持最低准度。

换弹自身导致的最低准度与恢复仍独立于三个受方倍率。维护边界及结构验证见 [敌人 AI](../enemy-ai.md) 和 [回归说明](../enemy-tests.md)。

## 精准爆头

玩家按**开火前基础准度**计算爆头率，超过可调起始准度后线性增长，满准度实际命中必爆头。公式为 `clamp((准度 - 起始准度) / (1 - 起始准度), 0, 1)`，默认起点90%：90%准度为0%、95%准度为50%、100%准度为100%。不另设增长指数或概率公式选项，概率随时间仍受原瞄准收敛影响。满准度沿用1e-6浮点容差，界面数字取整不提前获得满概率。

无需追加等待、不要求击中模型头部；实际射线必须命中。蹲姿只缩小散布，不增加基础准度或爆头率。打空、墙体遮挡、超出射程没有补偿伤害，满准度也不保证实际命中。敌人射击和近战本身没有爆头奖励。

**怎么调：Player → Equipment → Primary Weapon / Secondary Weapon → 命中效果 → 精准爆头（仅玩家）**，或打开对应武器 `.tres`：

| 配置／公开字段 | 默认值 | 作用 |
| --- | --- | --- |
| 启用爆头 `headshot_enabled` | 开启 | 关闭后该枪不产生玩家爆头 |
| 爆头起始准度 `headshot_accuracy_threshold` | 90% | 范围0%～99%，从此处0爆头率线性增长至满准度必爆头；0不关闭，关闭使用上方开关 |
| 启用爆头秒杀 `headshot_instant_kill_enabled` | 开启 | 对没有爆头防护的敌人直接走原死亡流程 |
| 未秒杀时伤害倍率 `headshot_damage_multiplier` | ×3 | 关闭秒杀或敌人有防护时，总伤害为普通伤害的3倍 |
| 被爆头状态时长 `headshot_stagger_seconds` | 1秒 | 存活敌人的效果持续时间，0关闭状态 |
| 被爆头时保留移速 `headshot_movement_multiplier` | 0% | 0%不能走动、100%不减速；资源／脚本0.4表示保留40% |
| 被爆头期间精度上限 `headshot_accuracy_cap` | 0% | 状态内不能超过此精度；不会抬高更差精度，也不禁止开枪 |
| 连续状态刷新方式 `headshot_stagger_refresh_mode` | 保留较长剩余时间 | 可切换为按本次时长重新计时；两种均不累加 |

这些是脚本初值。旧固定 `headshot_chance` 已移除，不提供兼容字段。外部旧资源若用该字段的0值禁用爆头，应改用 `headshot_enabled = false` 并删除旧键。只改一把独立武器时先设为唯一或另存副本。

参数仍在 `scripts/weapons/weapon_data.gd`，不在 ShotgunSettings 重复保存。`get_headshot_settings(stability)` 返回本枪的启用状态、基础准度、门槛、伤害及反应快照；不再携带一份对所有目标通用的固定概率。`headshot_probability()` 是唯一线性公式，`headshot_resolver.gd` 按实际目标的破绽分别计算，准星通过 Combat 的 `get_target_headshot_chance(target)` 共用只读规则。运行时修改从下一枪生效，不自动保存资源。

**近战眩晕破绽：**玩家近战命中后，仅该敌人保存一次门槛倍率，默认0.8；实际射击武器的普通起始准度乘该倍率，再进入原线性公式，不改变玩家精度。例如普通80%×0.8=64%，82%准度对此敌人的爆头率是50%；默认普通90%×0.8=72%。倍率0时门槛为0，准度大于0就有概率；倍率1不降低门槛。首次有效玩家枪击消费机会，即使该枪未爆头、概率为0、关闭爆头或实际伤害为0；打空与墙挡不消费，时间仍流逝。时长复用近战的“眩晕持续时间”，当前眩晕期间不能反复近战续期或重获机会。参数、玩家排除和星环含义见[近战眩晕](MELEE.md#近战眩晕与爆头破绽2026-10-27)。

**敌人防护：Enemy → Training → Profile → 作战能力 → 爆头防护**。只有这一个复选框：关闭时允许秒杀，开启时免秒杀、改受倍率伤害；防护不免伤，也不免“被爆头状态”。个人模式读当前训练，团队按原本场冻结配置，需重新加载本场应用训练改动。不按敌人名称或头盔外观自动判断。

**被爆头状态：**倍率伤害后仍活着才进入。默认1秒内自主速度和精度为0，**仍允许开枪**；效果全部使用攻击武器参数。例如把保留移速改成40%、精度上限改成20%，就会按此执行。复用近战／枪击的受击减速与精度损失接口，不接管Utility AI或协调器、不强制取消当前动作；转向、换弹、姿态和近战仍继续。普通减速与本状态取较强者，精度不会因上限较高而被抬升。连续命中时强度读取新一枪，时长按刷新方式处理。结束后原减速继续、精度按原规则恢复。暂停冻结；死亡、复位、退场和对话清理，换枪不解除。重力、碰撞和外力保留；零移速下的翻越使用原安全落地过程。

**霰弹：**每枪对每个实际命中的目标只判定一次，不随命中弹丸数增加概率。某目标中了5颗、每颗8伤害，普通伤害40；爆头时，无防护且允许秒杀则死亡，否则默认受到120伤害，存活者进入一次状态。A有近战破绽、B没有时分别计算各自概率，并各至多消费一次机会。全部射线和所有目标结果在受击回调前冻结；重复交付同一结果无效，已复位的目标不会承受上一生命的冻结命中。每枪扣弹、后坐和开火通知保持一次。

**怎么看：**对当前瞄准目标的爆头率大于0时，原金色菱形出现并随概率升高收小；满基础准度时增加金色外光。受击、换目标、破绽消费或到期会重新计算，降至0便隐藏；原圆形准星仍表达散布。发光表示命中后必爆头，不表示忽略防护的必杀。实际触发才显示“爆头击杀”“爆头 · 硬直”或“爆头”，反馈保留0.65秒，关闭Debug也可见。暂停冻结；对话／玩家死亡优先清理，包括死亡自动暂停的情况。

训练靶仍只统计命中；没有敌人爆头接口的旧测试目标通过原受击接口获得倍率伤害与反馈，不模拟秒杀／状态。倍率不放大命中精度损失、减速、压制或枪声。结构与验收见[爆头设计](../superpowers/specs/2026-10-25-headshot-stagger-execution-design.md)。

## 代码职责与验证

`weapon_data.gd` 保存参数和纯数值公式；`player_combat_v3.gd` 处理输入、锁定、转身、精度、弹药与射击；`target_switch_gesture.gd` 仅累计鼠标净位移。`headshot_resolver.gd` 根据实际命中冻结结算，`lock_reticle.gd` 只读显示。

UI 使用 `get_effective_accuracy()`、`get_spread_stability()`、`get_target_headshot_chance(target)`、`is_turning_to_target()`；表现订阅 `shot_fired` 与 `headshot_resolved`。保持单一锁定、单一准度和逐枪结算入口。

按变更选择 `target_switch_test`、`directional_tracking_test`、`aim_convergence_test`、`combat_compatibility_test`、`headshot_test` 等专项。已知资源假设、编辑器退出诊断和验证范围见[测试说明](../testing.md)。
