## 4. 搜索职责拆分

主要文件：`actions/enemy_search.gd`；新增 `services/enemy_search_hints.gd`、`services/enemy_search_coverage.gd`及 UID。

1. 提示组件负责概率衰减及候选提示，沿用原来的随机采样顺序与信息边界；动作决定是否接受及切换阶段。

3. 不让辅助组件获取其他动作或反向拥有搜索动作，不引入资源中的共享运行状态。
4. 迁移有价值的搜索测试到对应公共接口；保留既有覆盖完成、失视证据、受阻恢复、提示衰减断言。

换弹接管测试原先要求开放所有避险选项时必定离开 reload 动作；隔离原始工程同样可出现合法的 reload/on_way 并使该断言失败。现在仅在“交给其他动作”的子用例固定为无掩体权限，仍要求真实动作切换、满3.5秒补弹且全过程禁射；后续真实掩体换弹用例恢复权限。瞬移玩家后先等待物理同步。游戏配置与评分规则没有为测试调整。

堵枪口测试会在敌人胶囊内添加动态墙。新增出生安全检查要求先完成合法出生，再加入该运行时障碍；否则测试表达的是“出生时已经嵌墙”。独立复测仍覆盖双压制候选、实际射击、动态封堵、其他可信掩体和出口射程。

历史 `tests/prototype_corner_comparison.tscn` 仍引用缺失的实验脚本，之前实施记录已说明，未据此删除用户原型；它不被游戏和正式回归引用。`tests/.weapon_mode_roundtrip.tres` 是测试即时生成的资源，不能误判为废弃引用。第三方插件、对话动态字段与有文档的音频预留均保留。以上为自动化验收，未宣称人工试玩或跨项目发布。
