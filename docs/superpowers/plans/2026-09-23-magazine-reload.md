# 弹匣与换弹实施计划

**目标：** 先完成玩家枪械弹匣与四类共享备弹，再接入敌人基础换弹循环，遵循现有兵种基础能力边界。

**已确认规则：** 每枪12发、正常换弹2秒；玩家四类备弹各36发，同类共用，各枪独立弹匣。玩家仅R换弹，双方允许移动转向；玩家按每帧is_sprinting以0.5或1倍推进，敌人固定1倍。玩家切枪／对话／死亡取消并保留原弹匣与备弹，再次换弹重新计时，普通受击不打断。敌人无限备弹，打空自动开始基础换弹，不新增找掩体动作。

**结构：** WeaponData保存AmmoType（步枪／手枪／冲锋枪／霰弹枪）、magazine_capacity、reload_seconds。新增weapon_ammo.gd普通RefCounted实例管理每枪弹匣、换弹进度和完成时的补充，不修改共享资源。玩家WeaponSlots持有四类备弹字典与各槽弹药实例，Combat引用当前实例；Enemy持有自己的无限备弹实例。UnitType资格、现有射击冷却／跟枪／战术权限继续生效。

**执行细节：** 每次成功开枪扣一发；空匣／换弹中拒绝开火，不产生伤害／枪声／射击惩罚。正常换弹补足缺口，原弹匣余弹保留，备弹不足则只补剩余备弹。玩家场外也可准备换弹，暂停停止计时；开始换弹清掉待发扳机，完成后需新按左键。敌人AI在激活且非对话状态检查空匣并调用基础接口，执行层只接受请求、不自动决策；死亡、刷新、换枪或失去枪械资格终止换弹。压制定时规则保持原状，换弹不消耗压制的成功射击次数。弹药与换弹状态显示在原武器栏／敌人状态文字，不增加美术动画。
