# 半身掩体、姿态与翻越实施计划

依据：[已审阅设计](../specs/2026-10-08-half-cover-posture-vault-design.md)。用户已明确要求开始，沿用三名 agent 在当前会话并行实施。以当前本地工程为基线，不拉取远端；原有未提交文件已在忽略的日志目录备份用于区分本次差异。

## 阶段与职责

1. 主 agent：共享只读角色空间、低墙翻越与近距关系查询，低掩体场景、角色和导航尺度、表现快照／外部模型回退。保留原节点、UID 和高掩体。提供几何专项和场景核对。
2. 玩家 agent：原玩家脚本内接入实际姿态、手动输入、按当前方向的掩体辅助、独立翻越执行、攻击与换弹互斥、精度加成及脚步倍率。扩展有效玩家回归和对应玩法 MD。
3. 敌人 agent：原身体／服务内姿态和翻越；现有动作、公共路径估计和 Utility 接入低掩体方案及一次翻越路线；真实感知、按需启用的准确近距情报和两种压制的统一证据。保持搜索模糊提示边界和原评分，维护敌人 MD 及专项测试。
4. 主 agent 整合：主场景低掩体、1.75 米角色与导航、相机地面跟随。执行完整敌人与玩家回归及表现、声音、几何专项；核对结构、实际行为和保存重载，修复本次回归后审查提交集合。

实施中用户最新补充的压制分类：半身掩体通过可调的 Utility 情境评分偏好，倾向直接压制玩家消失点或近距准确感知点；出口压制与其他合法行为仍参与比较，不做硬性排除。全身掩体维持原消失点／出口选择。敌人 agent 在原证据与评分流程内接入该规则，补充分类、偏好开关和保存重载、Utility 自主选择及真实弹道验证；不扩展随机概率或新的动作框架。

后续用户试玩反馈纳入本轮：低墙普通失视也获得点压制偏好；核查近距离准确情报的完整接续；在 `cover` 内加入附近低墙起身射击一轮后蹲回的有限循环。出口压制只接受可靠的冻结线索归属，无法确认时不选出口，不因当前出口不可用换选邻墙。翻越仅修现有衔接问题，不扩展复杂全局寻路。

用户进一步要求取消低墙四角攻击区域、改用外围一圈站／蹲共用带，并指出实战仍偏好空地。该修正继续在原几何、候选与评分接口内实施，核对实际本地10发连射／0.2秒射速等配置，补近墙头肩可射而躯干受挡的资格检查；不以仅修改测试武器的理想场景代替实际验证。

## 共用接口

- 身体只读：`get_eye_position()`、`get_muzzle_position()`、`get_visibility_points()`、`get_torso_position()`、`get_body_height()`、`is_crouching()`、`is_vaulting()`；返回实际世界坐标／姿态，不更改身体。`get_posture_body_height(crouched)` 和 `get_posture_*_position(crouched, feet)` 查询假定姿态；翻越预检与身体执行使用同一配置高度。
- `systems/character_geometry.gd`：`can_occupy(actor, feet, height, radius, ignore_characters=false)`，用于假定姿态空间校验。玩家与敌人分别持有状态、碰撞及执行进度。
- `world/low_cover_geometry.gd`：`aim_cover`、`query_vault`、`query_vault_at`、`sample_vault`、`proximity_cover`；翻越返回有效性、原因、墙体、入口、出口、轨迹点、时长与执行身高。规划可忽略角色动态占位，执行必须重新检验真实碰撞。
- 低墙保留原 `cover_region.gd` 入口，增加 `is_low_cover()`、`get_top_height()` 和候选的蹲姿／同落点站立信息；原候选键保持兼容。
- 表现增加 `crouch_amount`、`vaulting`、`vault_progress`；玩法驱动真实状态，外部动画不能推进身体或命中。
