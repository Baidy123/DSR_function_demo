# 敌人基础枪械能力限制

**目标：** 由兵种决定是否支持基础枪械操作，AI选择和实际执行共用检查，禁止近战绕过AI直接开火。

**实现边界：** UnitType新增`supports_firearms()`，当前仅Ranged返回true。Enemy新增`can_use_firearms()`，先排除死亡、禁射、无枪，再查询UnitType；缺少兵种时拒绝枪械操作，移动与转向仍可独立执行。瞄准与开火、普通交战与压制共用此入口。使用短查询与提前返回，不新增通用能力框架、动作资源或兵种脚本。

**技术：** Godot 4.7.2 / GDScript。
