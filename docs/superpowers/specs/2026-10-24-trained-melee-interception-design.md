# 可训练的近战堵截

状态：已按用户补充的“个人战术动作，放在训练配置里面”实现并完成三档定向行为验证。普通/强配合通过严格性能诊断；0级开启/关闭训练对照均超出原P99门槛，保留既有性能待办，详见[测试记录](../../enemy-tests.md#2026-10-24-可训练的近战堵截)。

## 用户要求

- 近战根据玩家移动路线尝试跑到前方堵截，混编时与后方远程火力配合。
- 适用于所有配合等级，不再只限强配合。
- 是个人训练解锁的战术动作，不能作为所有近战自动具备的基础行为。
- 保留统一动作遍历；控制额外运算，减少无关测试。

## 本次实现方案

在近战兵种战术目录加入 `melee_intercept`（近战堵截），默认行为和保存的个人训练不自动勾选。参数沿原 `melee_tactics` 配置，通过 Training 的 Action Overrides 编辑。

0级装配后参与个人 Utility；1/2级通过共同 `prepare_command_offers` 和校验入口提供纯值候选，由协调器统一选择。只有本场已训练成员才提出和接受堵截方案。此动作不自动包含短程突进；抢位使用自身的普通奔跑参数，后续短程突进仍由独立已训练动作竞争并遵守原冷却。

只从合法本人/共享目击中的位置、平滑速度和时间推测短段路线。每次至多两个时间点，用本区导航限制预测行程；导航绕行按路程截取，不能把玩家瞬移到墙后。优先排除静止、朝近战迎面而来、已经能出手、预测太旧、明显来不及到位的情况。堵点须有身体空间、完整可走路线、在预测穿越位置的近战距离内且无遮挡。

接近路线先经过预测通道侧方，再到侧前方的攻击位置，避免直线追上玩家背后就提前挥击。预期堵截收益由接敌时间和保持原追击时的预计追赶时间差产生，命令提案也计入节省的追赶暴露时间，经原共同评分比较，不强制命中每个预测点。开始后保持选中位置与原截止时间；明显折返、偏离预测通道、失视过久或到期退出。新观察可以否定预测，预测不能更新目击记忆、赋予开火/近战视线或记作已查区域。

任务使用已有接敌职责，但标记为有限抢位步骤，避免被普通接敌岗位收缩回玩家当前身边。挥击仍走原身体与近战控制器，有实时出手机会立即执行。沿途保持关注合法威胁，实际碰撞/通行继续有效。远程保留有效射界，整队组合继续排除身体和枪线冲突；不增加一个按堵截动作 ID 分支的协调器。

## 职责

- `enemy_melee_interception.gd`：有限观察预测、导航和可及时到达的几何计算，无任务或动作选择权。
- `enemy_melee_intercept_action.gd`：个人候选/执行与共同命令协议，持有有限计划与失败后的短暂重试间隔。
- `melee_intercept.tres` / `units/melee.tres`：登记可选训练动作，不改变现有训练勾选。
- `melee_tactics_settings.gd`：预测时间/距离、短暂失视期限、普通奔跑倍率、最小预计收益。

默认参数是实现选择：预测最长1.8秒/6米、短暂失视0.6秒、奔跑2倍、最小时间收益0.25秒；每次固定两个候选。正常步伐、武器距离与实际命中规则沿用已有资源。

## 验收边界

以同一实际混编场景覆盖0/1/2级，检查训练开关、真实前向抢位与命中、远程实际开火、转向退出及身体间距。纯观察合同另检查短暂失视/到期、噪声与共享目击，没有隐藏玩家身体可供查询；未将它称为完整墙后运行验收。按相同运行输入对照关闭训练的基线，记录整队耗时；不提高既有16毫秒 P99 / 50毫秒峰值诊断门槛，不以行为通过替代性能结论。原装配合同和统一动作协议定向检查通过，不展开兵种比例矩阵或全部地图回归。
