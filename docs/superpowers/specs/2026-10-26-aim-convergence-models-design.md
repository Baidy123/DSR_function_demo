日期：2026-10-26。状态：**已按用户后续“弄吧”授权完成代码与定向验证；手感和平衡数值待试玩。**

同日后续检查器整理：用户确认归并为六个一级分组，当前恢复入口为 **瞄准与散布 → 恢复**，爆头入口为 **命中效果 → 精准爆头（仅玩家）**。原字段与公式保持；玩家正数时间下旧速度输入置灰，独立资源／敌人保留编辑。下文原“瞄准收敛（仅玩家）”分组名是本阶段首次实现记录，现行路径与验证见[使用说明](../../gameplay/COMBAT.md#武器资源分组2026-10-26)。

## 1. 用户方向

- 收敛前段较快，较快进入能进行普通射击的状态；接近最准时可以放慢，增加追求爆头资格的等待成本。
- “模型”指线性、二次或指数等实际函数公式，不是只有快慢几档的数值预设。每把武器可在自己的资源检查器中切换候选公式。
- 界面采用容易理解的“收敛公式”和“收敛时间”；不先增加此前解释不清的“耗时倍率”。
- 蹲姿方向以用户最后的说明“让最大散布减小，不影响后续”为准：最大散布按 `1-n` 缩小，`0 ≤ n < 1`；最小散布以及后续采用的公式、时间和恢复限制不因蹲姿另行改变。不继续使用稳定度直接加25个百分点的方式。
- 用户以CS2帮助说明想要的感觉；这里不声称复现CS2内部公式、参数或完整射击机制。

“可用”需要结合交战距离、目标大小、散布与实际伤害判断，不能把界面80%稳定度直接当成80%命中率。爆头仍需真实命中及武器概率判定，满稳定度也不保证每枪爆头。

## 3. 候选函数模板

先用一段没有新惩罚、可以持续恢复的过程说明公式：`θ0` 为参考起始散布半角，`m` 为最小半角，`T > 0` 为这段参考过程的收敛时间，`t` 只统计原恢复等待结束后实际允许恢复的时间。

```text
x = clamp(t / T, 0, 1)
散布半角 θ(x) = m + (θ0 - m) × g(x)
```

| 检查器候选 | 剩余散布函数 `g(x)` | 过程 |
| --- | --- | --- |
| 线性 | `1-x` | 每单位时间收拢相同角度，作为原匀速行为的对照 |
| 二次 | `(1-x)²` | 前段较快，越接近最小散布越慢 |
| 指数 | `(exp(-k*x)-exp(-k)) / (1-exp(-k))`，`k > 0` | 前快后慢，`k`控制前后速度差异 |

三者均满足 `g(0)=1`、`g(1)=0`，并在区间内单调下降。达到终点时明确写入最小散布／完整稳定度，避免只无限接近终点而与爆头资格判断冲突。指数形式是有限区间的归一化函数，不是直接使用不断增长的 `exp(x)`。

`k`接近0时指数形式趋近线性。本轮实现默认3、范围0～10；小于0.001回退线性，非有限强度使用3。非法模型按线性，非有限状态／步长／速度不传播；零宽度散布映射不做除法。

### 3.1 公式与总时间要分开比较

**相同参考起点和相同 `T` 下，三种公式到达最准的时间相同。** 二次或指数本身不能让这个终点更晚；它们可以把前段变快，再允许把总时间适当拉长，使普通射击的等待基本保持，而最准状态更贵。

以下只演示这种关系：起始6°、最小2°；用3.6°作为一个比较点，不把它规定为所有武器的“能打”门槛。

| 到达散布半角 | 线性，参考用时1秒 | 二次，参考用时1.6秒 |
| --- | --- | --- |
| 3.6° | 0.60秒 | 约0.59秒 |
| 2.4° | 0.90秒 | 约1.09秒 |
| 2.0° | 1.00秒 | 1.60秒 |

上述角度与秒数均为示例，不写回现有资源，也不是最终平衡参数。最终按普通命中、弹药消耗、爆头机会和暴露风险试玩比较。

### 3.2 实际恢复不能每次重新计满一段时间

玩家可能从射击、受击、换弹或移动造成的任意精度开始恢复。不能每次损失后都重新等待完整 `T`，也不能重启曲线时抬高当前精度。

实现以当前剩余散布反求曲线相位，再推进实际允许恢复的时间。以完整“最大散布→最小散布”区间建立参考，可覆盖比武器初始散布更差的受击状态；初始武器位于该曲线的相应中段。移动／跟枪恢复上限仍是上限，不作为新的“最准点”。

检查器字段显示为 **收敛时间（最大→最小）**，提示说明当前状态只使用剩余时间。旧“初始→最准”秒数不直接复制为新参考时间，换算见第5节。

## 4. 蹲姿只降低最大散布

设站立最大散布为 `M`，最小散布为 `m`，蹲姿缩减比例为 `n`：

```text
蹲姿最大散布候选值 = M × (1-n)
合法蹲姿最大散布 Mc = max(m, M × (1-n))
0 ≤ n < 1
```

例如最大散布4°、最小散布1°、`n=0.25`，蹲姿最大散布变为3°，最小仍为1°。这里的4°是最大值，不把普通武器的“初始散布”和“最大散布”混为同一字段。

实现只替换弹道映射中的最大端点，沿用同一基础收敛进度。用当前基础散布得到剩余比例 `r`，再映射到蹲姿范围：

```text
r = (当前基础散布 - m) / (M - m)
蹲姿显示／实际散布 = m + (Mc - m) × clamp(r, 0, 1)
```

这是本轮采用的映射：改变最大端点，不把整条散布角度直接乘比例；基础稳定度、恢复延迟和曲线相位不被蹲姿写回或重置。站起恢复正常最大端点，并继续当前进度；连续蹲起不能累计缩减，不能给切槽状态写入永久加成。换弹、受击限制、翻越和临时站起越墙射击仍按原资格处理。

注意 `n < 1`只保证候选最大值不因乘法变成0；当最小散布本来大于0时，候选值仍可能低于最小值。最大端点需钳制，`M=m`时不得除零。**端点钳制或姿态造成的散布变小，不应直接当成基础收敛已经完成而发放爆头资格。** 实施时需将实际散布效果与基础收敛完成条件核对清楚，准星资格提示和伤害入口必须一致。

“不影响后续”指不额外改变所选函数、收敛时间、恢复等待或基础状态，不承诺站蹲两种不同散布幅度在每个瞬间拥有相同的角度变化量。实际射击与准星大小使用同一映射。

## 5. 武器资源入口与兼容实现

在原 WeaponData 检查器增加收敛配置，不另建装备或角色管理系统。入口为 **Player → Equipment → 对应武器资源 → 瞄准收敛（仅玩家）**。

| 字段 | 显示与语义 | 实现默认／范围 |
| --- | --- | --- |
| `convergence_model` | 收敛公式：线性0／二次1／指数2 | 缺省0，可随时切换 |
| `convergence_seconds` | 收敛时间（最大→最小），秒 | 默认0按原速度换算；正数覆盖玩家原速度 |
| `convergence_exponent_k` | 仅指数公式显示的曲线强度 | 默认3，范围0～10，近0线性回退 |
| `Combat.crouch_spread_reduction` | 最大散布缩减比例 `n` | 默认0.25，范围0～0.99，0关闭；运行时也钳制 |

新字段缺失时，线性＋时间0继续原匀速行为。任何武器都可选择其他公式；没有把某一类枪锁定在线性，也没有批量重写现有 `.tres`。

时间0时使用原 `get_aim_settings().recovery`：散布锥完整时间为 `(M-m)/每秒收拢角度`，概率／霰弹为归一化恢复速率的倒数。原速率0仍关闭恢复；初始最准的概率／霰弹保留原从0恢复到1的回退速率。正时间直接使用 `1/T`，与旧速度不叠加。共享 `get_aim_settings()` 数值与字典结构保持，敌人读取它的行为不变。

旧速度字段保留保存值，并在提示中说明与新时间的关系。原检查器的枚举控件改为通用 `RefreshingEnumProperty`，供 Fire Mode 与公式共用原生保存／撤销／重做及字段刷新；近战隐藏收敛配置。旧 `crouch_accuracy_bonus` 通过 Combat 的 `_set()` 读取为新比例，重存时使用新字段。原槽位禁用状态键保留，不新增运行状态或迁移场景节点。

## 6. 实施范围与现有职责

- `scripts/weapons/weapon_data.gd`：沿现有资源扩展静态公式配置与必要的纯值换算；不保存当前玩家恢复进度。
- `scripts/player/player_combat_v3.gd`：沿现有恢复入口消费公式，保留移动、跟枪、射击、受击与换弹限制；蹲姿只改变散布上限的表现／弹道映射，不用旧加法提前补满基础精度。
- `addons/weapon_mode_inspector/weapon_inspector.gd`：沿原插件提供下拉选项、数值提示与相关参数显示，不新增独立插件入口。
- `scripts/ui/lock_reticle.gd`：核对实际散布、准星收拢和爆头资格的含义，避免准星显示可爆头但射击入口不合格，或相反。
- 原槽位保存、生命周期清理、资源引用、脚本UID和场景路径保留；不新增另一套瞄准计时总控，不调整武器伤害、爆头概率、射程或敌人训练来配合新曲线。

本轮范围选择：玩家散布锥、旧概率和霰弹共用公式恢复；蹲姿作用于散布锥最大半角、霰弹最大随机偏移。概率模式没有连续角度区间，保留原中心概率＋8～20°失准弹道，取消旧的蹲姿概率加法。共享弹道采样器、固定图样、随机流及敌人恢复／AI不改。以上是实施选择，不是用户逐项指定的参数；最小半角或稳定偏移不为0时仍保留它。

## 7. 验证与试玩边界

必要验证围绕直接受影响的行为：

1. 公式起终点、单调性和有限时间到顶；不同帧率／大帧时间下结果一致，指数极限、零散布宽度与非法参数保持有限值。
2. 使用相同武器和实际交战距离，比较达到可用散布与获得爆头资格的时间；分别对照相同总时间与调整总时间后的效果，不以单次随机命中得出平衡结论。
3. 新惩罚从当前状态接续；暂停、移动／跟枪上限、换弹及完成帧、受击等待、切槽保存与死亡重开不被绕过。恢复延迟不重复计入或在低帧率下被提前吃掉。
4. 蹲姿只缩小合法最大端点，最小值与基础恢复不变；反复蹲起不累积，站起或翻越按原规则处理。未完成基础收敛时不能单靠蹲姿获得爆头资格。
5. 资源中切换公式及时间后能保存重载，真实检查器可编辑并支持撤销／重做；旧资源的线性对照保留原恢复速率，既有武器调参不被重写。
