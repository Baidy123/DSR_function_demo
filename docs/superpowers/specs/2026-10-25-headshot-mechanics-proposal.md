# 概率爆头：精准射击奖励

日期：2026-10-25。状态：**已实施，使用原武器资源配置，完成后移除 `_todo` 后缀。**

**后续扩展已实施：**当前默认10%概率，加入秒杀／训练防护／默认3倍兜底伤害，并将霰弹改为每枪每目标一次。按用户最新要求，被爆头状态只在身体层按攻击武器参数限制速度与精度（不禁射），保留原AI和协调器控制权。见[当前设计](2026-10-25-headshot-stagger-execution-design.md)。本文以下保留基础版本的历史方案与验证，不能用旧参数覆盖当前规则。

[方向跟枪精度](2026-10-25-directional-tracking-accuracy-design.md) 已先行完成，默认平行容差为15°半角。本轮根据用户“做爆头吧”实施下述已确认方向。配置与提示说明见 [COMBAT](../../gameplay/COMBAT.md#精准爆头2026-10-25)。

## 1. 用户已明确的方向

- 当前采用自动瞄准加随机弹道，不做身体部位分伤；本机制中的“爆头”是精准射击获得的概率伤害奖励。
- **达到最准的精度后，每次实际命中都有概率触发爆头。** 目的在于鼓励稳住后精准射击，抑制持续泼水。
- 不追加“满精度后再瞄准0.4秒”的等待，也不通过额外蓄力自动变成100%爆头。
- 不把头部实际命中、头部暴露、敌人换弹或近战收招设为这套基础规则的前置条件。
- 概率与伤害倍率可根据枪械不同。此前提出的50%与250%保留为起始讨论数值；250%表示总伤害为普通伤害的2.5倍。
- **先只让玩家对敌人产生爆头，敌人射击保持现状。** 双方共用武器资源时，也必须保持这项来源限制。
- 保留已有武器资源、节点结构、引用、UID 和用户调参，不为了爆头改造原武器框架。

旧稿推荐的头部暴露资格、动作破绽奖励及追加蓄力，不再作为当前方案或后续必须选择的选项。用户已明确选择概率奖励方向，不需要再次询问是否改为身体部位伤害。

## 2. 跟枪精度前置已完成

原先目标所有方向的移动都会扣跟枪精度，并限制恢复；现已按有效横向位移处理，前后移动能正常恢复。玩家自身移动、开火、受击及压制影响保留。本轮直接使用已有有效精度，不降低爆头资格门槛，也不加入额外等待。

## 3. 结算规则

当前实现遵守以下顺序：

1. 成功开火时取得本枪**开火前**的精度，不能先扣本枪后坐，再判断是否达到最准。
2. 维持原自动锁定、射程、散布和霰弹采样。最准也不等于必然命中：武器仍可能具有非零最小散布，霰弹仍保留图样及每颗偏差。
3. 原射线实际击中合格敌人后，才允许判定爆头。打空、打墙、未到射程都不能凭概率补出伤害。
4. 本枪达到最准时，每次合格命中读取该武器的爆头概率；未触发则是普通伤害。没有后续蓄力、连续盯住同一目标的额外等待或保证爆头的计时器。
5. 触发后将对应伤害乘武器倍率，只结算一次；扣弹、枪声、射速、后坐和受击干扰沿原流程。
6. 依据实际命中的敌人结算，不能把射线打到乙的伤害施加给原先锁定的甲；普通命中仍保留原“瞄甲打乙”的能力，不额外增加同一目标等待门槛。

判定值复用与准星一致的有效精度：概率／散布模式和霰弹均用归一化的稳定度，达到100%表示最准，包括原有合法蹲姿加成。这里的100%是**精度资格**，不是100%命中率，也不是100%爆头率。当前浮点容差为0.000001，不把门槛改成95%等新玩法数值。

## 4. 精准射击与连射的取舍

例：普通伤害25，爆头概率50%、倍率2.5。

| 开火前状态与实际结果 | 伤害 |
| --- | --- |
| 未达到最准，实际命中 | 25 |
| 达到最准，命中但未触发爆头 | 25 |
| 达到最准，命中并触发爆头 | 62.5 |
| 打空或被墙挡住 | 不对该敌人造成伤害 |

50%概率、2.5倍率意味着合格命中的平均伤害是普通命中的1.75倍。该计算不包括打空、恢复精度的时间和射速，因此不能直接当成整体每秒伤害提升75%。

原开火精度损失会让连续射击更难持续保持最准，停火／稳住再打更容易获得爆头资格。这种取舍直接利用现有精度系统，不需要新增按键或第二条瞄准条。

不额外规定“自动枪绝不能爆头”。如果某把武器的后坐、恢复及合法加成允许某一发开火前达到最准，那一发就应按同一规则获得资格。调平衡时核对这些现有参数与爆头收益，而不是暗中按枪种取消奖励。

## 5. 霰弹结算粒度已确认

用户最终选择**每颗实际命中的弹丸独立判定**。满精度时逐颗掷概率，再按目标合计普通／爆头伤害。先完成所有射线和随机判定，再调用各目标一次原受击接口，避免前面的死亡或回调影响这一枪剩余弹丸。

九颗全中且概率50%，至少一颗触发的概率约99.8%；这不表示整枪全部获得2.5倍，平均总伤害仍为原合格伤害的1.75倍。反馈使用“爆头弹丸 ×N”，N是该敌人收到的触发颗数。

用户关心开销：实现沿用原弹丸射线，只增加实际命中的概率抽样和计数；不增加物理查询或碰撞体，也不对每颗弹丸重复发送受击、压制和反馈。原图样最大64颗的边界保持，反馈每目标一次，最多保留12条短暂标记。独立随机流不会消耗或改变原普通散布／霰弹采样的随机状态。

## 6. 当前配置与反馈

原 WeaponData 的“精准爆头（仅玩家）”增加：

- `headshot_enabled`：默认开启。
- `headshot_chance`：默认0.5，检查器显示50%，各枪可独立调整。
- `headshot_damage_multiplier`：默认2.5，是总伤害倍率，不乘命中干扰、减速或压制。

上述是实现起始值，不是已确认的最终平衡。旧资源使用新增字段的脚本默认值，本次不改写现有武器、图样或关卡资源。近战参数和敌人射击分支不读取爆头设置。

原准星继续表示精度，满精度且概率大于0时增加金色小菱形；实际触发才显示金色命中标记和文字，关闭Debug也有效。反馈使用命中时的世界位置，不引用死亡目标；0.65秒后移除，暂停冻结，切枪／对话／玩家死亡清理。准星资格不承诺实际命中，也不表示物理头部命中区。

沿原 `receive_weapon_hit`／`receive_hit` 传递最终伤害；保留 `shot_fired(hit, stability)`，新增 `headshot_hit(world_position, pellets, shotgun)` 供表现使用。训练靶仍只计数，但提供相同反馈；测试靶和敌人仍按原生命接口扣血。
