# 概率爆头：精准射击奖励

日期：2026-10-25。状态：**机制方向已由用户明确，尚未实施；先修正玩家跟枪精度。**

本文依据用户最新说明修订原提案。当前优先事项是[目标横向移动与跟枪精度修正](2026-10-25-directional-tracking-accuracy-design.md)。本轮已明确只更新文档，下一步先改跟枪精度，再考虑爆头实现。

## 1. 用户已明确的方向

- 当前采用自动瞄准加随机弹道，不做身体部位分伤；本机制中的“爆头”是精准射击获得的概率伤害奖励。
- **达到最准的精度后，每次实际命中都有概率触发爆头。** 目的在于鼓励稳住后精准射击，抑制持续泼水。
- 不追加“满精度后再瞄准0.4秒”的等待，也不通过额外蓄力自动变成100%爆头。
- 不把头部实际命中、头部暴露、敌人换弹或近战收招设为这套基础规则的前置条件。
- 概率与伤害倍率可根据枪械不同。此前提出的50%与250%保留为起始讨论数值；250%表示总伤害为普通伤害的2.5倍。
- **先只让玩家对敌人产生爆头，敌人射击保持现状。** 双方共用武器资源时，也必须保持这项来源限制。
- 保留已有武器资源、节点结构、引用、UID 和用户调参，不为了爆头改造原武器框架。

旧稿推荐的头部暴露资格、动作破绽奖励及追加蓄力，不再作为当前方案或后续必须选择的选项。用户已明确选择概率奖励方向，不需要再次询问是否改为身体部位伤害。

## 2. 为什么先修正跟枪精度

现在敌人无论向哪个方向移动，目标总位移都会造成玩家跟枪精度损失；“目标仍在移动”还会限制精度恢复。敌人经常移动，玩家因此难以达到最准，再加一段满精度等待会使奖励更难触发。

应先让敌人沿瞄准连线靠近／远离时不扣目标移动精度，并允许按原规则恢复；斜向和横向跑动才产生对应的跟枪影响。玩家自身移动、开火、受击、压制等已有精度影响保留。

这项修正通过后，再检查实际战斗中精准射击的机会是否合理，然后加入爆头。不能用放宽爆头门槛或提高概率去掩盖跟枪恢复的问题。

## 3. 结算规则

按用户明确方向，后续实现应遵守以下顺序：

1. 成功开火时取得本枪**开火前**的精度，不能先扣本枪后坐，再判断是否达到最准。
2. 维持原自动锁定、射程、散布和霰弹采样。最准也不等于必然命中：武器仍可能具有非零最小散布，霰弹仍保留图样及每颗偏差。
3. 原射线实际击中合格敌人后，才允许判定爆头。打空、打墙、未到射程都不能凭概率补出伤害。
4. 本枪达到最准时，每次合格命中读取该武器的爆头概率；未触发则是普通伤害。没有后续蓄力、连续盯住同一目标的额外等待或保证爆头的计时器。
5. 触发后将对应伤害乘武器倍率，只结算一次；扣弹、枪声、射速、后坐和受击干扰沿原流程。
6. 依据实际命中的敌人结算，不能把射线打到乙的伤害施加给原先锁定的甲；普通命中仍保留原“瞄甲打乙”的能力，不额外增加同一目标等待门槛。

判定值建议复用与准星一致的有效精度：概率／散布模式和霰弹均用归一化的稳定度，达到100%表示最准，包括原有合法蹲姿加成。这里的100%是**精度资格**，不是100%命中率，也不是100%爆头率。具体浮点容差属于实现细节，不擅自把门槛改成95%等新玩法数值。

## 4. 精准射击与连射的取舍

例：普通伤害25，爆头概率50%、倍率2.5。

| 开火前状态与实际结果 | 伤害 |
| --- | --- |
| 未达到最准，实际命中 | 25 |
| 达到最准，命中但未触发爆头 | 25 |
| 达到最准，命中并触发爆头 | 62.5 |
| 打空或被墙挡住 | 不对该敌人造成伤害 |

50%概率、2.5倍率意味着合格命中的平均伤害是普通命中的1.75倍。该计算不包括打空、恢复精度的时间和射速，因此不能直接当成整体每秒伤害提升75%。

原开火精度损失会让连续射击更难持续保持最准，停火／稳住再打更容易获得爆头资格。这种取舍直接利用现有精度系统，不需要新增按键或第二条瞄准条。

不额外规定“自动枪绝不能爆头”。如果某把武器的后坐、恢复及合法加成允许某一发开火前达到最准，那一发就应按同一规则获得资格。调平衡时核对这些现有参数与爆头收益，而不是暗中按枪种取消奖励。

## 5. 霰弹只剩结算粒度需要明确

身体部位分伤不是候选。需要进一步确定的是“每次命中”对多弹丸武器按哪一层统计：

| 候选 | 结算方式 | 影响 |
| --- | --- | --- |
| 每颗实际命中的弹丸独立判定 | 满精度时逐颗掷概率，再按目标合计普通／爆头伤害 | 图样与遮挡保持，伤害波动较平滑 |
| 每枪对每个实际命中的敌人判定一次 | 将该敌人收到的本枪弹丸总伤害统一获得或不获得倍率 | 反馈简单，单枪伤害波动较大 |

这项尚未选定，不因文档提供候选就自动确定实现。每颗独立判定时，九颗全中且概率50%，至少一颗触发的概率约99.8%；这不表示整枪全部获得2.5倍，平均总伤害仍为原合格伤害的1.75倍。反馈和调参要避免混淆。

无论选择哪一种，都保留先查询所有弹丸、再处理死亡、按目标统一受击的结构；每枪只扣一发弹药、执行一次后坐，同目标不重复受击干扰。各敌人根据各自的实际命中结果结算，不能一次抽签就把未命中的敌人也算进去。

## 6. 后续配置与反馈建议

武器检查器建议集中提供启用、爆头概率、爆头伤害倍率；名称和是否采用独立配置资源留到实施阶段确定。50%／2.5倍是起始讨论值，各枪可调整，不在文档阶段改写任何现有资源。

准星继续显示原精度，达到最准时可增加简短的爆头资格提示；实际触发后再出现爆头命中反馈。提示不能承诺当前随机弹道一定击中，也不能把概率奖励画成真实头部命中区。

后续接入位置按现有职责：

- 原 WeaponData 保存武器参数。
- 玩家 Combat 在原射击流程取得精度与结算伤害；敌人射击分支不获得该能力。
- 原准星／命中反馈只呈现状态和结果，不决定弹道或倍率。
- 霰弹若选择逐颗判定，在“全部射线完成”和“按目标结算伤害”之间处理，不改变固定图样。
- 现有伤害接口保持兼容；训练靶是否提供对应的测试反馈，需要在实施时明确，不需要为它新增头部碰撞。

## 7. 后续工作顺序与验收

1. 先实施并验证方向性的跟枪精度修正，包括平行运动时能真正恢复到最准。
2. 再明确各枪起始参数及霰弹判定粒度，实施概率爆头与可理解的反馈。
3. 验证开火前精度门槛、普通／爆头伤害、概率0／100%、射线遮挡、瞄甲打乙、不同射击模式及多弹丸结算。
4. 验证玩家与敌人共用资源时只有玩家生效，以及原弹药、冷却、受击和生命周期不被重复触发或绕过。
5. 必要回归保留原断言；将仍存在的旧失败与新增问题区分，不以放宽门槛证明功能正确。

本阶段仅更新设计文档，没有实现跟枪修正或爆头，也没有执行上述未来运行验收。
