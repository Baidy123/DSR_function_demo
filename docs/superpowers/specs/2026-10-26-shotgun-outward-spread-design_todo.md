# 霰弹禁止向圆心偏移：准备修改的设计草案

日期：2026-10-26。状态：**仅整理文档，尚未实施、调参或完成玩法验收。**

本轮用户要求“写个文档准备改”，随后明确：“也不一定是向外散，反正别向着圆心散就可以。”本文以这条最新方向为准：弹丸仍可向侧面、斜外侧随机偏移，只排除朝图样圆心的方向。此前草案中的强制沿径向外扩和最低外扩量已移除。公式、字段名和验证样本是实现建议，不应写成用户已经逐项确认的要求。当前游戏仍使用原随机偏移算法。

相关说明：[霰弹使用说明](../../gameplay/SHOTGUN.md)、[原覆盖标定与独立预览设计](../plans/2026-10-25-shotgun-coverage-editor.md)、[玩家方向跟枪设计](2026-10-25-directional-tracking-accuracy-design.md)、[项目目录](../../project-layout.md)。

## 1. 用户提出的问题与目标

用户认为当前霰弹在不准确射击时仍可能向中心集中，因此不追求爆头时，瞄准打稳的收益不明显。最新要求是不朝圆心偏移，并不要求每颗都沿“圆心到原落点”的直线向外移动，也不要求每次必须偏离一段保底距离。

直观理解：先找到这颗弹丸在图样上的原落点，再看它朝向总圆心的方向。这个方向及其朝内的斜向不允许；沿两侧擦过去、斜向外侧或正向外侧都允许，偏移也可以很小。

目标是让稳定度影响普通身体伤害的有效输出：近距离快速开枪仍可用，中距离想命中更多弹丸需要打稳。评估依据应包含同距离的平均命中颗数和伤害分布，不能只因某次随机向内偏就断言腰射平均更强。

本轮只准备方案，不修改武器、图样、场景、脚本或玩家既有调参；后续实施再按本文核对接口并验证。是否给当前示例霰弹启用新模式、最终偏移强度和伤害差距，留给实际试玩决定。

## 2. 当前实现与保留范围

`ShotgunBallistics.sample_offsets()` 位于 `scripts/weapons/shotgun_ballistics.gd`，当前对每颗弹丸执行：

```text
基准角度偏移 = 图样点 × pattern_angle_degrees
最大随机偏差 J = get_jitter_degrees(当前稳定度)
实际角度偏移 = 基准角度偏移 + 圆盘内随机向量，向量长度不超过 J
```

圆盘扰动允许朝任何方向，边缘点可能靠近瞄准中心。放大 `Unstable Jitter Degrees` 会扩大扰动范围，也仍保留向内偏的可能。

以下边界继续有效：

- `ShotgunPattern.points` 和距离／面积标定定义基准图样。新模式不改写点位，不按稳定度缩放或平移整幅图样；每颗弹丸仍围绕自己的基准点随机偏移，只限制朝内方向。
- 稳定度仍由原移动、跟枪、开火、受击和恢复流程提供；按下瞄准不等于立即达到满稳定度。此次不另加瞄准计时或命中概率抽签。
- 玩家、敌人和独立预览共用同一弹道采样入口。射程、每颗伤害、整枪弹药／冷却、碰撞、近弹通知及爆头规则保持。
- 普通枪的概率模式和散布锥模式保持。小队协调器、训练装配、AI决策和场景节点结构不因本模式改变。
- 原资源路径、脚本UID、图样编辑器、标定参数与用户本地数值保留；不以默认模板覆盖当前武器。

## 3. 建议采用的模式与配置

在原 `ShotgunSettings` 的“霰弹图样”分组只添加一项配置，字段名暂定：

| 字段 | 建议显示与语义 | 建议兼容值／范围 |
| --- | --- | --- |
| `spread_mode` | **偏移方式**：随机偏移／不向圆心偏移 | 枚举0为原随机模式，1为不向圆心偏移；旧资源缺少字段时用0 |

保留 `Stable Jitter Degrees` 和 `Unstable Jitter Degrees`，继续控制完全稳定／完全不稳定时每颗弹丸相对基准点的最大偏差角度。新模式只收窄随机方向的允许范围，不额外叠加一次原圆盘扰动。

不增加最低外扩比例、保底距离或全图放大倍率。偏移量仍允许从0到原最大值；旧资源的随机数调用顺序和采样结果必须保持，不因新增模式自动改变已有枪械。

## 4. 禁止朝内的随机采样建议

### 4.1 中心与方向

“圆心”指图样坐标原点 `(0, 0)`，对应当前射击瞄准轴；不是所有弹丸点位的平均位置，也不是目标身体的位置。非对称图样同样使用这个固定原点。

每颗弹丸的基准角度偏移记为 `b`，此次随机偏移记为 `delta`。当 `b` 非零时，以 `normalize(b)` 为朝外参考方向，允许左右各90°内的偏移：两侧切向、斜向外侧、正向外侧均可。

验收条件是 `dot(b, delta) >= 0`，即偏移没有朝内分量；由此保证最终落点不会比基准点更靠近圆心。不能只检查最终距离：一次朝内的大偏移可能穿过圆心，落到另一侧更远的位置，但它仍属于被禁止的朝内方向。

当有效 `b` 为零时，没有可排除的朝内方向，沿用原360°圆盘随机偏移，允许很小或零偏移，不给中心弹丸增加强制离心距离。此规则同时覆盖图样中心点、图样缺失／清空后的中心一颗回退，以及标定面积为零导致所有基准偏移为零。避免归一化零向量；浮点零判断应采用明确的小容差，验证采用相同量级的数值容差。

### 4.2 稳定度与随机量

沿用现有 `get_jitter_degrees()` 对稳定／不稳定最大角度的校验和插值。下面是一套可直接验证的建议公式，角度单位均为度：

```text
J = get_jitter_degrees(当前稳定度)
非中心点：偏移方向 = b 的朝向 + [-90°, +90°] 内均匀随机角度
中心点：偏移方向 = [0°, 360°) 内均匀随机角度
偏移长度 r = sqrt(当前弹丸独立取得的 [0, 1] 随机数) × J
delta = 偏移方向的单位向量 × r
实际角度偏移 = b + delta
```

非中心弹丸在以自身基准点为中心、朝外的半圆盘中均匀取样，包含两个切向边界；中心弹丸仍在完整圆盘中取样。每颗一次生成合法方向，不用反复抽样直到合格，也不把所有朝内的样本压到边界堆成一条线。

预期性质：

- 非中心弹丸的偏移没有朝内分量，最终到图样原点的距离不会小于基准距离；偏移量位于 `[0, J]`，没有正数下限。
- 有正负两侧的切向分量，不能把合法方向退化成唯一的径向射线。少量、零偏移都是合法结果。
- 满稳定度仍保留 `Stable Jitter Degrees` 允许的小幅偏差；该值为0时准确回到基准图样。新模式不承诺非中心弹丸在满稳定度时与旧模式逐颗落点一致。
- 对同一组随机样本，稳定度降低时偏移长度和到圆心的距离不减；不同枪重新抽样，不保证低稳定度的每一枪都比高稳定度的每一枪更散。
- 同一枪各颗弹丸独立采样，尤其多颗中心点不能共用方向后重叠为一束。
- 建议每颗继续固定消费两次随机数，第一次供方向、第二次供半径。旧模式必须沿用原有算法和调用顺序，便于固定种子的兼容验证。

不增加额外的“全图放大倍率”。当前最大偏差上限仍是 `J`，原基准范围加最大偏差的保守边界应继续覆盖新模式；实施时仍需核对预览投影和玩家的范围估计消费者。

### 4.3 手感边界

本方案不要求每颗都强制离开基准点一段距离，也不主动制造一个空心弹圈。新模式仍可能打出接近原图样的一枪；这是保留小偏移的自然结果，不能为了消除这种情况偷偷加回最低外扩量。

禁止朝内只保证相对图样中心的几何关系。目标大小、偏心瞄准、距离、遮挡和多目标分布都影响命中，不能承诺每一枪伤害必然降低。先使用原最大偏差与稳定度参数试玩；设计目标是提高打稳的平均收益，不添加强制未瞄准减伤，也不改变爆头倍率来替代弹道调整。

## 5. 编辑器、预览与文件职责

新选项在原检查器提供中文名称和悬停解释，说明“允许侧向偏移，只禁止朝圆心方向”，支持原生撤销／重做、保存重载与只读资源；不创建新插件。

独立图样预览继续保持三个图样槽和自己的数值。增加独立的偏移方式，传入内部专用 `ShotgunSettings`，仍调用同一采样器；不读取实际武器配置。原稳定度滑块、观察距离和自动扩大视野继续使用，状态文字显示当前模式与最大偏移，空心点表示原图样，实心点表示本枪弹丸。编辑器与F6参数都需保持原保存规则。

## 6. 验收要求

### 算法与兼容

1. 原模式在相同配置、稳定度和种子下与修改前输出逐颗一致，包含零偏差；不修改旧资源来使测试通过。
2. 新模式使用非中心、中心、非对称、横向／纵向图样，在多个种子和稳定度下检查偏移的朝内分量不为正、偏移长度不超过 `J`、最终距离不缩小以及有限数值。必须观测到朝外轴两侧的侧向随机偏移，不能只实现径向外扩或只检查最终半径。
3. 稳定度覆盖0、1和中间值；覆盖最大偏差为0、稳定／不稳定上限相等及逆序输入的现有校正规则。确认合法偏移没有正数保底距离，切向和零偏移边界均合法。
4. 用相同随机序列验证稳定度下降时单颗偏移长度与到圆心的距离不减；中心点保留全方向随机、小偏移与零偏移，满稳定且稳定偏差为0时回到原点。
5. 覆盖空图样、缺失图样、零标定面积、多颗中心点和64颗上限，确认无除零、非有限方向、额外弹丸或整枪共享随机偏移。
6. 原 `directions()` 投影与实际射线一致，遮挡和前排目标挡住后排的原行为保留；一枪只扣一发和一次冷却、同目标合并伤害／一次干扰、爆头每枪每目标一次等原断言保持。

### 资源与实际调用

7. 真实检查器切换模式后可撤销／重做、保存重载；旧资源缺少字段时使用原模式，切换回去不丢失原参数，不在加载时重写共享图样。
8. 实际玩家和敌人射击都消费新模式；原跟枪、移动、开火与恢复仍决定稳定度，不根据是否按住瞄准直接强制满稳定。
9. 预览与真实采样在相同数值／种子下结果一致；预览参数与实际枪械双向隔离。编辑器2D与F6保存值一致，空槽、远距离自动视野和原图样编辑继续正常。

### 玩法收益

10. 先用固定目标尺寸、位置、瞄准轴和武器配置，对比旧／新模式及不同稳定度；记录平均命中颗数、零命中比例、全中比例和伤害分布。建议距离3／8／15米、每组至少1000枪、多个固定种子，属于验证方案建议。
11. 比较普通身体伤害时在测试副本关闭爆头，保持每颗伤害、图样和目标碰撞一致。覆盖正中与偏心瞄准，避免用爆头奖励或改变目标大小制造结论。
12. 用真实玩家操作补查静止未打稳、瞄准恢复、移动、跟枪和连续开火，记录每枪实际稳定度。未瞄准可能仍有初始稳定度，不能把“稳定度0”直接当成全部腰射表现。

算法通过与手感通过分别记录。目前没有已确认的“腰射减伤百分比”或固定命中差距；完成统计后选取近距仍有效、中距打稳收益清晰的参数，再由试玩判断。不得通过放宽既有验收或降低全部武器伤害掩盖本机制未达到目的。
