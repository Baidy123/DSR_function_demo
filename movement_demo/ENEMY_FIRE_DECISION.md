# 射击动作评分第一步

用户反馈持续移动让敌人一直稳不到70%而不开枪。本步让普通交火实际比较“稳枪”和“开火”两个动作的分数，选择得分更高者；70%成为精度偏好，不再是禁射门槛。

## 节点与参数

`Enemy/AI/Tactics/FireDecision` 挂载 `enemy_fire_decision.gd`，只负责评分，不直接操作身体或武器。Tactics 提供当前稳定度、本帧真实恢复收益、可见目标的距离；Actor 的 `can_fire()` 与 `try_fire()` 共用执行条件。

| 检查器参数 | 作用 | 试玩初值 |
| --- | --- | --- |
| Tactics / Fire Stability Target | 精度偏好，0.7代表70%稳定度；不是命中率 | 0.7 |
| FireDecision / Recovery Gain Weight | 精度确实正在恢复时，提高继续稳枪的分数 | 0.35 |
| FireDecision / Close Range Weight | 目标进入最小交战距离以内时，提高开火分数 | 0.35 |
| FireDecision / Wait Pressure Per Second | 具备射击条件而继续等待时，每秒提高开火分数 | 0.45 |

精度比例是“当前稳定度÷目标稳定度”，限制在0～1。开火分由精度比例、近距离压力、累计等待压力相加；稳枪基础分为1，再加当前恢复收益，精度越接近目标，额外等待收益越小。分数相同时开火。

因此静止、马上能稳下来的敌人仍倾向稍等；玩家持续移动或敌人自己移动导致精度不能恢复时，等待不再获得恢复收益，而开火压力持续增加，最终可在较低稳定度下射击。低精度仍扩大真实弹道散布，不额外提高命中率。当前是两项动作评分，尚未给走位、找掩体、搜索等所有行为统一评分，也没有替换导航。

## 保留的限制

- 评分前检查实际可见、射程、远程类型、玩家存活且非对话、当前战术允许开火；继续保留0.3秒反应、每轮3枪、轮后2.1秒暂停。
- 枪口必须完成首次跟准、身体朝向允许、冷却结束；这些尚未满足时不积累主动等待压力。丢失目标、进入禁射动作、死亡和刷新清理评分状态。
- 真正发射后清零等待压力，不按命中次数计数。掩护撤退沿用允许低精度开火的规则，并继续受所有必要条件限制。
- 分数只读取已经可见的目标；没有加入隐藏玩家定位、听觉检测或额外动作。

运行时可在远程检查器查看 FireDecision 的 `selected_action`、`fire_score`、`steady_score`、`wait_seconds`；NONE表示尚不允许参与决策，STEADY表示等待，FIRE表示本次选择射击。冷却等禁射阶段会清理评分，下一次具备条件时重新评估。
