# 声音逻辑与调试范围

玩家或敌人实际移动、成功开火时发出逻辑声音；没有播放音频。敌人的 Perception 只接受玩家发出的声音，忽略自己与队友。判断依据是实际发声节点，共用同一个声音或武器资源也不会混淆。

## 在哪里调

| 位置 | 参数 | 当前试玩默认值 |
| --- | --- | --- |
| Main/Player → 移动声音 | Movement Noise Radius | 玩家移动声半径 5 米 |
| Main/Arena/Enemy → 移动声音 | Movement Noise Radius | 敌人移动声半径 5 米 |
| 上述两个角色节点 | Movement Noise Interval | 持续移动每 0.4 秒发声 |
| 武器 `.tres`（例如 test_pistol、test_sidearm、enemy_test_pistol） | Shot Noise Radius／枪声半径（米） | 14 米 |
| Movement Noise 或 Shot Noise 展开的声音资源 | Occluded Range Multiplier | 隔墙半径倍率 0.4 |
| 同上 | Audio Stream | 预留音频接口，可留空 |

半径为直接 `@export` 参数：移动范围归角色脚本，枪声范围归 WeaponData，声音资源不再重复保存半径。玩家主／副武器也可从 Player/WeaponSlots 展开；敌人从 Enemy/Weapon 展开。

半径设为 0，或对应声音资源留空，就不产生该类声音事件。角色之间的移动半径独立；武器半径属于该武器资源，共用同一把武器资源的角色会使用同一半径。默认声音资源也是共享的，若要独立修改隔墙倍率或预留音频，请先将声音资源设为唯一或另存一份。

走路和奔跑暂时共用移动半径；只按真实水平位移发声，站立、原地转身、完全顶住墙不发出脚步声。被冷却拒绝的射击不发声。

## 怎样看声音范围

F6/F5 运行 Main 后，勾选右上角 **声音范围**：

- 玩家发声显示蓝圈，敌人发声显示橙圈。
- 实线外圈是无遮挡半径，虚线内圈是隔墙衰减后的半径。
- 圆环固定在发声瞬间的位置，0.4 秒内淡出；持续走动或连射会继续产生新圈。
- 关闭开关立即清除圆环，不影响真正的声音逻辑。

两个圆圈是范围参考，并非按墙裁切后的精确传播形状。实际判断会逐个检测敌人与声源之间的遮挡。例如移动声 5 米、倍率 0.4，无遮挡时 5 米内可听，隔墙时仅 2 米内可听。第一版只区分有无遮挡，不累计墙层数或模拟绕射。调试图形通过 debug build 检查限制，未做 release 导出验证。

## 敌人怎样调查

移动／开火基础执行 → 声音事件 → Perception 判断来源、距离和墙壁 → AI 决定是否调用已有 search 动作。没有新增动作资源，也不把感知写进动作库。

UnitType 的 Available Actions 必须包含 search，Training 的 Allowed Actions 必须允许 search；Training 的 Perception Hearing Enabled 可关闭听觉。真实目击、正在执行的躲藏／架枪／压制优先于声音。

敌人只记住发声位置，按现有导航绕墙调查；安静移动不会自动更新其记忆。调查不到目标后进入附近搜索，结束后恢复原巡逻。声音调查不使用隐藏目标追踪提示；死亡和离场刷新会清除记忆。竞技场未激活时不因声音启动。
