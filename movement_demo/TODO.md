## 当前代码入口

| 用途 | 实际入口 |
| --- | --- |
| 玩家移动／耐力 | Main/Player → player.gd |
| 主场景玩家战斗 | Main/Player/Combat → player_combat_v3.gd，支持 3D 散射和目标移动精度惩罚 |
| 独立战斗基础场景 | combat.tscn → player_combat_v2.gd，Main 中覆盖为 v3 |
| 武器参数 | weapon_data.gd / test_pistol.tres |
| 敌人感知、追踪、搜索与接敌 | Arena/Enemy → enemy_tactical_v8.gd |
| 掩体转移、躲藏与 peek | Arena/Enemy/Cover → enemy_cover_tactical_v9.gd |
| 掩体四面区域与 Peek | CoverA～CoverF → cover_region.gd；区域直接由掩体碰撞盒生成 |

在 Godot 中选中 Main 的 Player、Arena 的 Enemy 或 Enemy/Cover，在检查器中将鼠标停在脚本参数名上查看中文说明；武器参数展开 Combat 的 Weapon 资源查看。按 F6 可从 Main 运行，试玩锁定射击、绕掩体和离场刷新。
