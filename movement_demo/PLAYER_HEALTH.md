# 玩家生命、体力显示与战斗重开

更新：2026-09-20。

## 当前规则

- 玩家出生时满血，最大生命试玩初值为 100；在 Main → Player → Health 的检查器中调整 Max Health。
- 生命归零后停止移动、射击、对话与敌人运行，显示“重新开始”按钮。
- 点击按钮回出生点，恢复生命、耐力、敌人、靶子及武器运行状态。场景节点（包括门）恢复初始状态。
- NPC A 的答应／拒绝选择保留，重新找 A 不会重新提供已选过的选项。没有新增存档系统，退出游戏重新运行仍会清空本次对话选择。
- 本步没有新增敌人攻击、自动回血或受击硬直。

## 无敌与受伤测试

1. 打开 Main，选中 **Player → Health**，勾选 **Debug Invincible** 可设置启动时无敌。
2. 运行时也可在“远程 → Main → Player → Health”检查器切换，或点击右上角的 **Debug 无敌**。
3. 点击右上角 **测试受伤 -25**，通过玩家的统一伤害入口模拟一次受击。
4. 无敌会阻止扣血，但仍记录命中；不会回血，也不能把已经死亡的玩家复活。
5. 无敌及测试按钮仅供 debug 构建使用；release 构建隐藏按钮且忽略无敌设置。本轮未导出 release 版本。
6. 场景重开后，无敌恢复检查器保存的初始值；运行时临时勾选不作为存档保留。

## 体力条与输出日志

左下角集中显示生命（红色）和体力（青绿色）两条状态条及数值；对话时隐藏状态条，避免遮挡正文和选项。体力在奔跑时减少，休息时恢复。耗尽后显示“恢复中”，沿用回满才能再次奔跑的规则。这里只读取原有耐力状态，不改变消耗、恢复延迟或锁定参数。

Godot 的“输出”面板仍是日志入口，不新增文件日志或游戏日志窗口。耐力数值不再逐帧打印。当前自有脚本使用以下分类：

- `[玩家][受击]`：输入伤害、实际扣血、前后生命与最大生命。
- `[玩家][无敌]`：命中的伤害数值、“无敌，未扣血”和当前生命。
- `[AI][掩体]`、`[AI][搜索]`、`[AI][追踪提示]`：现有 AI 调试信息，保留各自的开关。仅整理当前使用的 v8 / v9，历史版本脚本未改。

无效伤害（非正数、NaN、无穷）及死亡后的重复受击不扣血、不重复输出有效受伤记录。致死伤害会把实际扣血限制在剩余生命，不记录负生命值。

## 代码位置

- `player.gd`：新增 `receive_hit(damage, attacker_position)`，转交 Health；`is_dead()` 供移动与战斗判断。删除旧耐力打印。
- `player_health.gd` / `player_health.tscn`：保存生命、无敌状态，显示生命/体力与死亡界面；死亡时暂停世界，但本节点为 Always，按钮仍可用。
- `player_combat_v3.gd`：死亡后不允许进入战斗或开火。
- `shooting_range.gd`：场景卸载也会触发离场信号，过滤已经出树的目标，避免重开时报错。
- `dialogue_ui.gd`：对话面板外的按钮点击交给 GUI，不会同时推进对话。
- 重开使用 `reload_current_scene()`，重新创建 Main；自动加载的 GameState 不会随 Main 重载，故保留对话选择。
