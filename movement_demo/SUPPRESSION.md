# 普通区域压制与掩体出口压制

## 已确定范围

用户选择先朝最后目击位置附近射击，压制3～5秒，压制中弹后找掩体；随后追加要求也实现、测试掩体出口／架枪区域压制，作为有条件的高训练专属动作。弹匣与换弹稍后讨论，整体行为选择优化应考虑这些动作，当前不搭新决策框架。

## 本步实现方案

- Tactics下新增SuppressionAction，与AttackPositionAction、CoverAction并列。首次失去真实视线时尝试启动；优先保留已有掩体动作，否则停止原攻击选位并原地压制。能力可关闭，默认开启供试玩。
- 保存消失前的last_seen_position，朝周围水平圆形区域选择胸部高度的瞄准点；范围半径暂用0.75米，可调，不代表最终手感。每次实际开火后换一个瞄准点，不追踪墙后玩家。
- 每次压制随机持续3～5秒，参数可调。沿用枪械射速、跟枪、散布、连射停顿和实际首个碰撞物伤害；压制不等待普通精准攻击评分。重新目击回交战，计时结束交给原追踪／搜索，死亡／离场／刷新清理。
- 真正受伤立即结束压制并尝试寻找掩体，这次不抽原近身来弹的躲藏概率。找不到掩体回普通接敌，不停在压制状态；同一伤害不再启动墙角选位。零伤害不打断；附近来弹仍按原躲藏规则处理。

## 出口压制的能力和条件

- `enemy_exit_suppression_action.gd`继承`enemy_suppression_action.gd`，只替换目标准备、目标有效性、瞄准点和状态文字。计时、重新目击结束、中弹找掩体、射击与复位共用。
- Tactics的`Can Suppress Fire`默认true；`Can Suppress Exits`默认false，是未来高训练配置提供的能力接口。尚未实现训练分类挂载，当前手动勾选测试；没有擅自定义某种兵种或训练等级。
- 从最后目击位置推测最近的邻近掩体，距离按碰撞盒表面计算，`Cover Inference Distance`暂用1.75米。推测并不保证玩家实际仍藏在该掩体后，不读取隐藏玩家实时位置。
- 使用该掩体原有墙角攻击区域的样本，只取长轴两端之外、枪口射界通畅且在武器射程内的位置。两端都存在合格候选才启用；每侧随机连续打2～5枪后再换边，同侧每枪重新选择区域内的瞄准点。仅实际开火计数，冷却或连射停顿不换边。总持续时间仍为3～5秒，结束时可以尚未打完当前侧的计划枪数。
- 缺少能力、附近没有掩体或两端不都可射击时，自动退回普通最后目击区域压制。出口动作运行时能力被关闭、所属掩体被移除或当前目标被障碍挡住则结束。两种压制不会同时运行。
- 本步没有给玩家添加被压制减速、准度惩罚或恐惧值，伤害仍由实际弹道决定。

## 在Godot中试玩

1. 选中`Arena/Enemy/AI/Tactics`，保持`Can Suppress Fire`开启。按F5进入竞技场，先让敌人看见，再绕到墙后。头顶显示“火力压制”，持续3～5秒；原连射停顿仍保留，并非一直无间隔连发。
2. 开启`Can Suppress Exits`再测试。符合邻近掩体及两端射界条件时显示“掩体出口压制”；否则仍显示普通压制。
3. 普通区域半径及持续时间在`SuppressionAction`调；出口推测距离、持续时间和`Shots Per Exit Min / Max`（每侧连续枪数，默认2～5）在`ExitSuppressionAction`调。继承显示的`Target Radius`仅用于普通圆形区域，出口动作使用掩体本身的攻击区域。
4. 压制过程中打中敌人，观察它结束压制并找掩体；重新出现在视野中时恢复交战。`AI/Cover → Debug Cover Selection`控制`[AI][压制]`开始／结束日志。

能力默认普通开启、出口关闭，试玩参数均可调整。具体手感仍待用户试玩；本轮没有继续实现声音、弹匣、训练分类或总体评分。
