# 弹匣、备弹与换弹

玩家按R主动换弹，打空不会自动换；敌人由AI在弹匣打空后请求换弹。双方换弹时都能移动、转向，不能开枪。

## 在哪里调整

| 位置 | 参数 | 作用 |
| --- | --- | --- |
| Main → Player → WeaponSlots → 初始共享备弹 | Starting Rifle / Pistol / Smg / Shotgun Ammo | 四类备弹的出生初值，脚本默认各36发；修改后重新运行生效 |
| WeaponSlots的主／副武器资源 → 弹匣与换弹 | Ammo Type | 步枪、手枪、冲锋枪、霰弹枪；同类主副枪共用一个备弹池 |
| 同上；敌人则展开Enemy的Weapon | Magazine Capacity | 弹匣容量，脚本默认12发；每把枪独立保存余量 |
| 同上 | Reload Seconds | 正常换弹秒数，脚本默认2秒 |
| Player → Combat | Sprint Reload Speed Multiplier | 奔跑中开始的慢速换弹进度倍率，默认0.5；整次耗时为快速换弹的两倍，途中停跑不加速 |

以上是已同意的试玩初值，后续检查器调参优先，未覆盖用户已有武器设置。弹匣出生时装满，这部分子弹不占初始备弹。武器类型不等于射击模式，单发／自动与弹药类型分别配置。

右下角原武器栏显示每槽`当前弹量/容量 · 备弹数量`，换弹时显示进度百分比和“快速／禁跑”或“慢速／可跑”。显示的是该武器所用类型的共享备弹，不是两份独立存量。

## 玩家规则

- R只在有枪、非死亡、非对话和非暂停时生效，场外也能准备换弹。满匣、无备弹或已经换弹时不重启。
- 按 R 成功开始时读取 Player 的 `is_sprinting`，整次换弹方式固定。非奔跑时开始＝快速换弹，期间允许步行与转向但禁止奔跑；奔跑时开始＝慢速换弹，允许奔跑，途中停跑也不会加速。此规则优先于此前的逐帧切换规则。
- 快速换弹限制实际移动速度，不能保留先前奔跑的高速惯性。完成或取消后解除禁跑；一直按住 Shift 且耐力允许时，下一次移动更新恢复奔跑。慢速换弹仍受原耐力与瞄准锁定的禁跑规则限制。
- 普通受击不中断。切枪、进入对话或死亡取消；原弹匣及备弹保持，重新换弹从零计时。暂停时不推进。
- 完成时只补足弹匣缺口，保留旧弹匣余弹；备弹不足则全部装入。未完成时不提前扣备弹。
- 切回武器保留弹量；共享同一个WeaponData的两槽也各有独立弹匣。开始换弹清理待发扳机，完成后重新按左键开火。
- 重新开始恢复配置的初始武器、满弹匣、四类备弹及其他场景初态，仍保留对话选择。

## 敌人规则与结构

`weapon_ammo.gd`是小型RefCounted弹药状态对象，负责消耗、计时和补充，供玩家与敌人共用；WeaponData只保存配置。玩家WeaponSlots持有四类共享备弹字典与各枪状态，Combat引用当前枪；Enemy自己持有无限备弹状态。

AI的`_update_reload_request()`只在竞技场激活且非玩家死亡／对话时，发现空匣就调用Enemy的`request_reload()`。基础执行不自行决定何时换弹，`update_weapon()`以固定速度推进；不新增动作库资源或训练权限。兵种枪械资格仍由`can_use_firearms()`检查，近战不能请求换弹。

换弹期间沿用当前移动和转向、跟枪与冷却，头顶状态追加“换弹中”。普通受击不取消换弹；死亡、换枪、失去兵种枪械资格、对话取消，离场刷新恢复满匣并等待再次激活。暂停随世界停止计时。压制仍按原定时规则结束，只统计实际开出的枪；本步没有新增先找掩体再换弹或美术动画。
