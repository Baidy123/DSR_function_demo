# 玩家射击测试

## 当前模式与操作（2026-09-19）

Main 的 Player/Combat 使用 player_combat_v3.gd。选中 **Main → Player**，在检查器的 **Aim Mode** 下拉框选择：

- **新散布锥模式**（默认）：每枪在完整三维锥内按立体角均匀随机取方向，稳定度越高，锥的半角越小。没有额外的“是否直射中心”概率判定。
- **旧概率模式**：按当前稳定度判定是否直射中心，否则在距中心8°～20°的三维范围内随机偏转，保留修改前的算法。HUD 称“中心概率”，因为实际命中仍取决于碰撞。

两种模式共用右键瞄准、左键单发、自动锁定、移动/连射/目标移动惩罚和恢复过程。切换模式不重置锁定、稳定度或射击冷却。独立 combat.tscn 仍使用旧 v2，不读取 Player 的模式选择。

## 武器散布设置

在文件系统中选中 **test_pistol.tres**，或展开 **Player → Combat → Weapon**：

| 参数 | 用途 | 当前测试枪设置 |
| --- | --- | --- |
| Min Spread Angle Degrees | 稳定度100%时的散布半角 | 5° |
| Max Spread Angle Degrees | 稳定度0%时的散布半角 | 24° |
| Cone Angle Degrees | 锁定候选目标的扇形总角度，与弹道散布分开 | 45° |

最小/最大散布仅用于新模式。半角指中心轴到锥边的夹角，全开角是它的两倍。最小角为0时可以完全收拢；大于0时即使完全稳定也保留随机散布。运行时限制在0°～45°，最大值小于最小值时按最小值处理。

当前半角 = 最大半角 × (1－稳定度) ＋ 最小半角 × 稳定度。例如0°～12°的武器在稳定度50%时为6°半角。脚本默认半角为0°/12°；用户随后在测试枪资源中调整为5°/24°，索敌总角度为45°，均保留。本轮保留资源中用户设置的恢复时间1秒、移动上限0.4、每枪惩罚0.05、射击下限0.4、恢复延迟0.4秒和跟枪参数。

accuracy 属性名保留以兼容现有武器资源。它在新模式下表示稳定程度，**50%稳定度不等于50%命中率**；命中还受距离、目标大小、角度和遮挡影响。弹道仍是瞬时射线，仅第一个碰撞物受击，支持瞄A打B，不穿墙。

## 准星与试玩

按用户最新要求，两种模式都保留原来的圆形准星和四向短线：稳定时收缩、变绿，移动和连射时扩大。半径使用原屏幕像素设置，只提示稳定程度，不投影真实散布截面。弹道仍在三维锥内向上下左右随机散布；准星样式不改变弹道。失锁、出区或对话时隐藏。

F5运行主场景，靠近靶场入口按E开门，进入后面向训练靶，按住右键观察稳定恢复，再边移动边射击。停止游戏后在Player上切换模式，重跑比较；在武器资源中把最小散布设为非零，可以测试完全稳定后仍会偏转的武器。
