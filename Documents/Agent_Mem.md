## 2. 最近一轮完成的工作（材质、动作、武器槽、场景密度）

### 2.1 材质与图案系统

- 顶点新增 `material` 通道：`MeshVertex { position, normal, color, pattern, material }`，
  输入布局多一个 `TEXCOORD1`（偏移 40）。
- `Shared_Types.hpp` 定义 `SurfacePattern`（0–14）与 `SurfaceMaterial`（0–11），
  着色器 `ApplyPattern` 生成细节，`GetSurface` 查表得到
  `{高光宽度, 高光强度, 金属感, 漫反射比例, 环境反射}`，逐灯 Blinn-Phong + 假环境反射。
- 新增图案：纸箱（褶皱+瓦楞+胶带）、纸张/海报、玻璃条纹、瓷砖、棋盘、皮革、橡胶；
  新增材质：抛光金属、玻璃、塑料、纸板、布料、陶瓷、橡胶、积水。
- 场景体块只需给 `pattern`，材质由图案默认推导；台面黄铜、窗玻璃等特例显式指定。
- `.fcm` 新增 `surface <名称|编号>` 指令；四份网格资产全部重写并补齐材质。

### 2.2 场景密度

  盆栽、壁灯、吊扇、木椅、酒箱、啤酒筐；地面改木地板 + 吧台前瓷砖带。
- 街道：砖墙立面、橱窗暖光、消防梯、壁挂空调、落水管、售货机、垃圾箱、锥桶、
  路桩、告示牌、纸箱堆、帆布、电线、对面楼剪影与窗光。
- 铁港：货架、油桶、线缆盘、工作台、警戒栏、纸箱堆、管道、地面导向线、灭火器。
- 三处机位重新构图（酒吧 58°、街道 58°、铁港三段各 56°）。

### 2.3 角色与动作

- 骨骼扩到 16 段：新增 `weaponR`（挂在 `handR` 下），武器作为独立部件，空手时直接不绘制。
- 建模细节：手掌 + 拇指 + 四根两节手指、翻领、腰带扣、腰包、枪套、背包、护肩、
  护目镜、面罩、头盔+面甲、靴筒/鞋带/鞋底、袖口纽扣。
- 新增角色 `THUG`（近战打手：兜帽+面罩+护肩+钢管，体型最壮）。
- 姿态：待机（呼吸+重心+头部微动）、行走、奔跑（前倾+大摆臂+大弓步）、
  **双手持枪**（右手主握 + 左臂横过胸前托握）、换弹（左手取弹匣+压枪）、
  徒手近战（预备式→直拳→回收）、死亡前倾。

### 2.4 战斗

- 武器槽 `WeaponSlot { FISTS, PISTOL }`，滚轮切换；未领装备前强制空手。
- 空手：左键扇形近战（24 伤害 / 1.65 m / 击退 / 0.46 s 冷却）。
- 敌人：拾荒者远程 6–7 m、打手近战冲脸（1.5 m 挥棒 14 伤害）、特工 8–9 m 密集点射。
- 子弹改带半径（0.03 m）+ `SegmentBlockedDilated`，贴着纸箱/集装箱边缘的弹道也会被拦住；
  枪口高度降到 1.16 m，矮掩体也能挡弹。

### 2.5 其他

  所有阴影曾被渲染成白椭圆，修复后阴影恢复为深色。
- HUD 新增武器槽显示（手枪/空手 + “滚轮”提示）。

## 2.6 上一轮（UI 高清化、相机跟随、骨骼重建）

### 2.6.1 UI 与文字清晰度

- 3D 渲染与 UI 彻底分层：3D 画到 `720×405`，后处理放大到窗口，UI 再以屏幕像素密度叠加。
- `SpriteBatch::Begin` 支持 `scale / offset / targetSize`，UI 逻辑坐标 `480×270` 映射到任意窗口尺寸。
- `TextRenderer::SetPixelScale(n)` 让文字按物理像素光栅化（12px 逻辑字号 → 36px 纹理），彻底解决“放大后模糊”。
- 截图流程改为 `SetCaptureMode(true)` → 渲染到 `m_capture`（`1440×810`）→ 直接读回，包含后处理与 UI。

### 2.6.2 相机与可见性

- `CameraRuntime` 增加跟随：机位按玩家在区域内的位移平移（`CAMERA_FOLLOW_RATIO 0.55`，限幅 2.6 m），
  注视点额外向玩家靠拢 `CAMERA_TARGET_BIAS 0.55`，并把 eye 限制在区域边界内 0.35 m，避免穿墙。
- 三个场景的机位与出生点重设；铁港改为三段机位、抬到 y≈4.8，视野覆盖更宽。
- 场景提亮：环境光、雾浓度、地面/墙体基色整体上调；角色额外获得一盏跟随玩家的柔和补光。

### 2.6.3 碰撞（阻断性 Bug）

- 旋转道具的碰撞盒此前用“最大半径”近似，一辆横停的汽车会生成 4.5×4.5 m 的方块堵死街道，
  铁港 12 m 集装箱更会生成 17×17 m 的巨块。
- 改为 OBB 在 XZ 轴上的投影公式（`|cos|·hx + |sin|·hz`），并调整车辆位置与交互点。

### 2.6.4 角色重建（上一版）

- 旧实现每个部件是整体刚性块、无层级、无手。新实现：
  - 15 根骨骼：`hips / torso / head / upperArm(L,R) / foreArm(L,R) / hand(L,R) / thigh(L,R) / shin(L,R) / foot(L,R)`。
  - 每段几何以自身关节为原点，`part.pivot` 存“相对父关节的偏移”，绘制时做一次自顶向下 FK。
  - 建模细节：头骨 + 下颌 + 耳 + 鼻 + 眉 + 眼白/瞳孔 + 嘴；外套分腹/胸/肩线 + 口袋 + 中缝；
    前臂 + 护腕；手掌 + 拇指 + 指节；靴筒 + 鞋头 + 鞋底 + 鞋带；武器（手枪/步枪/铁管）。
  - 角色差异：大美长风衣 + 发髻，东子光头 + 背心 + 背包 + 护目镜，小帅围裙 + 衬衫，
    拾荒者兜帽 + 面罩 + 步枪，特工全罩头盔 + 发光面甲 + 护肩。
- 动画：走路（大腿/膝盖/脚踝 + 反相摆臂 + 重心起伏 + 髋部侧摆 + 躯干扭动）、
  idle（呼吸 + 头部微动）、瞄准（右臂抬起、左臂托握、上身与头转向）、后坐力、受击、死亡前倾。
- 身体朝向与瞄准方向分离：`Player::facing` 跟随移动方向，`aimOffset` 让上半身转向鼠标；
  停止射击 1.35 s 后放下枪，避免整段静止都保持举枪 T 形。

## 5. 接口契约

### 5.1 骨骼与角色网格

部件名固定为 16 个骨骼名（含 `weaponR`），`part.pivot` 存**相对父关节的偏移**，
绘制时 `CharacterLibrary::Draw` 按 `kSkeleton` 顺序做 FK：

```text
world[bone] = R_bone * T(offset_bone) * world[parent]
```

`weaponR` 的父骨骼是 `handR`；当 `CharacterAnim.showWeapon == false` 或
`weapon == WeaponKind::NONE` 时跳过该部件，因此不需要为每个角色准备空手/持枪两套模型。

角色的缩放通过 `base` 矩阵的最左侧 `Scale(style.height)` 完成，模型原点在脚底，因此缩放不会离地。

### 5.2 坐标空间

| 空间 | 尺寸 | 使用者 |
| --- | --- | --- |
| 世界 | 米，y 向上 | 玩法、碰撞、相机 |
| 3D 内部 | `INTERNAL_WIDTH × INTERNAL_HEIGHT`（720×405） | 场景、后处理输入 |
| UI 逻辑 | `UI_WIDTH × UI_HEIGHT`（480×270） | 所有界面与 HUD |
| 窗口/截图 | letterbox 区域（1440×810） | 最终输出 |

`GameRenderer::WorldToScreen` 返回 **UI 逻辑坐标**；`RenderDevice::ScreenToInternal` 也返回 UI 逻辑坐标。

### 5.3 新增调试入口

- `GameApp::SetCaptureMode(bool)`：截图模式，渲染到离屏大目标。
- `DebugSetWalkPose(bool)` / `DebugSetAimPose(bool)` / `DebugSetMeleePose(bool)`：
  无头截图时固定角色姿态。
- `OffscreenTest --pose aim|melee|walk`：对应上面三个钩子。
- 命令行：`--walk`、`--px <x> --pz <z>`。

### 5.4 材质与武器

- `SurfacePattern` / `SurfaceMaterial` 定义在 `Shared_Types.hpp`，C++ 与 `.fcm` 共享编号。
- `WeaponSlot { FISTS, PISTOL }`；`Player::slot` 决定 `aiming`、`showWeapon` 与左键行为。
