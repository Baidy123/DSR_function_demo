# 美术设计（Design Art）

> 方向：**复古低清多面体 + 像素化 CG 质感**，参考 *SIGNALIS* 的构图、光色与低分辨率处理，不复制其素材。
> 本仓库不引入任何图片文件：所有画面由几何 + 程序化图案 + 后处理生成。

---

## 1. 渲染规格

| 项 | 值 | 说明 |
| --- | --- | --- |
| 内部渲染分辨率 | `480 × 270` | 所有 3D 与 UI 共用同一张低分辨率目标 |
| 放大方式 | 整数倍最近邻 + 黑边 | 保持像素边缘干净，不出现插值糊边 |
| 深度格式 | `D24_UNORM_S8_UINT` | 只在 3D 场景使用；2D 精灵禁用深度 |
| 后处理 | 4×4 Bayer 抖动、扫描线、暗角、颗粒、轻微色差、受击染色、淡出、故障 | 统一在 `POST_SHADER` 中完成 |
| 抖动量级 | 24 级色阶 | 模拟低色深 CRT / VHS 观感 |

## 2. 光照模型

- **环境光**：每场景一个基色，按法线 Y 做半球提亮（`0.52 + 0.48 * saturate(N.y*0.5+0.5)`）。
- **点光源**：最多 8 盏，`atten = (1 - d/range)²`，`ndl = saturate(dot(N,L)*0.5+0.5)`（wrap 光照，避免死黑）。
- **边缘光**：`rim = (1 - N·V)³ * ambient * 0.45`，用于勾出低多边形的轮廓；系数不可再放大，否则细长圆柱会整条过曝。
- **自发光**：材质 `pattern >= 8` 时叠加 `albedo * 1.6`；另有全局 `uEmission` 项供警报等状态使用。
- **雾**：线性距离雾，用场景 `fogColor / fogNear / fogFar / fogDensity` 控制。

场景光色基准：

| 场景 | 环境光 | 主光源 |
| --- | --- | --- |
| 酒吧外 | `#333E54` | 暖琥珀雨棚灯、洋红霓虹、路灯暖白 |
| 酒吧内 | `#343C4E` | 吧台暖光、卡座洋红、冷青补光 |
| 铁港 | `#333C4C` | 三盏吊灯暖光 + 东侧警报红光 |

## 3. 程序化图案（`ApplyPattern`）

材质编号写进顶点属性，按世界坐标推导 UV，避免任何贴图：

| `pattern` | 名称 | 视觉 |
| --- | --- | --- |
| 0 | 素色 | 纯色块，用于台面、金属压边 |
| 1 | 砖 | 交错砖缝 + 噪声明暗 |
| 2 | 木 | 竖向拼缝 + 细木纹 |
| 3 | 金属筋 | 横向筋条 + 轻微噪声 |
| 4 | 锈 | 斑块锈色混入基色 |
| 5 | 布料 | 细密织纹 |
| 6 | 混凝土 | 大颗粒噪声 |
| 8+ | 自发光 | 霓虹、屏幕、灯罩 |

## 4. 文本网格 `.fcm`

所有静态道具都是 UTF-8 文本，可 diff、可审阅：

```text
mesh PROP_LAMPPOST
part body pivot 0 0 0
mat 0x22262A
pattern 3
cyl 0 0 0 0.09 0.07 3.6 8
mat 0xFFD79A
pattern 8
box 0 3.5 0.72 0.4 0.08 0.28
endpart
endmesh
```

- 单位：米；原点位于物件底面中心。
- 支持体块：`box`、`bevel`、`cyl`、`cone`、`sphere`、`plane`、`wall`、`quad`、`tri`。
- 现有资产：`common.fcm`（门框、灯、积水、木箱等通用件）、`street.fcm`、`bar.fcm`、`harbor.fcm`。
- 资源通过 `Resources.rc` 以 `RCDATA` 内嵌，运行时由 `LoadEmbeddedResource` 读出后拼接成一份网格库。

## 5. UI 视觉

1. 线框：1 px 青绿细线 + 四角折角，模拟终端。
2. 面板：近黑半透明填充 `rgba(6,9,13,0.77)` + 青绿描边。
3. 文字：系统字体拷到 32 位 DIB，用亮度生成 alpha，RGB 置白后按需染色；对话/日志用 14–16 px，标题用 28–34 px。
4. 图标：全部由矩形、圆形、三角拼出（弹匣、医疗包、信用点、准星、箭头），不依赖字体符号。
5. 状态必须“形状 + 文字”双通道：血条同时显示数字，货币同时显示图标与数值。

---

## 6. 角色与道具的造型规则

1. 单个物体尽量不超过 200 个三角形；角色整体不超过 400。
2. 斜切（`bevel`）用于柔化盒体硬边，是低多边形的主要“造型手段”。
3. 细节靠**色块分割**而不是几何：一条深色带就能表示口袋或绑带。
4. 高光只出现在自发光件与灯罩上，其他表面靠点光源的暖斑。
5. 避免纯黑死区：最暗处也要保留 `#0C1018` 量级的冷色，便于玩家读出空间。
