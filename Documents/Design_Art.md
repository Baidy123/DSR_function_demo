# 美术设计（Design_Art）

> 目标：在有限分辨率与自研渲染管线下，做出“雨夜旧城 + 暖色酒吧”的辨识度。
> 参考气质：《For The King》的平面化角色、《Astroneer》的干净色块、《How to Fish》的克制氛围；不追求写实 3D。

---

## 1. 技术规格

| 项目 | 规格 |
| --- | --- |
| 内部渲染分辨率 | 480×270（16:9） |
| 窗口默认尺寸 | 1440×810（3× 整数缩放） |
| 缩放方式 | 最近邻整数缩放 + 黑边；窗口过小时使用 2×，最小 960×540 |
| 瓷砖尺寸 | 16×16 |
| 角色尺寸 | 16×24（脚底原点）；部分 NPC 坐姿 24×24 |
| 头像尺寸 | 48×48 |
| UI 图标 | 12×12 / 16×16 |
| 特效 | 4×4 至 64×64，加色混合 |
| 字体 | 系统 `Microsoft YaHei UI` / `SimSun`，12–16px，GDI 抗锯齿后转纹理 |
| 动画帧率 | 行走 8 FPS；待机 2–4 FPS；特效 12–24 FPS |

### 1.1 像素规则

- 不使用半透明渐变做大面积阴影；渐变只用于光晕、雨雾和 UI 背景。
- 角色与道具使用 1px 深色描边（比底色暗 30%），保证在复杂背景上可读。
- 同一材质最多 4 个明度层级：暗部、底色、亮部、高光。
- 禁止缩放到非整数倍；所有资产按 1:1 生成。
- 光照以“局部点光”为主：霓虹、台灯、枪口焰、屏幕光。

### 3.2 酒吧内（30×17 格，固定镜头）

```text
┌──────────────────────────────────────────────┐
│ 墙：酒架 / 霓虹 / 管道 / 后门                │
│  卡座×4           吧台（长条）      点唱机   │
│  商人卡座（角落，青色终端光）               │

```

- 摄像机固定；所有关键交互物在单屏内可见或通过引导可发现。
- 吧台为暖光中心；商人卡座为冷色；大美卡座为暗红 + 暖光。
- 地面使用木地板 + 旧地毯；墙面砖 + 酒架；顶部悬挂灯。
- 后门在画面右上方，作为去铁港的通道（Demo 中由正门离开，后门可作为装饰）。

```text

│ 高墙 / 卷帘门 / 吊灯 / 管道                              │
```

- 中央高亮货物箱是视觉锚点，带橙色防伪贴与青色指示灯。
- 拾荒者分布在货堆之间；伏击时东侧卷帘门亮起洋红警报。
- 战斗空间保留掩体与走位通道；避免死角卡住玩家。

## 6. 动画与特效规范

### 6.1 角色动画

- 行走：4 帧循环，8 FPS；迈步时脚部交替 1px 偏移，身体上下 1px。
- 待机：2 帧循环，2 FPS；呼吸/烟灰/手指敲击。
- 朝向：S/N/E/W；攻击时朝向鼠标方向（使用 4 方向近似）。
- 受击：白色闪帧 0.06s + 击退 2px。
- 死亡：0.2s 内 alpha 降到 0，留下 2 帧烟雾。

### 6.2 场景动效

| 场景 | 动效 |
| --- | --- |
| 酒吧外 | 雨丝循环、霓虹 3 种闪烁节奏、水洼微光、车辆尾灯呼吸 |
| 酒吧内 | 吊灯轻微摆动、点唱机彩灯（修好后）、烟雾缓慢上升、终端屏幕扫描 |
| 铁港 | 吊灯摆动、警报旋转、货箱指示灯、尘埃粒子 |
| 全局 | 暗角、扫描线、受伤红闪、屏幕震动、拾取高光 |

### 6.3 战斗反馈

- 开枪：枪口焰 2 帧（0.05s）+ 屏幕震动 1px + 弹壳粒子 + 音效。
- 命中：火花/血点 6–10 粒 + 命中闪白 + 短促音效。
- 击杀：尸体淡出 + 掉落物光点。
- 玩家受伤：红色暗角脉冲 + 震动 2px + 音效。

## 7. UI 设计

### 7.1 HUD（常态）

```text
┌──────────────────────────────────────────────┐
│ [目标] 前往铁港仓库取回货物        ₡180  [♥]  │
│                                              │
│                                              │
│                                              │
│  [头像] 小明   ████████░░  80/100            │
│                [子弹 icon] 12/36  [F] 医疗包  │
└──────────────────────────────────────────────┘
```

- 左上：当前目标（最多两行），琥珀色文字 + 细线。
- 右上：信用点。
- 左下：玩家头像 32×32、生命条、弹药、医疗包数量。
- 中央下方：交互提示 `[E] 交谈`，仅在范围内显示。
- 生命低于 30% 时生命条转红并轻微脉动。

### 7.2 对话框

```text
┌──────────────────────────────────────────────┐
│ [48×48 头像]  大美                            │
│               这城市的规矩就是这样。          │
│               你想在这里过日子，就得学着适应。 │
│                                        ▼      │
└──────────────────────────────────────────────┘
```

- 高度 86px，底部对齐；半透明深色背景 + 1px 青色边线。
- 名字使用角色主色；正文骨白；选项用琥珀色高亮。
- 打字机速度 28 字/秒；空格/左键可立即补全，再按进入下一句。
- 选项出现时，玩家可用 `W/S` 或 `↑/↓` 选择，`E/Enter` 确认。

### 7.3 商店

- 左侧：商人头像 + 台词；中间：商品列表；右侧：详情。
- 每项显示图标、名称、价格、简介；买不起时价格变红。
- 底部：`[E] 购买  [Esc] 离开`；购买后播放收银音效并更新余额。
- 思维接入装置置顶、不可购买，显示“余额不足 / 非卖品？”。

### 7.4 任务日志

- `Tab` 打开；列出主线与支线，显示状态（进行中/已完成/失败）。
- 右侧显示操作说明与当前装备。
- 背景暂停游戏（不推进敌人与子弹）。

## 8. 生成与审阅流程

1. 修改 `Resources/ArtGen/ArtGen_Main.cpp`。
2. 编译生成器（独立命令，不进入根 `Makefile`）：
   ```powershell
   g++ -std=c++17 -O2 Resources/ArtGen/ArtGen_Main.cpp -o Temp/ArtGen.exe
   Temp/ArtGen.exe Resources
   ```
3. 检查 `Resources/Art/*.png`（可用图片查看器或视觉工具）。
4. 确认 `Resources/ArtPack.bin` 更新。
5. 运行 `make` 构建游戏；资源通过 `Resources/Resources.rc` 嵌入。
6. 使用 `Tools/OffscreenTest` 生成场景截图，审阅整体效果。

> 生成器只依赖 C++ 标准库；PNG 使用自实现的无压缩 Deflate，保证无需 zlib。

## 9. 美术验收标准

- [ ] 在 480×270 下，三名主要 NPC 可通过轮廓与主色在 1 秒内区分。
- [ ] 酒吧内至少有三处暖光源，形成“避风港”感。
- [ ] 酒吧外与铁港至少各有两处冷/暖对比，避免画面发灰。
- [ ] 角色在所有地砖上都有 1px 描边，不糊进背景。
- [ ] 对话正文在 480×270 下可读，不出现断字、溢出、遮挡。
- [ ] 战斗特效不遮挡玩家与敌人轮廓超过 0.1s。
- [ ] 所有资产命名与清单一致，缺失资源有日志与占位。
