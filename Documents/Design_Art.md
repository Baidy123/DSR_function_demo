# 美术设计（Design Art）

> 方向：**复古低清多面体 + 像素化 CG 质感**，参考 *SIGNALIS* 的构图、光色与低分辨率处理，不复制其素材。
> 本仓库不引入任何图片文件：所有画面由几何 + 程序化图案 + 后处理生成。

---

## 1. 渲染规格

| 项 | 值 | 说明 |
| --- | --- | --- |
| 3D 内部分辨率 | `720 × 405` | 场景与后处理的输入；放大 2 倍后依然是干净的像素块 |
| UI 逻辑分辨率 | `480 × 270` | 界面坐标空间；实际按屏幕密度 3 倍光栅化 |
| 放大方式 | 整数倍最近邻 + 黑边 | 3D 图层直接放大到 letterbox 区域 |
| 深度格式 | `D24_UNORM_S8_UINT` | 只在 3D 场景使用；UI 精灵禁用深度 |
| 后处理 | 4×4 Bayer 抖动、扫描线、暗角、颗粒、轻微色差、受击染色、淡出、故障 | 统一在 `POST_SHADER` 中完成 |
| 抖动量级 | 24 级色阶 | 模拟低色深 CRT / VHS 观感 |

> **分层原则**：低清只用于 3D 画面，UI 与正文永远按物理像素高清渲染。
> 文字纹理密度由 `TextRenderer::SetPixelScale(3)` 保证，12px 逻辑字号实际以 36px 光栅化。

## 2. 光照模型

- **环境光**：每场景一个基色，按法线 Y 做半球提亮（`0.72 + 0.28 * saturate(N.y*0.5+0.5)`），
  保证暗面仍有可读的空间信息。
- **点光源**：最多 8 盏，`atten = (1 - d/range)²`，`ndl = saturate(dot(N,L)*0.5+0.5)`（wrap 光照，避免死黑）。
- **角色补光**：每帧额外一盏跟随玩家的冷色弱光（`(0.62,0.70,0.86) × 0.8`，范围 6.8 m），
  让角色在暗场景里保持剪影可读，同时不照亮远处。
- **边缘光**：`rim = (1 - N·V)³ * ambient * 1.05`，用于勾出低多边形的轮廓；
  数值不能再低，否则角色会与背景融合。
- **自发光**：材质 `pattern >= 8` 时叠加 `albedo * 1.6`；另有全局 `uEmission` 项供警报等状态使用。
- **雾**：线性距离雾，用场景 `fogColor / fogNear / fogFar / fogDensity` 控制；
  夜间场面的雾密度控制在 0.58–0.62，避免远处被完全吃掉。

场景光色基准：

| 场景 | 环境光 | 主光源 |
| --- | --- | --- |
| 酒吧外 | `#333E54` | 暖琥珀雨棚灯、洋红霓虹、路灯暖白 |
| 酒吧内 | `#343C4E` | 吧台暖光、卡座洋红、冷青补光 |
| 铁港 | `#333C4C` | 三盏吊灯暖光 + 东侧警报红光 |

## 3. 程序化图案（`ApplyPattern`）

材质编号写进顶点属性，按世界坐标推导 UV，避免任何贴图：

| `pattern` | 名称 | 视觉 |
| --- | --- | --- |
| 0 | 素色 | 纯色块，用于台面、金属压边 |
| 1 | 砖 | 交错砖缝 + 噪声明暗 |
| 2 | 木 | 竖向拼缝 + 细木纹 |
| 3 | 金属筋 | 横向筋条 + 轻微噪声 |
| 4 | 锈 | 斑块锈色混入基色 |
| 5 | 布料 | 细密织纹 |
| 6 | 混凝土 | 大颗粒噪声 |
| 8+ | 自发光 | 霓虹、屏幕、灯罩 |

## 4. 文本网格 `.fcm`

所有静态道具都是 UTF-8 文本，可 diff、可审阅：

```text
mesh PROP_LAMPPOST
part body pivot 0 0 0
mat 0x22262A
pattern 3
cyl 0 0 0 0.09 0.07 3.6 8
mat 0xFFD79A
pattern 8
box 0 3.5 0.72 0.4 0.08 0.28
endpart
endmesh
```

- 单位：米；原点位于物件底面中心。
- 支持体块：`box`、`bevel`、`cyl`、`cone`、`sphere`、`plane`、`wall`、`quad`、`tri`。
- 现有资产：`common.fcm`（门框、灯、积水、木箱等通用件）、`street.fcm`、`bar.fcm`、`harbor.fcm`。
- 资源通过 `Resources.rc` 以 `RCDATA` 内嵌，运行时由 `LoadEmbeddedResource` 读出后拼接成一份网格库。

## 5. UI 视觉

1. 线框：1 逻辑像素青绿细线 + 四角折角，模拟终端；在高分辨率层上实际为 3 物理像素。
2. 面板：近黑半透明填充 `rgba(6,9,13,0.77)` + 青绿描边。
3. 文字：系统字体拷到 32 位 DIB，用亮度生成 alpha，RGB 置白后按需染色；
   字号以逻辑像素定义（对话 12、小注 9、标题 34），光栅化时乘屏幕密度，因此不会发虚。
4. 图标：全部由矩形、圆形、三角拼出（弹匣、医疗包、信用点、准星、箭头），不依赖字体符号。
5. 状态必须“形状 + 文字”双通道：血条同时显示数字，货币同时显示图标与数值。
6. 交互提示统一为“按住 Ctrl 快进”式带进度条的输入反馈，而不是单靠按键说明。

## 6. 角色与道具的造型规则

1. 单个道具尽量不超过 300 个三角形；单个角色约 20–30 个盒体（约 900 三角形）。
2. 斜切（`bevel`）用于柔化盒体硬边，是低多边形的主要“造型手段”。
3. 细节靠**色块分割**而不是几何：一条深色带就能表示口袋或绑带。
4. 角色必须靠**剪影与配色**区分：轮廓差异（风衣/围裙/兜帽/头盔）优先于面部细节。
5. 角色色板整体提亮 1.30 倍，避免在夜景中与背景融成一片。
6. 高光只出现在自发光件与灯罩上，其他表面靠点光源的暖斑。
7. 避免纯黑死区：最暗处也要保留 `#0C1018` 量级的冷色，便于玩家读出空间。
