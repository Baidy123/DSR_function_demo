# 测试计划（Test Plan）

> 所有自动化测试必须**无头**运行：不抢鼠标键盘、不抢焦点、不抓屏。视觉验收只看离屏截图。

---

## 1. 工具

| 工具 | 用途 | 命令 | 产物 |
| --- | --- | --- | --- |
| `UnitTests` | 纯逻辑单元测试 | `make -C Tools unit` → `Tools/UnitTests/Build/UnitTests.exe` | 控制台输出，失败时返回非 0 |
| `OffscreenTest` | 隐藏窗口真实渲染 + 截图 | `make -C Tools offscreen` → `Tools/OffscreenTest/Build/OffscreenTest.exe --scene bar --ui dialogue` | `Temp/Screenshots/*.bmp` |
| `OffscreenTest --flow` | 跑完整主线并断言阶段 | `Tools/OffscreenTest/Build/OffscreenTest.exe --flow` | 控制台输出，失败时返回非 0 |

---

## 2. 单元测试覆盖

| 分组 | 用例 |
| --- | --- |
| 数学 | 向量长度/归一化、点积叉积、XZ 距离、偏航与方向互转、平移矩阵、绕 Y 旋转、透视矩阵系数、深度随距离增长 |
| 碰撞 | 圆与 AABB 相交/分离、圆推出、线段命中与未命中、射线与圆、射线与地面 |
| 背包 | 初始金钱、购买成功/失败、弹药上限、医疗包上限、货币收支 |

| 对话 | 逐字显示、选项切换、确认跳转、完成事件、非法目标索引 |
| 剧情 | 全部对白集的节点合法性与可启动性、结局分支存在 |

当前结果：**93 / 93 通过**。

---

## 3. 流程测试（`--flow`）

按真实接口顺序推进，验证状态机而不是画面：

1. 新游戏 → 序章对白 → 进入可操作状态
2. 进入酒吧 → 与小帅对话 → 目标切到大美
3. 与大美对话 → 主线进入“领取装备”
4. 与小帅二次对话 → 接受支线
5. 与东子对话 → 打开商店 → 关闭后获得新手装备
6. 离开酒吧 → 上车 → 抵达铁港
7. 拾取零件 → 支线进入“已获得零件”
8. 搬起货物 → 触发警报 → 特工出现
9. 清理特工 → 目标切到“返回酒吧”
10. 返回街道 → 进入酒吧 → 交付零件 → 支线完成
11. 与大美对话 → 选择“我接” → 进入结局 → 奖励结算

当前结果：**25 / 25 通过**。

## 4. 视觉验收清单

离屏截图需逐张确认（`Temp/Screenshots/`）：

- [ ] 标题界面：标题、副标题、开始提示、操作说明清晰可读。
- [ ] 酒吧外：砖墙、门洞暖光、路灯、积水、雨丝、霓虹可辨认；无大面积死黑。
- [ ] 酒吧内：吧台、酒柜、冰箱、水槽、啤酒龙头、卡座、圆桌、椅子、点唱机、终端可辨认；
  木纹、黄铜、玻璃、布料、砖墙的反射明显不同。
- [ ] 铁港：纸箱、木箱、油桶、集装箱、货架、线缆盘、工作台、吊灯、敌人可辨认；
  纸箱有皱纹与胶带，金属容器有锈与高光。
- [ ] 对话框：头像、姓名、正文、选项、继续箭头、快进进度条齐全，对比度足够。
- [ ] 商店：商品名、说明、价格、余额、操作提示齐全。
- [ ] 任务日志：主线/支线/物品/操作四块信息完整。
- [ ] 暂停、死亡、结局：遮罩与文案完整，不遮挡关键信息。
- [ ] HUD：武器槽显示当前是“手枪”还是“空手”，与手上模型一致。
- [ ] 所有界面在中文字体下无豆腐块、无截断。

## 5. 回归重点（本轮修复过的问题）

| 问题 | 症状 | 回归方式 |
| --- | --- | --- |
| 精灵深度状态错误 | UI 与文字被场景几何部分裁掉 | 任意界面截图，文字必须完整 |
| 三维头像绑定错误 | 对话头像区域全黑 | 对话截图，头像应有人物 |
| 剧情事件丢失 | 接受支线 / 结局选择无效 | `--flow` 中“支线已接受”“结局选择”断言 |
| 相机在房间外 | 场景全黑或只剩天空 | 三个场景截图都必须有可见空间 |
| 边缘光过强 | 细长物体整条发白 | 街道路灯杆应为深色，只有灯罩发光 |
| 网格默认自发光为白色 | 所有物体被冲波成白雾，阴影变成白椭圆 | `DrawMesh` 的 `emission` 必须是黑色；截图阴影应为深色 |
| 自发光过曝 | 窗户、霓虹整块发白 | 窗内暖光应能看到玻璃与墙壁层次 |
| 子弹穿墙 | 弹道越过箱子/吧台 | 对着掩体开枪，子弹应在掩体表面消失并出火花 |
| 武器槽不同步 | 切到空手但模型仍拿着枪 | `--pose melee` 截图，手上应为空 |
| 敌人行为同质 | 近战敌人也站在远处对射 | `--flow` 后进铁港，打手应主动冲脸 |

## 6. 手动验收

1. 用与 `Target.exe` 不同的产物名构建（例如 `make release TARGET_FILE_NAME=TargetDev`），
   避免覆盖正在运行/测试的二进制。
2. 用键鼠完整走一遍主线，确认没有输入卡死、镜头穿墙、敌人卡住。
3. 故意打空弹药、故意死亡，确认死亡界面可重试且装备保留。
4. 滑轮切到空手，确认模型不再显示手枪且左键能近战。
5. 在铁港对着纸箱/集装箱开枪，子弹必须被拦住。
6. 对话中按住 Ctrl 约 0.8 秒，确认进度条填满后开始快进，松开立即停止。
7. 触发两个结局，确认文案与结算不同。
8. 检查 `Temp/fc_log.txt` 没有 `[ERROR]`。
