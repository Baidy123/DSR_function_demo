# 测试计划（Test_Plan）

> 原则：默认只做针对性测试；所有自动化测试无头运行，不占用鼠标、键盘、屏幕。
> 只有用户明确要求“跑一遍所有测试”时，才执行全量验证。

---

## 1. 测试层级

| 层级 | 工具 | 内容 | 运行方式 |
| --- | --- | --- | --- |
| 编译验证 | 根 Makefile | Release + Debug 构建 | `make` |
| 单元测试 | `Tools/UnitTests` | 数学、背包、任务、对话数据 | 无窗口控制台 |
| 渲染验证 | `Tools/OffscreenTest` | 隐藏窗口渲染三场景并截图 | 无窗口交互 |
| 实机验收 | 游戏本体 | 完整流程、手感、音频 | 人工（用户执行） |

## 4. 实机验收清单

- [ ] 双击 `Build/Release/Target.exe` 可启动，无缺失 DLL。
- [ ] 标题界面 `Enter` 进入游戏，`Esc` 退出。
- [ ] 移动、瞄准、射击、装填、交互、医疗包、日志、静音均可用。
- [ ] 完成主线：进入酒吧 → 对话 → 商店 → 仓库 → 战斗 → 返回 → 结局。
- [ ] 完成支线：接受 → 拾取零件 → 交付 → 点唱机音乐。
- [ ] 拒绝支线：支线关闭，不影响主线。
- [ ] 死亡后 `Enter` 可从检查点重试。
- [ ] 购买/余额不足/上限提示正确。
- [ ] 窗口缩放、Alt+Enter 全屏、失焦暂停输入正常。
- [ ] 无崩溃、无卡死、无中文乱码、无资源缺失（洋红占位）。

---

## 5. 回归策略

- 改动任务/剧情 → 运行 `UnitTests` + `OffscreenTest --scene bar`。
- 改动渲染/资源 → 运行 `OffscreenTest` 三场景 + 对话/商店截图。
- 改动输入/音频 → 实机抽查，不做自动化。
- 每次提交前：`make` 成功 + 针对性测试通过 + `git status` 干净。
